# v1.24.0 · 사이클 판단표

기존 일별 원자료 화면의 세 개 표와 지표 조합은 초보자가 기간과 매수·매도 검토 이유를 읽기 어렵게 만들었다. 전체 이력 MDD가 반복되는 표시도 현재 하락이나 같은 기간의 손실로 오해하기 쉬웠다. 이 릴리스는 `?page=data`를 **사이클 판단표** 하나로 재구성한다.

## 사용자에게 달라지는 점

페이지 제목·메뉴·브라우저 제목을 사이클 판단표로 바꾼다. 날짜·기간, 사이클 구간, 검토 단계, 판단 근거, 같은 기간의 가격 변화·최대 낙폭의 다섯 열을 둔다. 기본 범위는 최근 4년 안에 끝나는 기준점과 선택한 근거리 미래 가정이다. 과거·현재 관측 또는 미래 가정만 필터링하고, 개별 사이클이나 전체 이력도 같은 표에서 확인한다.

매수·매도 행은 **끝 지점에서의 검토**다. 앞의 상승 구간 전체를 매도하라는 지시가 아니다. 적극 매수·적극 매도는 완료된 기준점의 가격 방향과 잠정 여부에 따라 구분하는 계획 강도다. 미래 경로 안에서 강한 단계가 나와도 가정 분류와 설명은 그대로 남는다. 횡보 구간은 연속된 28개 일말 가격에서 폭 12% 이하·등락 절댓값 6% 이하 조건이 7개 관측 이상 유지된 기간이다. 7개 유지 여부를 알 수 있는 날짜를 보존하며, 표시 시작을 28일 전으로 돌리지 않는다. 이 수치들은 표시 규칙이며 수익성을 입증한 최적값이 아니다.

색상과 문구를 함께 사용한다. 과거 사후 기준, 잠정 관측, 현재 관측, 미래 가정을 구분한다. 자료 부족이나 조건 불충족은 횡보로 채우지 않는다. 모바일에서는 날짜·국면과 검토 단계를 먼저 읽고, 같은 표 안에서 근거·가격 열을 가로로 확인한다.

SMA50·SMA200·RSI14, 기존 세 지표의 매매 판정, 연간 자산 비교·월별 표·대량 일별 표·전체 이력 요약 카드를 제거한다. 이 화면은 BTC의 차트 사이클을 읽는다. 다른 자산에 BTC 반감기 시계를 복제하지 않는다.

## 계산과 차트 연결

`getCycleContext`는 통합 차트의 캐시된 관측 자료, 선택한 경로, 기준점 객체를 표에 전달한다. 표는 별도 예측 경로나 고점·저점 날짜를 만들지 않는다. 날짜 선택은 같은 차트 지점 또는 가격 구간으로 연결된다. 자료나 가정이 바뀌면 표를 재계산하며 잘못 연결된 자료에서는 이전 표와 CSV를 비운다.

MDD는 각 행의 명시된 실제 시작·종료 구간에 한정한다.

\[
\operatorname{MDD}_{[a,b]}=100\min_{a\le t\le b}\left(\frac{P_t}{\max_{a\le s\le t}P_s}-1\right)
\]

저점보다 늦은 최고 가격을 분모로 쓰지 않는다. 실제 누락일은 보간하지 않고, 관측된 자료의 낙폭이 실제 손실을 과소평가할 수 있음을 표시한다. 미래 행에는 실현 수익률·MDD를 만들지 않는다. 현재 횡보 조건과 기간 MDD는 서로 다른 뜻이다.

공유 저점은 앞 사이클을 닫고 다음 사이클을 열 수 있다. 전체 표에서는 한 번만 표시하되 두 사이클에 속한다는 정보를 유지하여, 개별 사이클 필터에서도 마지막 하락 구간이 빠지지 않는다. 이전 가정의 날짜가 새 가정과 같아도 시나리오와 가격이 다르면 오래된 선택을 수락하지 않는다.

## 조사 결과와 설계 근거

완결된 차트 선택 구간의 상승·하락 기간은 2013년 747·406일, 2017년 1,067·364일, 2021년 1,059·366일이다. 3년 상승·1년 하락과 유사한 사례가 있지만 강제할 법칙은 아니다. ‘상승 구간’ 안의 MDD도 각각 −71.24%, −35.76%, −61.45%였다. 따라서 달력의 앞 3년을 통째로 강한 매수로 칠하지 않는다. 산식·고점 선택 편향·작은 표본·원문 출처는 [기간 연구](CYCLE_TABLE_RESEARCH.md)와 [재현 자료](data/cycle-table-research.json)에 보존한다.

## 검증

로컬 필수 회귀 검사 **999개가 모두 통과**했다. 독립 수치 검산, 기존 상태 모델, 연구 자료 보존, 차트 작업량, 정적 경로와 단일 HTML 빌드도 통과했다. 새 `verify:cycle-table` 검사는 실제 공개 함수에 유한 입력을 열거하고, **27개 의도적 결함**을 각각 해당 결함의 예상 실패로 탐지한다. 1,089개 짧은 가격 경로를 전수 검사하며 더 긴 횡보 구간은 명시한 유한 경계 사례로 검사한다.

독립 검토에서 찾은 세 문제의 재현 절차도 `scripts/verify-cycle-table-integration.mjs`에 보존했다. 이 검사는 실제 차트·표 컨트롤러를 사용하여 다섯 가정의 새 행 선택, 이전 가정 선택 거부, 공유 저점, 횡보 구간, 자료 오류 후 복구를 확인한다. 두 검사는 `verify:numerics`에 포함되어 CI·Pages·릴리스에서도 실행된다. 이 컨트롤러 검사의 DOM 경계는 브라우저 화면의 실제 배치·색상 검증을 대신하지 않는다.

검토 범위와 상태 전이는 [검증 문서](CYCLE_TABLE_VERIFICATION.md)에, 독립 검토에서 찾은 문제는 [최종 리뷰](CYCLE_TABLE_FINAL_REVIEW.md)에 기록한다. 같은 모델의 반복 render에서 모델 재계산 및 동일 표의 재기록을 억제하는 작업량 검사는 `tests/daily-data-performance.test.mjs`에 있다. 이 수치는 브라우저 실제 렌더 시간이나 모바일 기기 성능 측정이 아니다.

이번 검증은 표시·기간 산술·자료 연결과 명시된 코드 경계에 관한 것이다. 미래 가격 정확도, 투자 수익성, 수수료를 반영한 전략 성과를 증명하지 않는다.
