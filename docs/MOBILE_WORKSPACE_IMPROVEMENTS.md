# v1.10 · 지표 값, 모바일, 자석, 과거 봉 조회

작성: 2026-10-22. 소스 변경과 자동 검증을 기록한다. 실제 브라우저 검증은 배포 후 아래 별도 절에 추가한다.

## 화면과 표시 계약

첫 접속의 가격 창은 최신 완료 일말 관측의 과거 24개월과 미래 24개월이다. 2026-10-21 자료라면 **2024-10-21–2028-10-21**을 보여 준다. 이는 표시 범위이며, 2050년까지 계산한 조건부 미래 경로는 보존한다. 4년/기본 범위 복원, 명시적인 장기 전망/전체, 사용자가 확대·이동한 범위를 구분한다. 기존 공유 URL의 `span`을 존중한다.

좌측 지표 목록은 각 항목에 현재 값을 표시한다. `Vol 2.22k BTC`처럼 가격·수익률·거래량을 읽고, 숫자가 적절하지 않은 자료 출처·범례·사건은 출처명·표시 상태·사건/라벨 수를 보여 준다. 미래 거래량은 `가정`과 `BTC/일` 또는 `BTC/주`로 구분한다. 조회하지 않은 봉이나 과거 근거가 없는 지표에 0이나 미래 값을 대입하지 않는다. 최근 전환은 선택 시점까지 **확인된** 전환만 표시한다.

D-day는 `다음 하락 D-88 / 가정 2027.01.18`처럼 두 줄로 정리했다. 7일 유지 조건, 현재 상태 유지 범위, 자료 기준일은 접근성 설명·툴팁·사용자가 직접 연 근거 패널에 남긴다. 실제 시장의 확정 일정으로 표현하지 않는다.

## 모바일

620 CSS px 이하에서 고정 좌우 레일을 접어 가격 차트가 화면 전체 폭을 사용한다. 8개 시간 간격은 네이티브 선택 메뉴로 유지한다. 상단의 **차트 도구**와 **정보와 설정**에서 기존 기능을 연다. 연구 자료·원자료 화면에는 통합 차트 복귀 버튼이 있다. 상세와 지표 라이브러리는 작은 화면에 맞는 패널이며, 화면 안전 영역과 가로 방향도 고려한다.

헤더의 가격·OHLC·거래량을 줄바꿈하고 실제 높이를 관찰해 출처와 지표 목록을 배치한다. 기본 접힌 지표와 간결한 D-day는 같은 높이에 놓는다. 펼친 지표 목록은 높이를 제한해 내부에서 스크롤하며 눈 아이콘과 제거 버튼을 유지한다. 작은 화면의 배경 블러·큰 그림자는 줄였다.

차트에서 한 손가락으로 좌우 이동하고 두 손가락으로 시간축을 확대·축소한다. 제스처마다 금융 모델을 재계산하지 않는다. 축소 후 과거 데이터가 필요하면 같은 간격으로 조회한다. 일반 탭은 값을 고정하며 상세 패널을 자동으로 열지 않는다. 차트 밖의 텍스트/입력과 데스크톱 Ctrl+휠은 브라우저 기본 조작을 유지한다. 구현은 [Pointer Events](https://www.w3.org/TR/pointerevents/latest/)와 [MDN pinch](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events/Pinch_zoom_gestures)의 취소·포인터 추적 계약을 따른다.

모바일 도구 트레이는 Escape/배경 탭으로 닫히고, 열린 동안 키보드 Tab 이동을 보이는 조작 안에 유지한다. 자석 하위 메뉴의 포커스와 상세 패널의 포커스 복원은 별도로 처리한다. 화면 크기 확인용 [미리보기](../dist/mobile-preview.html)는 동일한 실제 페이지를 지정한 CSS viewport의 iframe에 표시한다. 실제 휴대전화 CPU·GPU·터치 장치의 대체 측정은 아니다.

## 자석과 SVG

TradingView의 실제 차트 왼쪽 메뉴에서 약한/강한 자석과 아이콘을 확인하고 [공식 OHLC 도움말](https://www.tradingview.com/support/solutions/43000472715-drawing-points-don-t-snap-to-ohlc-values-correctly/) 및 [임시 Ctrl/Command 동작](https://www.tradingview.com/support/solutions/43000722509-magnet-mode/)과 대조했다. Atlas는 지원하는 두 지점 측정에 실제 OHLC 붙임을 적용한다. 모든 간격에서 쓰며, 선·미래 가정에 없는 OHLC를 만들지 않는다. 세부 임계값과 구현 범위는 [MAGNET_MODE.md](MAGNET_MODE.md)에 명시했다.

도구 SVG는 동일한 viewBox, currentColor, 1.7 선 굵기와 둥근 선 끝을 사용한다. 강한 자석은 작은 화살표로 구별한다. SVG 저장은 명시적인 크기, 차트 제목·선택값·출처·관측/가정 설명을 포함하며 일시적인 십자선·자석 미리보기를 제외한다. 외부 CSS 없이 열 수 있고 휴대전화 폭에서는 텍스트를 줄바꿈한다. TradingView의 [스냅샷 문서](https://www.tradingview.com/charting-library-docs/latest/ui_elements/Snapshots/)는 이미지 저장 동작의 참고 자료이며, Atlas의 SVG 구현이 TradingView의 내부 렌더러와 같다는 주장은 하지 않는다.

## 성능 변화와 한계

- 보이지 않는 기존 비교·타이밍·원자료 페이지는 처음 가격 화면에서 미리 계산하지 않는다. 분석 창도 해당 모드의 설정이 바뀔 때만 다시 그린다.
- 주 차트의 크기 관찰을 한 곳으로 모아 같은 resize 이후 중복 그리기를 제거했다.
- 포인터 이동과 지표 텍스트는 화면 프레임당 한 번 처리한다. 새 날짜가 같으면 값을 다시 포맷하지 않으며, 지표 행 DOM을 매번 만들지 않는다. 닫힌 목록은 텍스트 갱신을 미룬다.
- 날짜→UTC 일수 변환은 검증한 불변 날짜만 최대 32,768개 캐시한다. 가격·모델 결과를 이 캐시에 넣지 않는다.
- 분·시간 확대 구간 조회는 `O(log N + V)`. 밀집 캔들·거래량은 제한된 SVG 경로로 묶고, 실제 선택값은 원본에서 읽는다. 한 화면 최대 6,000개 봉 간격, 간격별 캐시는 최근 창 12,000개 간격과 초기 180개 봉이다. 더 과거로 이동하면 추가 조회하며, 빈 거래 시간은 채우지 않는다. [API 교차 검증과 구현](INTRADAY_HISTORY.md)

같은 자료와 옵션을 별도 Node 프로세스에서 실행한 계산 결과:

| 작업 | 변경 전 | 변경 후 |
|---|---:|---:|
| 128개 샘플 장기 모델 | 798.52 ms | 560.42 ms |
| 거래량 모델 적합 | 192.39 ms | 104.23 ms |
| 기존 타이밍 분석 | 130.37 ms | 48.62 ms |

장기 모델·거래량 적합·거래량 전망의 전체 JSON SHA-256이 변경 전후 같았다. 따라서 계산량을 줄이려고 샘플 수·가격·미래 경로를 바꾸지 않았다. 이 값은 **CPU 계산 단일 실행**이며 실제 기기의 FPS, 페인트 시간, 터치 지연 또는 통계적인 반복 성능 평가가 아니다. [원 기록](data/mobile-calendar-cache-profile.json), [재현 스크립트](../scripts/profile-startup-computation.mjs)

실제 Coinbase 응답으로 1m 180→727봉, 4h 180→363봉 확장을 확인했다. 요청 시각·URL·상태·표본 OHLCV는 [API 검증 기록](INTRADAY_HISTORY_LIVE_VERIFICATION.json)에 있다. API 제한·장애 시 이미 받은 자료를 유지하고 다시 조회할 수 있으며, 무한한 봉을 한꺼번에 내려받는 구조는 아니다.

## 자동 검증

36개 테스트 파일, 정적 참조 검사, 128개 샘플 D-day·사이클 보정 검사, 성능 구조 검사 통과. 실제 일봉 5,544개를 다루는 구조 검사에서 SVG 요소는 94개로 120개 예산 이내다. 분·시간 테스트는 6,000봉을 360/1280px에서 120개 미만의 요소로 그리는지와, 131,072행 중 좁은 창 조회가 70회 미만의 원배열 읽기를 사용하는지 검사한다. 제스처 취소·새 간격의 늦은 응답·빈 데이터·측정값 보존·패널 비자동 열기도 검증한다.

실제 브라우저 화면, 배포된 버전, CI 결과는 배포 검증 완료 후 별도로 기록한다.
