# 비트코인 통합 차트 사용 안내 — v1.14.1

이 화면은 관측 가격, 완료 거래소 캔들, 출처가 있는 미래 경제 가정을 같은 차트에서 읽는 도구다. 기본 **4년**은 최신 관측일의 전후 24개월이며 **장기 전망**·**전체**는 검토한 원문의 마지막 목표 연도인 2050년 말까지 넓힌다. 경제 가정과 자료 출처를 표시하며, 미래 값을 실제 관측으로 취급하지 않는다. [표시 종료일](../dist/long-horizon-forecast.js), [현행 입력·파일 검수와 한계](MOBILE_QA_RECEIPTS_2026-10-24.md), [v1.14.0 모바일 개선 이력](MOBILE_WORKFLOWS_2026-10-23.md)

v1.14에서는 D-day UI를 제거하고 모바일의 가격·여섯 색 범례 묶음을 숨긴다. 좌상단 값 목록과 연구 창은 한정된 차트 영역을 나누어 쓰며, 기간·사건·축·상태는 한 줄 하단에서 조작한다. 이 안내의 현재 사용법과 §10의 이전 버전 검증을 구분한다.

## 1. 처음 사용할 때

1. **관측과 가정을 구분한다.** 관측 가격선·완료 캔들과 금색 미래 점선을 구별하고, 선택 정보에서 출처·UTC·관측/가정을 읽는다. 데스크톱 범례는 우측 상단이며 모바일 범례 묶음은 숨긴다.
2. **간격과 선·캔들을 고른다.** 분·시간 화면은 완료된 거래소 봉, 일·주 화면은 관측 역사와 장기 미래를 함께 보여 준다. 거래량은 새 접속·초기화에서 숨김이며 필요한 때 눈 아이콘으로 켠다. 저장한 명시적 표시 설정은 유지한다.
3. **날짜를 눌러 값을 고정한다.** 클릭만으로 우측 패널을 열지 않는다. 상세가 필요할 때 우측 데이터 아이콘을 누른다. 실제 봉의 O/H/L/C와 미래 가정의 값을 구분한다.
4. **날짜와 가격 위치를 옮긴다.** 최대 축소나 자료가 없는 날짜에서도 이동할 수 있다. 기본 4년으로 돌아가려면 맞춤 또는 `0`을 사용한다. `Alt+G`는 UTC 날짜·시각이나 시작–끝 기간을 입력한다.
5. **인디케이터 라이브러리에서 지표를 관리한다.** 항목을 다시 누르면 제거, 눈은 숨김·복원, 작은 화살표는 데스크톱에서 이름·값 전체 접기·펼치기다. 뷰포트 폭 620px 이하에서는 모바일의 제목·값 목록이 항상 접혀 있다. 이 폭에서는 `indicator-list=open` 링크·템플릿·초기화도 펼치지 않으며, 접힘은 지표 자체의 표시/숨김·추가/삭제와 별개다. 펼친 목록의 높이는 작게·보통·넓게로 조절한다.
6. **모바일의 가림을 직접 조절한다.** 상단 **차트 도구**와 **정보와 설정**은 필요한 트레이를 연다. **차트 집중 보기**로 정보와 연구 창을 잠시 감추고 **정보 다시 표시**로 복원한다. 추가·숨김·접힘 상태를 바꾸는 조작은 아니다.
7. **저장 목적에 맞는 창을 연다.** **작업 화면·공유**는 설정과 날짜 범위를 보관한다. **차트 내보내기**는 PNG·SVG·CSV의 자료·범위를 고른다. 모바일 저장·공유는 해당 탭으로 바로 열며 처음부터 입력창에 초점을 주지 않는다.

| 위치 | 현재 제공하는 도구 |
|---|---|
| 상단 | 8개 간격, 선·캔들, 인디케이터·설정·즐겨찾기·템플릿, 미래 가정, 기간선, 실행 취소·다시 실행, 저장·내보내기 |

## 2. 상단 간격과 선·캔들

| 간격 | 실제 자료와 집계 | 미래 표시 |
|---|---|---|
| **1m · 5m · 15m** | Coinbase BTC-USD의 해당 분봉 OHLCV | 없음 |
| **30m** | 연속된 실제 15분봉 2개 | 없음 |
| **1h** | 실제 1시간봉 OHLCV | 없음 |
| **4h** | 연속된 실제 1시간봉 4개 | 없음 |
| **1D** | 선은 Coin Metrics 일말 값, 캔들은 제공 범위의 Bitstamp 완료 일봉 | 장기 미래 점선 |
| **1W** | 선은 주별 마지막 일말 값, 캔들은 월~일 실제 일봉 7개 | 장기 미래 점선 |

모든 봉 시각은 UTC다. 집계는 첫 시가, 실제 최고·최저, 마지막 종가, 거래량 합계를 사용한다. 구성 봉이 빠지거나 기간이 완료되지 않았으면 해당 집계 봉을 만들지 않는다. 주봉은 일요일에 그리며 선택 정보는 월~일 범위를 보여 준다. 분·시간 선은 같은 실제 봉의 종가를 연결하며 진행 중인 봉·없는 구간을 채우지 않는다. [OHLC 계약](OHLC_CHART_METHOD.md), [집계](../dist/ohlc-data.js)

일·주 캔들 화면에서 완료 거래소 봉이 없는 관측 구간은 Coin Metrics 일말 가격선으로 남긴다. 거래소 제공 범위 이전뿐 아니라 **마지막 완료 주봉 이후의 부분 주**에도 적용한다. 두 종류가 함께 보이면 관측 캔들·관측 가격선과 각 자료 종료일을 함께 표시한다. 일말 가격 하나를 O/H/L/C로 복제하거나 미래 가정을 캔들로 만들지 않는다. 장기 모형 관측 종료일 이후의 거래소 봉도 이 화면에 섞지 않는다. [가격 차트](../dist/atlas-price-chart.js), [범례·출처](../dist/price-legend.js)

### 처음 캔들로 바꿀 때

**장기 전망·전체에서 처음 캔들로 전환**하고 직접 지정한 범위가 없으면 일봉은 마지막 일말 관측의 180일 전~30일 후, 주봉은 560일 전~30일 후로 좁힌다. 기본 4년·가까운 6개월·사용자가 직접 정한 범위는 유지한다. 캔들 전환이 2050년 경로를 삭제하지 않으며 장기 전망으로 다시 넓힐 수 있다. [첫 전환 규칙](../dist/lab-view.js)

작은 화면은 8개 간격을 선택 메뉴로 제공한다. O/H/L/C·Vol 읽기는 필요한 만큼 줄바꿈하며 출처를 함께 읽는다. 거래량 도형을 숨겼다고 실제 봉의 거래량 데이터가 없어지는 것은 아니다. 간격 전환은 UTC 중심·표시 기간·원 USD 수동 가격 범위를 보존하며 봉 수 제한으로 기간이 조정되면 안내한다.

## 3. 하단 기간과 가격축

**상단 간격은 자료의 시간 단위**, **하단 기간은 보이는 날짜 범위**다.

| 하단 조작 | 의미 |
|---|---|
| **4년** | 최신 관측일 전후 24개월·기본 화면 |
| **6개월** | 계산 기준일의 45일 전부터 6개월 뒤까지 |
| **장기 전망** | 마지막 일말 관측의 1년 전부터 현재 원문 목표 종료일 2050-12-31까지 |
| **전체** | 전체 관측 이력부터 장기 전망 종료일까지 |
| **맞춤·0** | 직접 지정한 범위를 해제하고 해당 화면의 기본 범위로 복원 |
| **달력·Alt+G** | UTC 날짜·시각 또는 시작–끝 기간으로 이동 |
| **사건** | 현재 범위의 주요 사건 목록을 위로 펼침. 검색·전체 목록과 출처로 이동 |
| **더보기** | 표시 기간·UTC·갱신 상태, 기본 범위 복원과 추가 조작 |

일·주 화면은 최대 축소 상태와 자료 범위 밖에서도 이동한다. 빈 날짜에는 없는 가격을 만들지 않고 축·이동·복원 조작을 유지한다. 분·시간 화면은 축소·과거 이동 시 실제 완료 봉을 추가 조회하며 한 화면의 최대 6,000봉 간격 제한을 따른다. 일·주 장기 기간 버튼을 분·시간 화면에 적용하지 않는다. [탐색](../dist/chart-navigation.js), [화면 연결](../dist/lab-view.js)

**로그**는 같은 배수, **선형**은 같은 가격 차이를 같은 높이로 표시한다. **Auto는 버튼**이며 표시 범위의 가격축 자동 맞춤을 복원한다. 가격축을 끌면 수동 범위, 가격축 더블클릭은 Auto로 돌아간다. 시간축 드래그는 날짜 간격을 조절한다. 가격축 메뉴의 반전·가격 자료만 자동 맞춤도 구분한다. [가격축](../dist/price-axis.js)

단위는 **USD · 최근 관측=100 · 표시 시작 대비 % · 표시 시작=100**이다. 표시 시작 모드의 기준은 현재 화면에서 처음 표시할 수 있는 가격이므로 이동하면 달라진다. 수동 범위·저장한 측정 좌표와 관측 CSV의 원가격은 USD로 유지한다. [단위 변환](../dist/price-display.js)

## 4. 실제 값·가정 값·범례

데스크톱 우측 상단은 SVG 견본으로 **관측 가격선·관측 캔들·미래 가정·가정 범위·고점·저점**을 구분한다. **폭≤620px, 또는 폭≤950px이면서 높이≤500px에서는 가격·여섯 색 범례 묶음을 숨긴다.** 색 원·기간선 자체와 가격/OHLC·출처의 표시 상태를 제거하지 않으며 넓은 화면으로 돌아오면 저장한 범례 설정을 따른다. [범례](../dist/price-legend.js), [반응형 규칙](../dist/cycle-milestones.css)

| 선택 자료 | 읽는 의미 |
|---|---|
| Coin Metrics 일말 값 | 관측 종가·해당 자료의 직전 값 대비 변화 |
| Bitstamp·Coinbase 완료 봉 | 봉 종가·O/H/L/C·거래량·직전 봉 종가 대비 변화. 이전 봉이 없으면 비교값 없음 |
| 미래 점선 | 선택한 경제 가정과 역사 잔차를 합친 한 가지 조건부 경로 |
| 미래 가치평가 기준 | 원문 또는 자체 혼합·스트레스 가정의 기준값 |
| 변동성 가정 | 경로 생성에 넣은 크기. 만들어진 경로에서 계산한 변동성과 구분 |

관측 종가는 실시간 현재가가 아니다. Coin Metrics 지수와 단일 거래소의 종가는 출처가 다르며 값 차이만으로 오류라 단정하지 않는다. 일말 관측 종료일과 완료 주봉 종료일도 서로 다를 수 있다. 실제 저장 자료의 예와 혼합 표시 규칙은 [v1.14 가격 설명](MOBILE_WORKFLOWS_2026-10-23.md#3-현재-화면에서-달라진-사용법)에 기록한다.

미래 음영은 **경제 가정 범위**이며 10–90% 분위수나 미래 결과의 80%를 포함하는 확률구간이 아니다. 같은 잔차 경로에 다른 경제 가정을 적용한 차이를 보여 준다. 기관 목표 연도를 연말에 놓는 것은 표시 규칙이며 그날의 고점·저점을 뜻하지 않는다. [모형 범위](MODEL_SCOPE.md)

### 사이클 원·기간선과 보정 띠

CYCLE TOP·PIT STOP·FIRST TOP·ATH·MID-TOP·BOTTOM의 실제 날짜·가격을 색 원으로 표시한다. 원과 기간선의 실선은 사후 기준, 점선은 잠정·가정 기준이다. 이미 관측된 가격에서도 잠정 선정 규칙을 썼으면 점선일 수 있다. 가격 그래프 하단 기간선의 높이는 주석 배치이며 가격 수준이 아니다. 확대해도 하단에 남고, 기간 선택은 정확한 두 끝점과 날짜를 강조한다. 상단 **기간선 → 전체 사이클·관계 필터·숨기기/보이기**, 선택 후 **전체 구간 보기**로 읽는다. [정의와 원본 이미지](CYCLE_MILESTONES.md)

사이클 보정 띠는 해당 날짜까지 관측한 정보에서 계산한다. 빨강은 단축 가정, 초록은 기준 부근, 파랑은 연장 가정, 회색은 근거 부족이며 매매 신호가 아니다. 새 자료에 따른 보정·미래 단계 계산은 유지하지만 **D-day 카드·지표·클릭 진입점은 v1.14에서 제거**했다. [보정 모형](CYCLE_CALIBRATION_MODEL.md)

## 5. 클릭·키보드·터치와 우측 패널

포인터 이동은 임시 십자선과 읽기 값을 갱신한다. 클릭·키보드 선택은 날짜·값을 고정하고 우측 패널의 기존 열림·닫힘을 유지한다. 선택 상세가 열려 있으면 내용만 바꾸며 다른 패널을 덮지 않는다. 데이터 아이콘이나 사건·분석 요약은 명시적으로 설명을 요청하므로 상세를 연다. [선택 정책](../dist/inspection-policy.js)

가로 십자선과 가격축 값은 포인터 높이를, 선택 점과 O/H/L/C는 해당 날짜·봉 원관측을 따른다. 보조 연구 영역에 가짜 달러 커서를 표시하지 않는다. 최근가격 표식도 실제 마지막 완료 봉의 시각·출처를 포함하며 진행 중인 실시간 호가가 아니다. [십자선](../dist/chart-hover.js)

| 조작 | 지원 동작 |
|---|---|
| 클릭·터치 탭 | 날짜·완료 봉 선택 고정. 터치 추적 중 새 탭은 추적 종료 |
| 길게 누르기 | 십자선의 터치 값 추적 시작·드래그로 날짜 이동 |
| C·H·M | 십자선·두 축 이동·두 점 측정. 지원하는 8개 간격 모두 |
| 좌우 방향키·Home/End | 이전·다음 또는 표시/조회 범위 처음·끝의 자료 선택 |
| 휠·−·+·두 손가락 | 표시 범위 확대·축소. 휠·두 손가락 탐색은 H/십자선에서 사용하며 M은 두 지점 선택용. 물리 다중 터치 수락은 별도 |
| 가격축·시간축 드래그 | 가격 범위 또는 시간 간격 조절 |
| Ctrl/⌘+K·Alt+G | 명령 검색·날짜/기간 이동 |
| Ctrl/⌘+Z·Ctrl/⌘+Shift+Z | 명시적 화면 변경의 실행 취소·다시 실행 |

터치의 일반 좌우 드래그는 날짜를 옮기고 Auto를 유지하며 **H 이동**에서 상하좌우를 옮긴다. 도구 트레이의 **터치 안내**는 닫거나 다시 열 수 있고 현재 도구·자석 상태를 함께 표시한다. M에서 두 손가락 탐색을 하려면 H/십자선으로 전환한다. 20개 합성 회귀, AVD의 실제 단일 터치·CDP 두 접점, 실물 검증의 차이는 [최신 QA 기록](MOBILE_QA_RECEIPTS_2026-10-24.md)과 [이전 모바일 보고서](MOBILE_WORKFLOWS_2026-10-23.md#5-제스처-회귀-20개가-확인하는-것)에 구분한다.

두 점 측정은 시간·가격 차이·변화율을 읽는다. 자유 가격 또는 약한/강한 자석의 실제 O/H/L/C를 사용하며 미래 점을 포함하면 가정 포함으로 표시한다. 완료 측정은 **저장한 연구 측정**에서 원좌표·출처·메모와 함께 보존·편집·잠금·숨김·삭제한다. 임시 측정 제거와 저장 자료 삭제는 별도다. [측정 저장](../dist/research-annotations.js)

900 CSS px보다 넓으면 우측 패널은 도킹하며 폭을 조절한다. 작은 화면은 차트 위에서 열고 닫으면 진입 조작으로 초점을 돌린다. 긴 설명은 패널 안에서 읽는다. [패널 연결](../dist/viewport-workspace.js)

## 6. 경제 가정과 장기 근거

**미래 가정**에서 통화·금 기준·채택 확대·완만한 채택·낮은 채택·수요 훼손을 고른다. WisdomTree의 기준·높음·낮음 발표 가격을 보존하고, 완만한 채택은 낮음·기준의 기하평균, 수요 훼손은 자체 스트레스다. 시나리오 이름에 발생 확률을 부여하지 않는다. [시나리오 구현](../dist/long-horizon-forecast.js)

**모델과 검증**에서 장기 계산·공급 일정·연도별 가격·변동성·기관 원문과 한계를 읽는다. 가격 평가, 금과의 동조화, 변동성 하락은 서로 다른 주장이다. 가격의 4년 주기가 끝나는 확정 연도나 금의 변동성에 반드시 도달하는 연도는 제시하지 않는다. 새 장기 모형의 정확도를 과거 3년 모형 평가로 대신하지 않는다. [장기 리서치](LONG_HORIZON_RESEARCH.md), [모델 범위](MODEL_SCOPE.md)

## 7. 지표·연구 창·즐겨찾기

가격은 상시 표시하며 나머지 다섯 연구는 인디케이터에서 추가한다. 좌상단 목록은 추가한 지표의 이름·선택값을 한 줄로 읽는다. 가격/OHLC·출처·범례는 별도의 표시 항목이며 관리 행에 같은 값을 중복하지 않는다. 긴 행은 줄임표와 전체 설명, 긴 목록은 내부 스크롤을 제공한다. [목록 UI](../dist/indicator-workbench.js)

| 조작 | 정확히 바뀌는 것 |
|---|---|
| 화살표·**차트의 지표 이름·값 펼치기** | 모든 이름·값 행의 접힘. 대표 한 행을 남기지 않으며 도형은 유지 |
| 눈·**지표 일괄 숨김/표시** | 해당 지표 도형·연구 창의 표시. 일괄 동작도 가격/OHLC·출처·범례 설정은 유지 |
| 지표 설정의 값 표시 | 값 읽기만 숨김·표시. 실제 그래프는 유지 |
| ×·인디케이터 항목 재선택 | 해당 지표를 추가 목록에서 제거 |
| 목록 **높이** | 현재 화면의 스크롤 영역을 작게·보통·넓게 조절 |
| 연구 창 최소화·눈·× | 각각 제목만 남김·일시 숨김·추가 목록에서 제거 |
| **차트 집중 보기** | 정보·목록·연구 창을 일시 감춤. 정보 다시 표시로 원상 복원 |

뷰포트 폭 620px 이하에서는 모바일 지표 제목·값 목록을 항상 접는다. `indicator-list=open` 링크·작업 화면·템플릿·초기화도 이 정책을 열지 않으며, 지표 자체의 표시/숨김·추가/삭제와 별개다. 지표 관리는 인디케이터 라이브러리에서 한다. 데스크톱에서는 전체 접기 설정을 `indicator-list=open/closed`와 작업 화면·템플릿에 보존한다. 예전 대표 지표 1개 정책은 사용하지 않는다. 거래량은 fresh/reset에서 추가됨·숨김이며 명시적 사용자 표시 설정이 우선한다. 옛 링크·템플릿의 D-day 항목은 제거하되 다른 지표 설정은 유지한다. [상태](../dist/indicator-state.js)

설정은 실제 지원하는 값·축 숫자·선 굵기·투명도·채움·표시 간격·기존 계산 입력만 제공한다. 일·주 전용 지표를 분·시간 화면에서 선택해도 상태를 지우지 않고 지원 간격을 안내한다. 값이 없는 경우 사유를, 미래 계산은 가정을 표시한다. [설정 정의](../dist/indicator-settings.js), [값의 의미](../dist/indicator-readouts.js)

연구 창은 독립 축을 유지하며 순서 이동·최대화/복원·경계 높이 조절을 제공한다. 경계에 초점을 두고 방향키·Home/End로도 높이를 바꾼다. 작은 화면은 목록과 공유한 높이 안에서 스크롤하고, 짧고 넓으면 두 영역을 나란히 놓는다. 여러 창은 고정된 **연구 창** 선택과 **이동**으로 접힌 제목·복원에 접근한다. 창을 이동하려고 자동 펼치기·숨김 해제를 하지 않는다. [연구 창](../dist/analysis-dock.js), [공간 배분](../dist/compact-chart-layout.js)

| 연구 | 읽을 내용 |
|---|---|
| **4년 비교** | 저점·반감기·달력 구간 출발값=100의 가격 비교 |
| **구간 길이** | 큰 상승·하락의 일수와 내부 신고가·반등·횡보·되돌림 |
| **고점권 도달** | 최종 최고값 95% 첫 진입부터 최고값까지의 시간·낙폭 |
| **월·분기** | 수익률·최대 하락·변동성·새 최고가 일수와 미완료 기간 |
| **CryptoCon 검증** | 공개된 최초·수정 주장과 실제 날짜·가격 |

큰 국면 경계와 최종 최고값은 사후 정보다. 고점권 첫 진입부터 오래 걸렸다고 그동안 계속 고점권이었다는 뜻은 아니다. [시장 구조 방법](MARKET_STRUCTURE_METHOD.md)

즐겨찾기의 별은 즐겨찾기만 바꾸며 지표를 추가하지 않는다. **템플릿**은 이 브라우저에 최대 8개 저장하고 지표 구성·설정·데스크톱 목록 접힘·연구 창 순서·높이·최소화 등을 복원한다. 모바일 이름·값 목록은 템플릿 적용 뒤에도 항상 접힌다. 가격 간격·날짜 범위·미래 가정은 바꾸지 않는다. 명시적 공유 설정을 개인 즐겨찾기가 덮어쓰지 않는다. [개인 설정](../dist/indicator-preferences.js)

모바일 정보 트레이의 **통합 차트·리서치 자료·원자료**로 각 페이지를 고른다. 자료 페이지의 복귀 버튼으로 차트에 돌아온다. 보관용 이전 분석 도구는 `?page=compare&legacy=1`로 연다.

## 8. 조회 시각·완료 봉·저장 자료

마지막 관측·봉 시각, 조회 시각, 연구 검토일은 서로 다르다. 검증한 저장 자료를 열었다고 수집 시각을 현재 시각으로 바꾸지 않는다. 간격을 바꿀 때 늦은 이전 응답이 새 화면을 덮지 않도록 처리한다. [자료 제어](../dist/market-data-controller.js)

분·시간 초기 표시는 검증한 저장본을 우선 사용하며, 새로고침으로 새 완료 봉 조회를 시도한다. 과거 이동 시 실제 봉을 추가 조회한다. 진행 중인 봉의 틱 갱신·자동 폴링을 제공하지 않는다. 조회 실패 시 이전 유효 자료와 그 시각을 유지하며 자료가 없으면 실패를 표시한다. [OHLC 방법](OHLC_CHART_METHOD.md)

장기 일말 자료는 번들·유효 저장본을 먼저 읽고 새 완료 자료 갱신을 시도한다. GitHub Actions는 하루 네 번 일말 자료·거래소 저장 봉과 사이클 산출물을 검증·갱신하도록 구성돼 있다. 열린 페이지는 보이는 상태에서 6시간 간격으로 공개 스냅샷을 확인하며 가격이 바뀌었을 때 모형을 다시 계산한다. 실제 예약 실행은 지연될 수 있으며 과거 연구·검증 보고서를 자동으로 고쳐 쓰지 않는다. D-day UI의 날짜별 갱신은 현재 사용법에 포함하지 않는다. [브라우저 갱신](../dist/app.js), [갱신 작업](../.github/workflows/refresh-data.yml)

## 9. 저장·공유와 내보내기

**Ctrl/⌘+K**는 명령 검색을 연다. 간격·지표·캔들·저장·CSV를 검색하고 방향키·Enter·Escape로 조작한다. 모바일 **정보와 설정 → 작업 화면·공유**는 저장·공유 탭을 직접 열고 첫 초점은 닫기에 둔다. 입력이 필요할 때 직접 선택한다. 작업 화면·공유, 내보내기와 인디케이터 검색 창은 가상 키보드가 열리면 가시 viewport 높이에 맞춘다. 인디케이터 검색은 공간이 짧아지면 창 전체를 스크롤하고, 키보드를 닫으면 원래 높이와 목록 스크롤로 복원한다. [작업 화면](../dist/workspace-tools.js), [viewport 대응](../dist/dialog-viewport.js)

이름 있는 작업 화면은 이 브라우저에 최대 8개 보관한다. 날짜·시간 범위, 간격·선/캔들·가격 단위·축 설정·수동 가격 범위, 미래 가정과 지표·연구 창 설정을 복원한다. 저장 당시 시장 가격을 고정한 자료 스냅샷은 아니다. 선택 커서·진행 중 측정·열린 패널·집중 보기·목록 높이 편의 설정은 공유하지 않는다. 저장한 연구 측정은 브라우저에 별도 보관하고 실행 취소 기록은 현재 탭에만 남는다. [저장 계약](../dist/workspace-state.js), [범위별 설명](RESEARCH_WORKFLOWS_2026-10-23.md#6-저장과-복구의-경계)

공유 링크는 같은 범위·설정을 연다. 다른 계정·기기 동기화나 자동 외부 전송은 하지 않는다. 복사 권한이 없으면 링크를 직접 복사하도록 안내하고, 저장소 실패를 알린다. 단독 HTML은 웹 링크 공유를 지원하지 않는다.

**차트 내보내기**는 형식·자료·범위를 고른 후 미리보고 저장한다. 모바일에서도 제목·닫기·저장 조작은 스크롤 본문과 분리한다.

| 내보내기 | 자료와 범위 |
|---|---|
| **PNG·SVG** | 현재 가격 또는 현재 가격+보이는 펼친 연구 창. 연구 창은 원 순서·독립 축·출처로 수직 합성 |
| **Coin Metrics 관측 CSV** | 보이는 범위의 원 일말 가격. 화면에서 줄인 표본이나 주봉으로 바꾸지 않음 |
| **Bitstamp·Coinbase OHLC CSV** | 선택한 실제 완료 일·주·분·시간 자료. 현재 조회하지 않은 봉·미완료 봉을 만들지 않음 |
| **조건부 경로 CSV** | 미래 가정임을 표시한 별도 자료 |
| **개별 연구 CSV** | 해당 연구의 실제 계산 행·독립 축·단위·출처 |

관측 CSV는 화면 %·지수 단위를 적용하지 않은 원 USD이며 UTC·출처·간격·실제 조회/저장 범위·행 수를 명시한다. 이미지·CSV는 창을 열 때의 상태를 고정하며 이후 차트 이동이 그 미리보기를 바꾸지 않는다. 비어 있거나 오류인 자료는 저장하지 않는다. 이미지 복사는 브라우저가 지원하고 권한이 허용될 때 제공한다. [내보내기](../dist/chart-export-workbench.js), [v1.13 계약과 검증 한계](RESEARCH_WORKFLOWS_2026-10-23.md#7-내보내기와-자료-정체성)

## 10. 구현 검증과 이전 기록

현재 사이트는 자체 SVG 구현이다. TradingView의 사용 방식을 참고했으나 시세·주문·브로커를 연결한 제품이나 TradingView 모바일 전체 복제는 아니다. v1.14.1 후속 검수는 **656개 테스트 통과**, Chrome 156 AVD의 실제 검색 IME·두 연구 창 조작과 수정 후 PNG 픽셀·파일별 수신을 구분해 [후속 QA 기록](MOBILE_QA_RECEIPTS_2026-10-24.md)에 남긴다. 실물 Galaxy·iOS·TalkBack과 전수 창 조합을 완료로 간주하지 않는다. 자동 검사는 예측 정확도나 물리 다중 터치 수락의 증거가 아니다.

v1.14.0 당시 G01–G08 적용, 20개 합성 제스처 회귀, **73개 파일·684개 케이스/명명된 검사**와 CSS·수신 PNG의 범위는 [이전 모바일 개선 보고서](MOBILE_WORKFLOWS_2026-10-23.md) §7의 고정 이력이다. 당시와 현재 검사의 분모를 합산하거나 동일한 테스트 수로 비교하지 않는다. CI·병합·Pages도 각 변경의 실제 커밋·체크·배포 결과로 구분한다.

이하 수치·화면은 명시된 이전 버전의 고정 이력이다. D-day·대표 지표 1개·기본 펼침·옛 범례 위치를 현재 UI 설명으로 사용하지 않는다. 원본 [모바일 조사](research/tradingview-mobile-2026-10-23/README.md)도 당시 Android 에뮬레이터 관찰로 보존한다.
