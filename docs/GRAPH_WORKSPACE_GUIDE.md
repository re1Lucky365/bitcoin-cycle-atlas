# 비트코인 통합 차트 사용 안내

이 화면은 **현재 위치를 확인하고, 과거 사이클과 미래 가정을 같은 그래프 영역에서 비교하는 도구**다. 처음에는 그래프와 간결한 상단 조작만 보여 준다. 현재 가격은 가격축에서, 반등·조정 후보와 남은 일수는 차트 안에서, 갱신 시각은 상단에서 확인한다. 선택한 값과 출처, 계산식, 검증표는 필요할 때 **하나의 우측 패널**로 연다. 상단의 큰 상태·D-day 카드와 하단 정보 영역은 두지 않는다. 기본 화면은 문서 스크롤 없이 뷰포트에 맞춘다. 화면을 단순하게 바꾸면서 기존 가격 자료와 금융 모형의 계산은 유지했다. [화면 구성](../dist/index.html), [통합 화면 연결](../dist/lab-view.js), [우측 패널](../dist/viewport-workspace.js)

## 1. 처음 사용할 때: 세 단계

1. **‘가격과 미래’에서 실선과 점선을 구분한다.** 흰 실선은 실제로 수집한 가격이고 금색 점선은 선택한 가정으로 만든 한 가지 미래 예시다. 기본 화면은 최근 1년과 앞으로 3년을 함께 보여 준다.
2. **궁금한 날짜를 누른다.** 우측 패널에서 날짜, 가격, 이전 최고가 대비 하락폭, 가격 흐름을 확인한다. 미래 구간을 고르면 ‘가정’이라는 구분이 붙는다. 패널 제목 아래의 날짜 입력, 이전·다음 고저점, 최근 관측 아이콘으로 선택을 바꾼다. 패널을 닫으면 차트가 다시 전체 폭을 사용한다.
3. **확인할 질문에 맞춰 왼쪽 위 차트 아이콘을 누른다.** 우측 패널에서 그래프 종류를 고르면 그래프가 바뀌고 패널이 닫힌다. 사이클의 가격 모양은 ‘4년 비교’, 기간이 짧아졌는지는 ‘구간 길이’, 고점 부근에 먼저 도착했는지는 ‘고점권 도달’, 월별 낙폭은 ‘월·분기’에서 확인한다. 설정이 복잡해졌다면 표시 설정의 ‘처음 화면’을 누른다.

차트 안의 **‘반등 후보’ 또는 ‘조정 후보’와 남은 일수 표시**를 누르면 해당 전환 후보 구간이 확대되고, 우측 패널에 중앙 날짜와 전체 후보 날짜 범위가 열린다. D-day는 시장이 반드시 움직이는 날짜가 아니라 여러 예시의 첫 전환 시기를 요약한 값이다. [가격 그래프 선택·이동](../dist/atlas-price-chart.js), [D-day와 초기화 동작](../dist/lab-view.js)

## 2. 여섯 가지 그래프에서 읽을 내용

| 그래프 | 무엇을 비교하나 | 읽을 때 구분할 점 |
|---|---|---|
| 가격과 미래 | 실제 과거 가격, 앞으로 3년의 조건부 예시, 고저점, 이전 최고가 대비 하락폭 | 실제 가격과 미래 가정, 대표 경로와 여러 경로의 요약을 구분한다. |
| 4년 비교 | 저점·반감기·달력 4년을 출발점으로 맞춘 가격 흐름 | 출발 가격을 100으로 환산한다. 같은 가로 위치라도 실제 달력 날짜는 서로 다르다. |
| 구간 길이 | 저점→고점과 고점→다음 저점까지 걸린 실제 일수 | 완료된 구간, 초기 자료가 부족한 구간, 최신 저점 후보를 구분한다. |
| 고점권 도달 | 최종 관측 최고값의 95%에 처음 도달한 날과 최고값 날짜 | 최고값을 나중에 알아야 계산할 수 있는 사후 비교다. |
| 월·분기 | 기간 수익률, 최대 하락폭, 가격 흔들림, 새 최고가 일수 | 끝나지 않은 월·분기는 일부 날짜만 관측한 값이다. |
| CryptoCon 검증 | 최초·수정 전망, 근접 기준별 선행일, 목표 가격 대비 결과 | 본인 공개 글, X 색인, AI 생성 요약, 보도를 구분하며 계정 전체 적중률로 환산하지 않는다. |

위 비교는 [관측 자료 그래프 모듈](../dist/atlas-analysis.js)과 기존 [시장 구조 계산](../dist/market-structure.js), [고점권 분석](../dist/peak-zones.js)을 사용한다. 그래프를 그리기 위해 실제 가격이나 과거 날짜를 가정에 맞게 수정하지 않는다.

### ‘구간 길이’에서 내부 흐름까지 보기

‘비교할 흐름’에서 다음 세 가지를 고를 수 있다.

- **전체 상승·하락 기간:** 큰 상승 구간과 하락 구간을 막대 길이로 비교한다.
- **상승장 안의 반복 흐름:** 상승장 내부의 신고가 발견, 반등, 되돌림, 횡보 등의 실제 순서를 색 띠로 본다.
- **하락장 안의 반복 흐름:** 하락장 내부에서 반등과 재하락이 어떻게 반복되었는지 같은 방식으로 본다.

색 띠의 가로 길이는 실제 일수다. 사이클마다 모든 띠를 같은 폭으로 늘리지 않으므로, 전체 기간과 내부 구간의 길이가 함께 비교된다. 한 날짜는 하나의 상태로만 분류한다. 구간을 누르면 상태별 합계와 관측 경계를 읽을 수 있다. 분류에는 해당 날짜까지 알려진 정보를 사용하지만, 큰 상승장·하락장의 시작과 끝은 사후 기준이다. ‘저점 형성 조건’이라는 이름만으로 최종 저점을 확정하지 않는다. [내부 흐름의 경계와 분류](../dist/atlas-analysis.js), [국면 정의](./MARKET_STRUCTURE_METHOD.md)

### ‘고점권 도달’에서 횡보와 조기 진입 구분하기

동그라미는 95% 구간에 처음 들어간 지점, 사각형은 최고 일말 가격 지점이다. 두 지점 사이의 일수는 **고점권 첫 진입이 최고값보다 얼마나 앞섰는지**를 보여 준다. 그 사이 내내 횡보했거나 계속 95% 위에 머물렀다는 뜻은 아니다. 선택 정보의 ‘첫 도착 이후 최대 하락’도 함께 살펴본다. 종가 기준 결과는 장중 최고가 기준 결과와 날짜가 다를 수 있다. [고점권 그래프와 선택 정보](../dist/atlas-analysis.js), [제공자·가격 정의 대조](./STRUCTURE_CROSS_VALIDATION.md)

### ‘월·분기’에서 작은 구간 확인하기

기본 화면은 최근 월 또는 분기 구간을 보여 준다. ‘2010년부터 전체’로 바꾸면 전체 관측 기간을 한 축에서 볼 수 있다. 막대를 누르면 해당 기간의 수익률, 최대 하락폭, 가격 흔들림, 새 최고가 일수와 실제 관측 일수를 함께 읽을 수 있다. 이전·다음 이동은 선택한 기간을 바꾸며, 최근 구간 보기에서는 선택 위치에 따라 보이는 창도 이동한다. [기간 그래프](../dist/atlas-analysis.js)

‘가장 크게 떨어진 폭’은 그 기간 안의 앞선 고점에서 이후 저점까지 가장 크게 하락한 비율이다. 전기 마지막 가격도 시작 기준에 포함한다. ‘가격 흔들림’은 일별 수익률의 변동을 연간 기준으로 환산한 수치이며, 상승 방향이나 손실 확률을 뜻하지 않는다. [월·분기 계산 정의](./MARKET_STRUCTURE_METHOD.md)

## 3. 클릭·터치·키보드로 값을 읽는 방법

그래프를 클릭하거나 터치하면 선택한 날짜 또는 구간의 상세가 우측 패널에 열린다. 가격 그래프에서 마우스를 움직이면 **십자선과 축에 붙은 날짜·가격 값**으로 위치를 확인한다. 그래프를 덮는 큰 호버 툴팁은 사용하지 않는다. 자세한 수치와 근거는 선택한 뒤 패널에서 읽는다. 과거의 확인된 고저점은 채운 점, 미래 예시의 고저점은 빈 점으로 구분한다. 점 색만 외우지 않아도 선택 상세에 고점·저점과 실제·예시 여부가 표시된다. [선택 표시 구현](../dist/atlas-price-chart.js), [상세 패널 연결](../dist/viewport-workspace.js)

| 조작 | 가격과 미래 | 과거 비교 그래프 |
|---|---|---|
| 그래프 누르기 | 해당 날짜 선택과 우측 패널 열기 | 경과일, 사이클 또는 기간의 상세 열기 |
| 패널의 이전·다음 아이콘 | 이전·다음 고저점 이동 | 현재 그래프의 비교 단위 이동 |
| 왼쪽·오른쪽 방향키 | 일별은 하루, 주별은 7일 이동 | 경과일 또는 비교 항목 이동 |
| Home / End | 보이는 가격 구간의 처음 / 끝 | 비교 범위의 처음 / 끝 |
| Enter / Space | 현재 선택한 날짜의 우측 패널 열기 | 현재 선택한 비교 항목의 우측 패널 열기 |
| 패널의 날짜 입력 | 입력한 날짜가 보이도록 과거 전체 또는 미래 전체로 전환 | 달력 날짜가 다른 비교에서는 입력창을 숨김 |
| 패널의 최근 관측 아이콘 | 마지막 실제 관측 날짜로 복귀 | 가격과 미래에서 제공 |
| 휠 / −·+ 아이콘 | 포인터 또는 화면 중심으로 확대·축소 | 가격 그래프에서 제공 |
| 가로 드래그 / 좌우 탐색 아이콘 | 보이는 날짜 창 이동 | 가격 그래프에서 제공 |
| Shift+휠 / 가로 휠 | 날짜 창 이동 | 가격 그래프에서 제공 |
| + / − / 0 키 | 확대 / 축소 / 기본 구간 복귀 | 가격 그래프에 초점이 있을 때 |
| Escape / 패널 닫기 아이콘 | 열린 상세 패널 닫기 | 열린 상세 패널 닫기 |

방향키와 Enter·Space는 그래프에 키보드 초점이 있을 때 작동한다. 차트 선택으로 패널이 열려도 초점을 차트에서 빼앗지 않아 방향키로 계속 날짜를 이동할 수 있다. ⓘ·책·도움말처럼 상세를 여는 버튼을 직접 누르면 패널 제목으로 초점을 옮기며, 닫으면 열 때 사용한 요소로 돌아간다. 일반적인 Tab 이동으로 메뉴와 조작 버튼을 선택할 수 있도록 초점 표시를 제공한다. 이 구현만으로 모든 보조기술에서 접근성 적합성이 확인되었다고 주장하지는 않는다. [키보드 처리](../dist/atlas-price-chart.js), [비교 그래프 이동](../dist/atlas-analysis.js), [패널 포커스 처리](../dist/viewport-workspace.js)

### 우측 패널과 화면 크기

우측 패널은 처음에는 닫혀 있다. 데스크톱에서는 약 320 CSS 픽셀을 사용하고, 남은 실제 너비에 맞춰 차트가 다시 그려진다. 닫으면 그 너비를 차트에 돌려준다. **화면 너비 600 CSS 픽셀 이하에서는 차트 위에 겹쳐 표시**하여 작은 차트를 다시 좁히지 않는다. 선택값·계산식·방법론·자료의 근거 상세도 같은 패널을 사용한다. 긴 내용은 패널 안의 이전·다음 페이지로 읽으며 문서나 패널에 별도 스크롤을 추가하지 않는다. [패널 레이아웃](../dist/chart-details-panel.css), [내용과 페이지 분할](../dist/viewport-workspace.js)

상단의 그래프 종류와 표시 설정도 별도 팝오버 대신 이 패널을 연다. 그래프 종류를 고르면 패널이 닫히고, 표시 설정은 값을 바꾸는 동안 열린 상태를 유지한다. 이 두 조작 화면에는 설명용 페이지 넘김을 표시하지 않는다. 패널을 닫거나 다른 상세로 바꾸어도 설정값과 버튼 동작은 유지된다. [조작 요소와 패널 연결](../dist/viewport-workspace.js)

### TradingView에서 참고한 구성

[공식 Supercharts 설정 안내](https://www.tradingview.com/support/solutions/43000748166-how-to-configure-your-supercharts/), [상태줄 문서](https://www.tradingview.com/charting-library-docs/latest/ui_elements/Legend/), [시간축 문서](https://www.tradingview.com/charting-library-docs/latest/ui_elements/Time-Scale/)에서 차트 안의 상태 표시, 가격·시간 눈금, 확대·이동·초기화 도구를 참고했다. 가격축을 오른쪽으로 옮기고, 최근 실제 일말 가격과 십자선의 가격·날짜를 축에 붙였다. 여러 탭 대신 하나의 그래프 메뉴와 문맥에 맞는 설정을 둔다. 이는 자체 SVG 구현이며 TradingView의 라이브러리나 실시간 시세를 사용한다는 뜻은 아니다. 원자료에 없는 시가·고가·저가·거래량을 생성해 캔들처럼 표시하지 않는다.

표시 범위는 관측 시작일에서 미래 표시 종료일 안으로 제한된다. 확대는 최소 30개 UTC 날짜까지 지원하며, 범위 끝에 닿으면 창 길이를 유지한다. 모바일의 기본 핀치와 Ctrl/Meta+휠은 브라우저에 남긴다. [탐색 모듈](../dist/chart-navigation.js), [범위 계산 검증](../tests/chart-navigation.test.mjs).

## 4. D-day와 미래 고저점의 정확한 의미

화면에는 서로 다른 세 종류의 미래 정보가 있다.

| 종류 | 화면에서의 의미 |
|---|---|
| 점선 한 개의 고점·저점 | 선택한 대표 예시 경로 안에서 가격이 꺾인 날짜와 가격 |
| 가까운 고점·저점 후보와 D-day | 여러 예시 경로에서 첫 전환이 발생한 날짜들의 중앙값과 후보 범위 |
| 고점권 도달·큰 주기 고점 기준 | 큰 주기를 구성하기 위해 넣은 시간과 가격 가정 |

첫 전환 날짜의 중앙값과 점선 한 개의 고저점 날짜는 일치할 필요가 없다. 차트 안의 후보 표시나 D-day 수직선이 보인다고 그날 점선이 반드시 꺾이는 것은 아니다. 반등·조정 후보를 선택하면 구간을 확대하고 우측 패널에서 **중앙 날짜, 후보 범위의 시작·끝 날짜, 남은 일수, 전환 뒤 방향 후보, 계산 기준일**을 함께 읽는다. 좁은 차트 안에서 요약한 날짜 범위도 패널에서는 전체 값으로 확인한다. ‘여러 예시의 요약’ 또는 ‘미래 가정’이라는 구분으로 어떤 수치를 읽고 있는지 확인한다. [D-day 계산·선택 정보](../dist/lab-view.js)

고저점 발생일과 확인일도 다르다. 기본 세부 고저점은 반대 방향으로 12% 움직인 뒤 확인한다. 따라서 뒤늦게 확인된 점을 과거 발생일에 표시할 수 있지만, 그 발생 당일에 고저점이 확정되어 있었다고 해석하면 안 된다. 미래 예시의 확인일은 그 예시 안에서 계산된 확인일이다. [방향 전환 정의](./MARKET_STRUCTURE_METHOD.md)

미래 음영은 같은 가정에서 만든 경로들의 날짜별 10·90 분위수 범위다. **실제 미래가 그 안에 들어갈 확률이 80%라는 뜻은 아니다.** 대표 경로가 일부 날짜에서 이 음영 밖으로 나갈 수도 있다. 계산의 재현 가능성과 미래 가격을 정확하게 맞히는 능력은 별개다. [미래 경로와 범위의 정의](./DETAILED_FORECAST_METHOD.md)

## 5. 미래 가정과 표시 설정

‘미래 가정’은 기본적인 4년 흐름, 더 빠른 고점권·고점 도달, 빠른 상승 뒤 긴 횡보, 늦은 고점 전환, 기존 저점 이탈을 비교한다. 고점권에 빨리 도착하는 것과 최종 고점이 빨라지는 것을 별도 조건으로 다룬다. ‘3년 상승·1년 하락’은 이 비교에서 유지하는 큰 가정이며, 가격 자료가 증명한 불변 법칙은 아니다. [시간 가정과 수식](./DETAILED_FORECAST_METHOD.md)

### 모형이 사용하는 입력과 가정

상단에 바로 보이는 **책 아이콘**은 ‘계산식과 검증’ 패널을 연다. 맨 앞에서 모형의 반영 범위를 확인하고, 그 뒤에 날짜표·수식·과거 평가를 읽는다. 자세한 정의는 [현재 모형이 반영하는 것과 반영하지 않는 것](./MODEL_SCOPE.md)에 정리했다.

| 구분 | 현재 반영 범위 |
|---|---|
| 실제 입력 | 날짜와 완료된 UTC 일말 달러 가격. 시가총액·공급량·거래량·ETF 자금 흐름·시장 유동성·온체인 지표는 입력하지 않는다. |
| 가격에서 계산하는 특징 | 로그수익률, 이전 최고가 대비 하락폭, 가격 규칙으로 구분한 국면과 최근 90일의 변동성. |
| 세부 움직임 | 과거 가격의 잔차를 연속 블록으로 재표본화한다. 28일은 블록 길이 분포를 조절하는 설정이며, 모든 블록의 길이나 시장 국면의 학습된 평균 기간이 아니다. |
| 지정한 큰 틀 | 48개월 시계, 명목 36개월 상승·12개월 하락, 고점권 선행·체류 기간, 미래 가격 기준과 마지막 거시 저점의 조건. |

과거 국면의 길이를 비교하는 화면과 미래를 생성하는 모형의 입력은 구분한다. 현재 미래 생성기는 **기간 단축 속도나 국면별 체류시간 분포를 역사에서 학습하지 않는다.** 최근 변동성을 반영하고 같은 조건에서 경로를 재현할 수 있다는 성질도 미래 방향·전환일을 증명하지 않는다. 이 구분과 가격 기준의 설정값, 종점 조건, 검증 표본의 한계를 [모형 범위 설명](./MODEL_SCOPE.md)에서 먼저 확인한다.

‘보기’에서는 최근 1년과 미래 3년, 2010년부터 미래 3년, 가까운 6개월, 미래의 각 1년을 선택한다. 표시한 3년 밖의 큰 주기 기준은 정확한 수치 표에서 확인할 수 있다. 이를 보이는 그래프 안의 실제 전환점처럼 당겨 그리지 않는다.

상단 설정 아이콘을 누르면 우측 패널에 ‘표시 설정’이 열린다. 보기·미래 가정 등 현재 그래프의 선택 조건과 일별·주별, 달러·최근 가격 100, 여러 경로의 범위, 고저점, 이전 최고가 대비 하락폭, 상태 띠, 최근 확인 구간의 되돌림 비율을 모았다. 되돌림 선은 최근 기준점이 확인된 시점부터 표시한다. 과거 전체에 소급해서 당시 이미 알려진 기준처럼 그리지 않는다. 주별 선은 일말 자료를 재집계한 가격이며 장중 캔들이 아니다. ‘그래프 저장’은 현재 그래프를 SVG로, ‘계산 자료 저장’은 미래 계산 결과를 JSON으로 저장한다. [표시 설정 연결](../dist/lab-view.js), [되돌림·가격 단위 표시](../dist/atlas-price-chart.js)

## 6. 관측 종료일, 계산 기준일, 연구 보고서 날짜

**실제 자료 날짜**는 현재 그래프에 사용한 마지막 완료 일말 관측을 뜻한다. 상단의 갱신 시각을 누르면 우측 패널에서 현재 차트의 관측일과 자동 배포 자료의 관측일을 확인할 수 있다. **계산 기준일**은 D-day와 미래 표시 기간을 계산하는 기준이며, 후보 선택 상세와 계산식에서 확인한다. 실시간 거래 가격이나 컴퓨터 시각과 동일한 개념이 아니다. [갱신 상세](../dist/viewport-workspace.js), [후보 선택 정보](../dist/lab-view.js)

사이트는 포함된 자료와 유효한 브라우저 저장 자료를 먼저 읽는다. 마지막 자료가 현재 UTC 날짜보다 하루 넘게 뒤처져 있으면 최신 완료 자료 갱신을 시도한다. 갱신에 성공하면 그래프를 다시 계산하며, 실패하면 기존 자료를 유지한다. 따라서 실제 자료 날짜를 먼저 확인해야 한다. [자료 선택·갱신 구현](../dist/app.js), [제공자 자료 처리](../dist/data-source.js)

발행된 과거 검증표와 연구 문서는 **2026-10-20 UTC 자료로 만든 고정 연구 결과**다. 웹 화면이 더 최근 관측을 받더라도 이 검증표가 새로운 자료와 모든 시나리오의 적중률을 자동으로 다시 측정한 것은 아니다. [연구 스냅샷](./DETAILED_FORECAST_METHOD.md), [발행 검증값](../dist/forecast-validation.js)

## 7. 미래 예시를 평가할 때 확인할 근거

**상단바의 책 아이콘을 바로 누르면** 우측 패널에서 모형의 입력·가정·미반영 변수부터 큰 주기의 기준 날짜, 대표 예시의 고저점 목록, 계산식, 과거 평가, 민감도를 확인할 수 있다. 설정 메뉴를 먼저 열 필요는 없다. [모형의 반영 범위](./MODEL_SCOPE.md), [상세 패널](../dist/viewport-workspace.js)

기존 평가에서 MAPE라는 가격 오차 기준으로는 모든 평가 기간에서 가격을 그대로 둔 기준선보다 오차가 컸다. 장기 2·3년의 평균 절대 로그오차는 더 작았지만, 표본이 작고 척도에 따라 결과가 달라 일관된 예측 우위가 확인되지는 않았다. 음영 범위 역시 실제 결과를 정해진 확률로 포괄하도록 보정되지 않았다. 변동성 등 가정을 바꾸면 첫 전환 후보일이 크게 움직일 수 있다. 차트에는 ‘가정’을 표시하고 이 평가 결과는 근거에서 확인한다. [과거 평가와 민감도](./DETAILED_FORECAST_METHOD.md)

그래프가 정교해졌다는 사실을 미래 날짜의 수학적 증명으로 받아들이지 않는다. 이 도구가 검증 가능하게 제공하는 것은 **주어진 자료와 가정을 어떤 수식으로 변환했는지**, 그리고 **그 방법이 과거에서 어떤 오차를 냈는지**다.

## 8. 리서치와 원자료를 찾는 위치

왼쪽 사이드바의 책 아이콘은 자료 표, 표 아이콘은 일별 원자료다. **상단바의 책 아이콘은 계산식과 검증**이므로 위치로 구분한다. 각 표는 화면 높이에 맞춰 행 수를 정하고 이전·다음 페이지로 이동한다. 제목 검색과 CryptoCon 필터로 좁힐 수 있다. 한 화면 구성을 위해 예전 무한 스크롤을 페이지 이동으로 바꿨다. 제목은 원문을 열고 근거 등급은 우측 패널에 읽는 이유와 한계를 연다. 긴 상세도 패널 안에서 페이지를 넘긴다. 원문 링크는 페이지 분할 뒤에도 사용할 수 있다. A–D는 활용 등급이며 미래 적중 확률이 아니다. [자료 정렬](../dist/evidence-index.js), [표와 상세](../dist/evidence-view.js), [패널 페이지 분할](../dist/viewport-workspace.js)

상단 ⓘ는 선택한 구간의 모든 수치와 출처를 우측 패널로 연다. 작은 화면에서도 같은 필드를 패널 페이지로 확인한다. 기본 화면에는 긴 설명문이나 여러 탭 줄을 두지 않는다. 아이콘에는 접근 가능한 이름과 툴팁을 제공한다. 왼쪽 아래 ⓘ는 그래프 해석, 상단 책 아이콘은 모형 설명·수식·날짜표·평가, 상단 갱신 시각은 현재 차트의 관측일·자동 배포 번들의 관측일·마지막 자동 확인·실행 기록을 같은 패널에 연다. 브라우저가 직접 받은 더 최근 자료와 CI 번들의 날짜를 별도로 표시한다. [상세 종류와 여는 버튼](../dist/viewport-workspace.js)

GitHub Actions는 매일 03:20·09:20·15:20·21:20 KST에 최신 완료 UTC 일말 자료를 확인한다. 지연 가능성이 있어 예약 시각과 실제 확인 시각을 구분한다. 자료가 날짜·연속성·가격 검증을 통과하면 그래프 번들과 배포를 갱신한다. 새 일봉이 없으면 가격은 그대로이고 확인 시각만 갱신한다. 실패하면 마지막 유효 자료를 보존한다. 고정 연구 결과는 자동으로 덮어쓰지 않는다. [갱신 프로그램](../scripts/refresh-data.mjs), [워크플로](../.github/workflows/refresh-data.yml).

기존 세부 분석은 계산식 마지막의 ‘이전 상세 분석 도구’ 또는 `?page=compare&legacy=1`에서 연다. 이 보관용 화면만 문서 스크롤을 사용한다. 기본 여섯 그래프, 자료 표, 원자료 표는 뷰포트 안에서 조작한다.
