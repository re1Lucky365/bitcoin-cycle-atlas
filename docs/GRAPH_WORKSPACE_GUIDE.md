# 비트코인 통합 차트 사용 안내 — v1.10.1

이 화면은 실제 가격, 실제 거래소 캔들, 출처가 있는 미래 경제 가정을 같은 차트 영역에서 읽는 도구다. **기본 ‘4년’은 최신 관측일의 전후 24개월**, ‘전체’는 2010년 관측 시작부터 2050년 말까지, ‘장기 전망’ 버튼은 최근 1년부터 같은 끝까지 표시한다. 2050년은 현재 검토한 원문의 마지막 목표 연도이며 사용자가 N년을 지정하는 조작은 없다. 간격·차트 형식·화면 범위를 바꿔도 장기 모형의 전체 기간을 다시 3년으로 자르지 않는다. [표시 종료일](../dist/long-horizon-forecast.js), [차트 연결](../dist/lab-view.js)

## 이번 버전의 기본 화면

첫 접속은 최신 관측일을 중심으로 과거 24개월과 미래 24개월을 표시한다. 예측 종료일은 바뀌지 않는다. 4년 버튼 또는 기본 범위 복원은 이 표시 창으로 돌아온다. 장기 전망·전체를 누르면 2050년까지 보인다. 지표 목록은 각 항목의 현재 값과 가용 상태를 함께 표시하며, 값은 호버·고정 날짜를 따른다. 모바일은 상단 도구와 더 보기에서 접혀 있던 좌우 기능을 연다. [세부 개선·검증](MOBILE_WORKSPACE_IMPROVEMENTS.md)

## 1. 처음 사용할 때

현재 버전의 변경·성능·검증 범위는 [v1.10 개선 기록](MOBILE_WORKSPACE_IMPROVEMENTS.md)에, 이전 동작의 검수는 [v1.9 통합 검증](INDICATOR_WORKSPACE_VERIFICATION.md)에 기록한다.

1. **흰 실제 가격선과 금색 미래 점선을 구분한다.** 미래 선은 한 가지 조건부 경로다. 오른쪽 아래 범례의 ‘가정 범위’는 경제 가정 사이의 차이를 뜻한다.
2. **상단에서 간격과 선·캔들을 고른다.** 분·시간 간격은 완료된 거래소 자료, 일·주 간격은 과거와 장기 미래를 함께 읽는 화면이다.
3. **궁금한 위치를 눌러 값을 고정한다.** 클릭만으로 우측 패널을 열지 않는다. 상세가 필요할 때 우측 데이터 아이콘을 누른다. 미래 날짜는 가정임을 표시하며, 실제 캔들은 O/H/L/C와 거래량을 보여 준다.
4. **장기 전체로 돌아가려면 하단 ‘장기 전망’을 누른다.** 앞뒤 2년의 기본 표시 기간으로 복원하려면 맞춤 아이콘, 여러 설정을 기본값으로 돌리려면 설정의 ‘처음 화면’을 사용한다.
5. **상단 ‘인디케이터’를 열어 필요한 표시만 추가한다.** 항목을 다시 누르면 제거된다. 좌측 상단 목록의 눈 아이콘으로 숨김·보임, ×로 제거하며 목록도 접을 수 있다. 연구 창은 선택했을 때만 차트 안에 표시하고 사이트 하단 분석 패널은 사용하지 않는다.
6. **우측 상단 D-day는 가정 경로의 다음 상태다.** 실제 미래 전환의 확정 일정이 아니다. 클릭하면 현재 구간의 유지 범위, 다음 7일 이상 상태 후보와 자료 기준일을 읽는다.

| 위치 | 제공하는 도구 |
|---|---|
| 상단 | BTCUSD, 8개 간격, 선·캔들, 검색 가능한 인디케이터 창, 미래 가정, SVG 저장, 설정 |
| 좌측 | 모든 간격의 십자선·이동·측정·자석·확대·축소·복원 |
| 차트 안 | 가격·거래량·날짜·출처와 표시 목록, 시나리오 D-day, 관측일까지의 사이클 보정 띠, 선택한 연구 창, 오른쪽 아래 범례 |
| 우측 | 선택 데이터, 레이어, 모델과 검증, 자료·원문·도움말 |
| 하단 | 일·주 화면의 4년·6개월·장기 전망·전체, 날짜 이동, 로그·선형, 범위 맞춤, 갱신 정보 |

현재 구현은 [도구 모음](../dist/workbench-chrome.js), [가격 차트](../dist/atlas-price-chart.js), [분·시간 차트](../dist/intraday-chart.js)에서 확인할 수 있다. 이 안내는 코드의 동작을 설명하며 공개 배포나 모든 기기의 검수를 완료했다는 기록은 아니다.

## 2. 상단 간격과 선·캔들

| 간격 | 실제 자료와 집계 | 미래 표시 |
|---|---|---|
| **1m · 5m · 15m** | Coinbase BTC-USD의 해당 분봉 OHLCV | 없음 |
| **30m** | 연속된 실제 15분봉 2개를 집계 | 없음 |
| **1h** | 실제 1시간봉 OHLCV | 없음 |
| **4h** | 연속된 실제 1시간봉 4개를 집계 | 없음 |
| **1D** | 선은 Coin Metrics 일말 값, 캔들은 제공 범위의 실제 거래소 일봉 | 장기 미래는 점선 |
| **1W** | 선은 주별 마지막 일말 값, 캔들은 월~일 실제 일봉 7개를 집계 | 장기 미래는 점선 |

모든 봉 시각은 UTC다. 30분·4시간·주봉은 첫 시가, 실제 고가의 최댓값, 실제 저가의 최솟값, 마지막 종가와 거래량 합계를 사용한다. 구성 봉이 빠지면 해당 집계 봉을 만들지 않는다. 주봉은 일요일 날짜에 그리며 선택 정보에는 월요일부터 일요일까지의 범위를 표시한다. [자료 계약과 API](OHLC_CHART_METHOD.md), [집계 구현](../dist/ohlc-data.js)

캔들 아이콘을 누르면 **선 ↔ 캔들**로 전환한다. 분·시간 화면의 선은 동일한 실제 봉의 종가를 연결한다. 빈 구간은 채우지 않으며, 현재 진행 중인 봉은 완료되기 전까지 제외한다. 이 화면은 거래 스트림이나 분·시간 단위 미래 예측을 제공하지 않는다.

일·주 캔들 화면에서는 거래소 자료가 있는 과거 구간만 실제 캔들로 바뀐다. 그 이전 구간은 Coin Metrics 일말 가격선으로 남고 미래는 계속 점선이다. 일말 값 하나를 시가·고가·저가로 복제하거나 미래 값을 가짜 캔들로 만들지 않는다. 거래소 자료 중 장기 모형의 관측 종료일 이후에 끝난 봉도 일·주 장기 차트에 섞지 않는다. [실제 캔들과 미래 경계](../dist/atlas-price-chart.js), [관측일 필터](../dist/lab-view.js)

### 처음 캔들로 바꿀 때의 확대

장기 전체를 한 화면에 놓으면 최근 실제 캔들의 몸통이 너무 작다. 따라서 **‘장기 전망’ 또는 ‘전체’에서 처음 캔들로 전환할 때**, 직접 지정한 날짜 범위가 없다면 다음 범위를 보여 준다.

- **일봉:** 마지막 일말 관측의 180일 전부터 30일 후까지.
- **주봉:** 마지막 일말 관측의 560일 전부터 30일 후까지.

기본 4년 보기, 이미 직접 옮기거나 확대해 정한 범위, 가까운 6개월 보기는 유지한다. 캔들 전환 때문에 2050년 경로를 삭제하지 않는다. 하단 **‘장기 전망’**을 누르면 최근 1년부터 2050년까지 다시 볼 수 있다. **맞춤 아이콘은 기본 4년으로 복원**한다. [첫 전환 범위 규칙](../dist/lab-view.js)

작은 화면에서는 긴 간격 버튼 행 대신 같은 8개 선택지를 가진 간격 메뉴를 제공한다. 분·시간 화면은 축소·왼쪽 이동 시 실제 과거 봉을 추가로 조회한다. 장기 기간 버튼과 미래 가정은 일·주 화면에만 제공하지만, 이동·측정·자석은 분·시간 화면에도 사용할 수 있다. [반응형 조작과 상태](../dist/workbench-chrome.js)

## 3. 하단 표시 기간과 가격축

**상단 간격은 자료의 시간 단위이고, 하단 기간은 보이는 날짜 범위다.** 두 조작은 서로 다르다.

| 하단 조작 | 일·주 가격 화면의 표시 범위 |
|---|---|
| **4년** | 최신 관측일 전후 24개월 · 기본 화면 |
| **6개월** | 계산 기준일의 45일 전부터 6개월 뒤까지 |
| **장기 전망** | 마지막 실제 일말 관측의 1년 전부터 확인한 마지막 목표 연도 말까지; 현재 2050-12-31 |
| **전체** | 2010년부터 장기 전망 종료일까지 |
| **맞춤 아이콘** | 직접 지정한 범위를 해제하고 기본 4년으로 복원 |
| **날짜 이동** | 우측 패널의 날짜 입력으로 선택 위치 이동 |

일·주 화면에서는 휠과 좌측 −·+로 확대·축소하고, 이동 도구 또는 Shift+휠로 날짜 범위를 옮긴다. 범위는 실제 첫 관측일과 현재 장기 종료일 안에서 제한한다. 분·시간 화면에서도 휠·드래그·확대 버튼을 사용한다. 현재 캐시 밖으로 축소·이동하면 같은 간격의 실제 과거 봉을 추가 조회한다. 한 화면은 최대 6,000개 봉 간격이며 계속 더 과거로 이동할 수 있다. 장기 전망 기간 버튼은 분·시간 화면에 적용하지 않는다. [날짜 탐색](../dist/chart-navigation.js), [지원 범위 연결](../dist/lab-view.js)

**로그** 축은 같은 배수 변화를 같은 높이로, **선형** 축은 같은 달러 차이를 같은 높이로 보여 준다. 하단 ‘자동’은 가격축을 표시 자료에 맞춘다는 상태 설명이다. 버튼이 아니다. 가격 단위를 지수로 바꿔도 실제 자료와 가정 자료의 구분은 유지된다. [가격축](../dist/chart-math.js)

## 4. 실제 값·가정 값과 범례 읽기

범례는 차트 **오른쪽 아래**에 두고 가격축 오른쪽 여백과 날짜축을 피하도록 배치한다. 작은 화면에서는 줄바꿈한다. 일·주 화면은 ‘실제 가격 · 미래 가정 · 가정 범위 · 고점·저점’을, 분·시간 화면은 ‘실제 캔들’ 또는 ‘실제 종가’와 거래소·UTC를 표시한다. 꺼 둔 레이어의 범례는 숨긴다. [범례 내용](../dist/lab-view.js), [범례 위치](../dist/chart-details-panel.css)

| 선택한 자료 | 선택 정보의 의미 |
|---|---|
| Coin Metrics 실제 일말 값 | 관측된 지수 가격과 전일 값 대비 변화 |
| Coinbase 실제 캔들 | 해당 봉의 O/H/L/C·거래량, **시가 대비 종가** 변화율, 완료 여부·거래소 출처 |
| 미래 점선 | 선택한 경제 가정과 역사 잔차를 합친 한 가지 경로의 값 |
| 미래 가치평가 기준 | 원문 가격 또는 자체 혼합·스트레스 가정의 기준선 값; 대표선의 실제 미래값이 아님 |
| 연환산 변동성 가정 | 경로 생성에 넣은 변동성 크기 |
| 가정 경로의 계산 변동성 | 만들어진 경로에서 별도로 계산한 값; 아직 관측하지 않은 실제 미래 변동성이 아님 |

Coin Metrics 지수와 Coinbase 거래소 종가는 동일한 가격 정의가 아니다. 미래 점선의 출발값과 역사 국면 분석은 Coin Metrics를 유지하므로 실제 캔들 종가와 조금 다를 수 있다. 출처와 계산 시점을 함께 읽는다. [선택 정보](../dist/atlas-price-chart.js), [분·시간 선택 정보](../dist/intraday-chart.js)

미래 음영은 **경제 가정 범위**다. 현재 장기 모형에서는 같은 잔차 경로에 낮음·기준·높음 평가를 적용하며, 수요 훼손 선택 시 해당 자체 스트레스도 포함한다. 10–90% 분위수 또는 미래 결과의 80%를 포함하는 범위가 아니다. 기관의 목표 연도를 연말에 표시하는 것은 앱의 배치 규칙이며 그날의 고점·저점을 뜻하지 않는다. 새 D-day는 이 대표 경로의 다음 지속 상태를 계산하며, 예전 여러 경로의 ‘첫 전환 확률’과 다르다. [모형과 범위의 정의](MODEL_SCOPE.md)

### 우측 상단 D-day와 색 띠

일·주 화면의 D-day는 같은 선택 모형에서 상승·조정·하락·횡보·바닥 후보·전환/혼합 상태를 읽는다. 다음 상태가 **7일 이상 연속** 이어지는 첫 구간의 시작일과 오늘의 한국 달력 날짜를 비교한다. 현재 상태의 연속 유지 기간은 오늘을 포함하며, 중간의 짧은 상태를 제외하고 찾은 다음 후보까지의 기간과 다를 수 있다. 후보가 없거나 경로 자료가 부족하면 날짜를 만들지 않는다. 분·시간 화면에서는 이 일별 상태 표시를 사용하지 않는다. [D-day 구현](../dist/scenario-countdown.js)

색 띠는 해당 날짜까지 관측한 정보로 산출한 사이클 시점 보정이다. 빨강은 단축 가정, 초록은 기준 부근, 파랑은 연장 가정, 회색은 근거 부족이다. **시장 상승·하락 색이나 매매 신호가 아니다.** 새 일별 자료가 들어오면 보정·미래 단계·D-day가 같은 모형에서 다시 계산된다. 이미 지난 날짜의 색은 나중 자료로 다시 칠하지 않는다. 새 고점·반감기·자료 누락에는 기준 초기화가 발생할 수 있다. [수식·설계값·독립 결과 수의 한계](CYCLE_CALIBRATION_MODEL.md)

## 5. 클릭·키보드와 우측 패널

포인터를 움직이면 십자선과 차트 상단의 임시 값이 바뀐다. 일반 클릭·키보드 선택은 날짜와 값을 고정하고 **우측 패널의 열림·닫힘 상태를 유지한다.** 선택 상세가 이미 열려 있으면 내용만 갱신하고, 설정·거래량 등 다른 패널이 열려 있으면 그 패널을 그대로 둔다. 우측 데이터 아이콘으로 고정한 값의 상세를 명시적으로 연다. 사건·D-day·분석 요약은 설명을 요청하는 조작이므로 상세를 연다. 키보드는 차트에 초점이 있을 때 사용하고 입력창에 글을 쓰는 동안에는 차트 단축키를 적용하지 않는다. [선택과 패널의 정책](../dist/inspection-policy.js)

| 조작 | 일·주 가격 화면 | 분·시간 화면 |
|---|---|---|
| 클릭·터치 | 날짜 또는 실제 캔들 선택, 패널 상태 유지 | 실제 완료 봉 선택, 패널 상태 유지 |
| 왼쪽·오른쪽 방향키 | 이전·다음 표시값 선택 | 이전·다음 완료 봉 선택 |
| Home / End | 표시 범위 처음·끝 선택 | 조회한 봉의 처음·끝 선택 |
| C / 십자선 | 값 읽기 | 값 읽기 |
| H / 이동 | 날짜 범위 드래그 | 실제 완료 봉 범위 드래그 |
| M / 자 | 시작·끝 두 가격 측정 | 두 지점 가격·시간·봉 간격 측정 |
| 휠 · − · + | 범위 확대·축소 | 실제 완료 봉 범위 확대·축소 |
| 패널 이전·다음 | 고점·저점 이동 | 이전·다음 완료 봉 이동 |

측정은 선택한 두 가격 사이의 경과 시간·달러 차이·변화율이다. 자석 끄기에서는 자유 가격, 약한·강한 자석에서는 실제 O/H/L/C에 측정점을 붙인다. 선과 미래 가정은 실제로 표시한 가격만 후보로 사용한다. 일반 값 읽기의 종가는 자석 측정 가격과 구분한다. 미래 점을 포함하면 ‘가정 포함’으로 표시한다. 측정 지우기 또는 Escape로 제거한다. [선택·측정](../dist/atlas-price-chart.js)

900 CSS 픽셀보다 넓으면 우측 패널은 기본 320px로 도킹하며, 경계에서 폭을 조절할 수 있다. 작은 화면에서는 차트 위에 겹쳐 열고 닫으면 조작 요소로 초점을 돌린다. 긴 설명은 패널 안의 페이지로 읽는다. [패널 동작](../dist/viewport-workspace.js), [레이아웃](../dist/chart-details-panel.css)

## 6. 경제 가정과 장기 근거 찾기

상단 **미래 가정**에서 ‘통화·금 기준 · 채택 확대 · 완만한 채택 · 낮은 채택 · 수요 훼손’을 고른다. 통화·금 기준·채택 확대·낮은 채택은 각각 WisdomTree의 기준·높음·낮음 발표 가격을 사용한다. 완만한 채택은 낮음과 기준의 기하평균이고, 수요 훼손은 현재 가격에 자체 손실 가정을 적용한다. 선택한 이름에 따라 확인할 가정이 달라지며 발생 확률을 부여하지 않는다. [시나리오 정의](../dist/long-horizon-forecast.js)

우측 **모델과 검증**에서 장기 계산, 연도별 가격·변동성 가정, 공급 일정, 기관별 원문과 한계를 읽는다. 가격 평가, 금과의 동조화, 변동성 하락은 서로 다른 주장이다. 4년 주기의 종료를 확정한 연도나 금의 변동성에 반드시 도달하는 연도는 제시하지 않는다. [장기 리서치](LONG_HORIZON_RESEARCH.md), [현재 모델 범위](MODEL_SCOPE.md)

현재 모형은 원문의 연도별 경제 기준과 역사 가격을 결합한다. 실시간 통화량·ETF 흐름·호가 유동성을 모두 학습한 예측기가 아니며, 새 2050년 모형의 정확도를 과거 3년 모형의 평가표로 대신하지 않는다. 예전 연구 결과는 아래 보관 자료에서 모형·기준일과 함께 읽는다.

## 7. 여섯 그래프와 자료 페이지

주 가격은 상시 표시한다. 나머지 다섯 연구는 기본적으로 닫혀 있으며 인디케이터 창에서 추가한다. 다시 선택하면 제거되고 눈 아이콘으로 일시 숨길 수도 있다. 추가한 연구는 차트 안의 제한된 영역에서 별도 축을 사용한다. 접두 구간을 100으로 맞춘 비교 축을 날짜별 실제 가격 축에 겹치지 않는다. 표시 목록·개별 숨김·추가 상태는 URL에 유지한다. [상태 계약](../dist/indicator-state.js), [연구 창](../dist/analysis-dock.js)

| 그래프 | 읽을 내용 |
|---|---|
| **가격과 미래** | 실제 거래 자료와 장기 조건부 예시 |
| **4년 비교** | 저점·반감기·달력 구간의 출발값 100 기준 가격 비교 |
| **구간 길이** | 큰 상승·하락의 길이와 내부 신고가·반등·횡보·되돌림 |
| **고점권 도달** | 최종 최고값의 95% 첫 진입과 최고값 사이의 일수·하락폭 |
| **월·분기** | 수익률·최대 하락·변동성·새 최고가 일수; 미완료 기간 구분 |
| **CryptoCon 검증** | 공개된 최초·수정 주장의 날짜·가격과 관측 결과 |

‘고점권 첫 진입’에서 최고값까지 오래 걸렸다고 그 사이 계속 고점권에 머물렀다는 뜻은 아니다. 큰 상승장·하락장의 경계와 최종 최고값은 사후 정보이며, 실제 관측·진행 중인 후보·미래 가정을 구분한다. [시장 구조 방법](MARKET_STRUCTURE_METHOD.md), [관측 비교 그래프](../dist/atlas-analysis.js)

우측의 **리서치 자료**와 **원자료**는 각각 원문 근거와 일별 가격 표로 이동한다. 검색·필터와 이전·다음 페이지로 읽으며, 자료 제목은 원문을 연다. 긴 근거와 한계는 같은 우측 패널에서 읽는다. 기존 보관용 분석 도구는 계산식의 이전 도구 링크 또는 `?page=compare&legacy=1`로 연다.

## 8. 조회 시각·완료 봉·저장 자료

거래소 상태에는 조회 중, 조회 완료, 갱신 중의 이전 자료, 연결 실패 시 저장 자료 또는 조회 실패가 표시된다. **마지막 봉의 시각은 관측 범위이고, 조회 시각은 자료를 받은 때**다. 저장 자료를 열었다고 수집 시각을 현재 시각으로 바꾸지 않는다. 간격을 바꿀 때 이전 요청을 취소하고, 늦게 도착한 응답이 새 간격을 덮지 않도록 처리한다. [요청과 상태](../dist/market-data-controller.js)

거래소 자료는 해당 간격을 처음 선택할 때 조회한다. 이후 새 완료 봉이 필요하면 차트의 **새로고침 아이콘**을 누른다. 자동 폴링이나 진행 중인 봉의 틱 갱신은 없다. 원격 조회 실패 시 검증한 이전 조회 또는 저장 봉을 표시하고, 둘 다 없으면 실패 상태를 보여 준다. [OHLC 방법](OHLC_CHART_METHOD.md)

장기 일말 자료는 포함된 번들과 유효한 브라우저 저장 자료를 먼저 읽고, 자료가 뒤처져 있으면 최신 완료 자료 갱신을 시도한다. GitHub Actions는 하루 네 번 완료 일말 자료와 거래소 저장 봉의 갱신을 시도하며, 사이클 시계 산출물을 재계산·검증한 뒤 같은 작업에서 배포한다. 열린 웹 페이지는 보이는 상태에서 6시간 간격으로 공개 스냅샷을 재확인하며 가격이 바뀌었을 때만 모형을 다시 계산한다. D-day는 한국 달력 날짜가 바뀔 때 갱신되지만 관측 기준일은 그대로 유지한다. 예약 시각과 실제 확인 시각은 다를 수 있다. 발행 연구 보고서와 과거 검증 결과는 자동으로 다시 계산하지 않는다. [일말 갱신](../dist/app.js), [배포 자료 갱신 작업](../.github/workflows/refresh-data.yml)

## 9. 저장과 구현 검증

상단 다운로드는 현재 그래프를 SVG로 저장한다. 일·주 가격 화면에서 계산 자료 저장은 모델 결과를 JSON으로 저장한다. 조회한 실제 자료의 날짜, 장기 연구 검토일, 저장한 계산 결과의 기준일을 함께 보존해 읽는다. [내보내기](../dist/lab-view.js)

현재 사이트는 자체 SVG 구현이다. TradingView에서 간격·도구 배치의 사용 방식을 참고했지만 TradingView 시세·주문 기능을 연결한 제품은 아니다. [구성 조사](TRADINGVIEW_WORKSPACE_RESEARCH.md), [실제 캔들 검증 항목](OHLC_CHART_METHOD.md). 자동 검사는 입력·집계·종료일·계산 성질을 확인하며 장기 예측 정확도의 증명은 아니다. 공개 배포 여부는 해당 커밋의 [Actions](https://github.com/twoimo/bitcoin-cycle-atlas/actions)를 확인한다.
