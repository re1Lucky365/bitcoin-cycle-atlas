## 1. 처음 사용할 때: 세 단계

1. **‘가격과 미래’에서 실선과 점선을 구분한다.** 흰 실선은 실제로 수집한 가격이고 금색 점선은 선택한 가정으로 만든 한 가지 미래 예시다. 기본 화면은 최근 1년과 앞으로 3년을 함께 보여 준다.
2. **궁금한 날짜를 누른다.** 우측 패널에서 날짜, 가격, 이전 최고가 대비 하락폭, 가격 흐름을 확인한다. 미래 구간을 고르면 ‘가정’이라는 구분이 붙는다. 패널 제목 아래의 날짜 입력, 이전·다음 고저점, 최근 관측 아이콘으로 선택을 바꾼다. 패널을 닫으면 차트가 다시 전체 폭을 사용한다.
3. **확인할 질문에 맞춰 왼쪽 위 차트 아이콘을 누른다.** 우측 패널에서 그래프 종류를 고르면 그래프가 바뀌고 패널이 닫힌다. 사이클의 가격 모양은 ‘4년 비교’, 기간이 짧아졌는지는 ‘구간 길이’, 고점 부근에 먼저 도착했는지는 ‘고점권 도달’, 월별 낙폭은 ‘월·분기’에서 확인한다. 설정이 복잡해졌다면 상단 설정의 ‘처음 화면’을 누른다. 하단 맞춤 아이콘은 다른 설정을 유지하고 기본 표시 기간만 복원한다.

차트 안의 **‘반등 후보’ 또는 ‘조정 후보’와 남은 일수 표시**를 누르면 해당 전환 후보 구간이 확대되고, 우측 패널에 중앙 날짜와 전체 후보 날짜 범위가 열린다. D-day는 시장이 반드시 움직이는 날짜가 아니라 여러 예시의 첫 전환 시기를 요약한 값이다. [가격 그래프 선택·이동](../dist/atlas-price-chart.js), [D-day와 초기화 동작](../dist/lab-view.js)

## 2. 여섯 가지 그래프에서 읽을 내용

| 그래프 | 무엇을 비교하나 | 읽을 때 구분할 점 |
|---|---|---|
| 가격과 미래 | 실제 과거 가격, 앞으로 3년의 조건부 예시, 고저점, 이전 최고가 대비 하락폭 | 실제 가격과 미래 가정, 대표 경로와 여러 경로의 요약을 구분한다. |

| 월·분기 | 기간 수익률, 최대 하락폭, 가격 흔들림, 새 최고가 일수 | 끝나지 않은 월·분기는 일부 날짜만 관측한 값이다. |
| CryptoCon 검증 | 최초·수정 전망, 근접 기준별 선행일, 목표 가격 대비 결과 | 본인 공개 글, X 색인, AI 생성 요약, 보도를 구분하며 계정 전체 적중률로 환산하지 않는다. |

위 비교는 [관측 자료 그래프 모듈](../dist/atlas-analysis.js)과 기존 [시장 구조 계산](../dist/market-structure.js), [고점권 분석](../dist/peak-zones.js)을 사용한다. 그래프를 그리기 위해 실제 가격이나 과거 날짜를 가정에 맞게 수정하지 않는다.

### ‘구간 길이’에서 내부 흐름까지 보기

‘비교할 흐름’에서 다음 세 가지를 고를 수 있다.

- **전체 상승·하락 기간:** 큰 상승 구간과 하락 구간을 막대 길이로 비교한다.
- **상승장 안의 반복 흐름:** 상승장 내부의 신고가 발견, 반등, 되돌림, 횡보 등의 실제 순서를 색 띠로 본다.
- **하락장 안의 반복 흐름:** 하락장 내부에서 반등과 재하락이 어떻게 반복되었는지 같은 방식으로 본다.

색 띠의 가로 길이는 실제 일수다. 사이클마다 모든 띠를 같은 폭으로 늘리지 않으므로, 전체 기간과 내부 구간의 길이가 함께 비교된다. 한 날짜는 하나의 상태로만 분류한다. 구간을 누르면 상태별 합계와 관측 경계를 읽을 수 있다. 분류에는 해당 날짜까지 알려진 정보를 사용하지만, 큰 상승장·하락장의 시작과 끝은 사후 기준이다. ‘저점 형성 조건’이라는 이름만으로 최종 저점을 확정하지 않는다. [내부 흐름의 경계와 분류](../dist/atlas-analysis.js), [국면 정의](./MARKET_STRUCTURE_METHOD.md)

### ‘고점권 도달’에서 횡보와 조기 진입 구분하기

동그라미는 95% 구간에 처음 들어간 지점, 사각형은 최고 일말 가격 지점이다. 두 지점 사이의 일수는 **고점권 첫 진입이 최고값보다 얼마나 앞섰는지**를 보여 준다. 그 사이 내내 횡보했거나 계속 95% 위에 머물렀다는 뜻은 아니다. 선택 정보의 ‘첫 도착 이후 최대 하락’도 함께 살펴본다. 종가 기준 결과는 장중 최고가 기준 결과와 날짜가 다를 수 있다. [고점권 그래프와 선택 정보](../dist/atlas-analysis.js), [제공자·가격 정의 대조](./STRUCTURE_CROSS_VALIDATION.md)

### ‘월·분기’에서 작은 구간 확인하기

기본 화면은 최근 월 또는 분기 구간을 보여 준다. ‘2010년부터 전체’로 바꾸면 전체 관측 기간을 한 축에서 볼 수 있다. 막대를 누르면 해당 기간의 수익률, 최대 하락폭, 가격 흔들림, 새 최고가 일수와 실제 관측 일수를 함께 읽을 수 있다. 이전·다음 이동은 선택한 기간을 바꾸며, 최근 구간 보기에서는 선택 위치에 따라 보이는 창도 이동한다. [기간 그래프](../dist/atlas-analysis.js)

‘가장 크게 떨어진 폭’은 그 기간 안의 앞선 고점에서 이후 저점까지 가장 크게 하락한 비율이다. 전기 마지막 가격도 시작 기준에 포함한다. ‘가격 흔들림’은 일별 수익률의 변동을 연간 기준으로 환산한 수치이며, 상승 방향이나 손실 확률을 뜻하지 않는다. [월·분기 계산 정의](./MARKET_STRUCTURE_METHOD.md)

## 3. 클릭·터치·키보드로 값을 읽는 방법

십자선 모드에서 그래프를 누르면 해당 날짜·구간을 선택하고 우측 **‘선택 데이터 · 고정’** 패널을 연다. 마우스만 움직일 때는 십자선·축 라벨과 차트 상단 날짜·가격이 포인터를 따라간다. 패널의 고정값은 바꾸지 않으므로, 이전에 선택한 값과 잠시 가리키는 값을 구분할 수 있다. 포인터가 차트를 벗어나면 차트 상단은 원래 읽을 값으로 돌아간다. 큰 호버 설명 상자는 사용하지 않는다. [가격 선택·호버](../dist/atlas-price-chart.js), [정보 연결](../dist/lab-view.js)

과거의 확인된 고저점은 채운 점, 미래 예시의 고저점은 빈 점이다. 색뿐 아니라 선택 상세의 실제·가정 구분을 함께 읽는다.

| 조작 | 동작 |
|---|---|
| C / 십자선 아이콘 | 가격을 가리키고 클릭해 선택 상세 열기 |
| H / 손 아이콘 | 차트를 드래그해 표시 날짜 범위 이동 |
| M / 자 아이콘 | 두 지점을 골라 날짜·가격 변화 측정 |
| 좌측 휴지통 / 측정 중 Escape | 측정 지우기 |
| 왼쪽·오른쪽 방향키 | 가격 날짜 또는 현재 비교 항목 이동 |
| Home / End | 보이는 범위의 처음 / 끝으로 이동 |
| Enter / Space | 십자선 모드에서는 선택 상세 열기, 측정 모드에서는 시작·끝점 확정 |
| 패널의 이전·다음 아이콘 | 가격 그래프의 이전·다음 고저점, 비교 그래프의 항목 이동 |
| 하단 달력 아이콘 | 우측 패널의 날짜 입력으로 이동 |
| 패널의 최근 관측 아이콘 | 마지막 실제 관측 날짜로 복귀 |
| 휠 / 좌측 −·+ | 가격 그래프 확대·축소 |
| Shift+휠 / 가로 휠 | 가격 그래프의 날짜 창 이동 |
| + / − / 0 | 그래프에 초점이 있을 때 확대 / 축소 / 기본 기간 복귀 |
| Escape / 패널 닫기 | 열린 상세 패널 닫기 |

C·H·M은 ‘가격과 미래’에서 제공하며 입력창에 글을 입력하는 동안에는 적용하지 않는다. 방향키와 Enter·Space는 차트에 키보드 초점이 있을 때 사용한다. 과거 비교에서는 해당 그래프의 항목 이동만 제공하고 가격용 측정·축 조작을 숨긴다. [도구와 단축키](../dist/workbench-chrome.js), [가격 키보드 처리](../dist/atlas-price-chart.js), [과거 비교 이동](../dist/atlas-analysis.js)

### 두 지점의 기간과 가격 변화 측정

좌측 자 아이콘 또는 M을 선택하고 시작점과 끝점을 차례로 누른다. 키보드로는 방향키로 위치를 고른 다음 Enter·Space를 두 번 사용한다. 측정에는 선택 날짜에 대응하는 **일별 가격 두 값**을 사용하며, 표시 눈금이 로그인지 선형인지와 관계없이 원래 달러 가격으로 계산한다.

- 기간: 끝 UTC 날짜에서 시작 UTC 날짜까지의 경과 일수.
- 달러 차이: 끝 가격에서 시작 가격을 뺀 값.
- 변화율: `(끝 가격 / 시작 가격 − 1) × 100`.
- 미래 지점을 포함하면 측정 표시에도 **‘가정 포함’**이 붙는다.

두 점은 선택 순서를 유지하므로 과거 방향으로 측정하면 일수 부호가 음수일 수 있다. 완료한 측정 뒤 새 점을 고르면 새로운 측정을 시작한다. 측정 지우기 또는 차트에서 Escape로 제거한다. 일별 두 가격 사이의 차이이며 장중 고가·저가·거래량을 측정하는 기능은 아니다. [측정 구현](../dist/atlas-price-chart.js)

### 우측 패널과 화면 크기

우측 세로 아이콘은 선택 데이터, 레이어, 모델과 검증, 다음 전환 후보, 페이지, 도움말 순으로 모았다. 필요한 상세가 같은 패널에서 전환되고 현재 열린 종류를 아이콘 상태로 표시한다. 그래프 종류를 고르면 패널이 닫히며, 레이어·가정·설정은 값을 바꾸는 동안 열린 상태를 유지한다. [배치와 연결](../dist/workbench-chrome.js)

**900 CSS 픽셀보다 넓으면** 기본 320px로 도킹한다. 패널 왼쪽 경계를 드래그하거나 경계에 초점을 두고 좌우 방향키를 눌러 폭을 바꾼다. 허용 범위는 280–420px이며 차트에 최소 480px을 남기도록 최대 폭을 줄인다. 경계 더블클릭 또는 Home은 기본 폭으로 복원한다. 차트는 남은 실제 너비에 맞춰 다시 그려진다.

**900 CSS 픽셀 이하에서는** 패널을 차트 위에 겹쳐 열어 차트를 더 좁히지 않는다. 열린 동안 배경의 중앙·좌측 조작은 비활성화되고 Tab은 패널과 우측 도구 모음 안에서 순환한다. 닫으면 열 때 사용한 조작 요소로 초점을 돌려준다. 큰 화면의 도킹 상태는 배경 차트도 계속 조작할 수 있다. [레이아웃](../dist/chart-details-panel.css), [너비·초점·배경 처리](../dist/viewport-workspace.js)

긴 설명·근거는 이전·다음 페이지로 읽는다. 실제 입력을 조작하는 설정·레이어·시나리오 화면은 설명 페이지 분할과 구분하며 원래 입력 요소를 유지한다. 이 설계와 별개로 실제 브라우저 검수 범위는 [v1.5 검증 기록](FIVE_REGION_VERIFICATION.md)에서 확인한다.

### TradingView에서 참고한 구성

[공식 Supercharts 시작 안내](https://www.tradingview.com/support/solutions/43000746464-getting-started-with-supercharts/), [설정 안내](https://www.tradingview.com/support/solutions/43000748166-how-to-configure-your-supercharts/), [날짜·가격 측정 안내](https://www.tradingview.com/support/solutions/43000516996-date-and-price-range-drawing-tools/)를 바탕으로 상단 빈도, 좌측 조작, 우측 상세, 하단 기간·축을 구분했다. 최신 공식 문서에 근거한 다섯 영역 조사와 적용 판단은 [TradingView 구성 리서치](TRADINGVIEW_WORKSPACE_RESEARCH.md)에 정리한다.

이 사이트는 자체 SVG 구현이다. TradingView 라이브러리·실시간 시세·주문 연동을 사용한다는 뜻은 아니다. 원자료에 없는 시가·고가·저가·거래량을 만들어 캔들로 표시하지 않는다. 확대 범위와 날짜 경계는 [탐색 모듈](../dist/chart-navigation.js)에서 제한한다. 모바일의 기본 핀치와 Ctrl/Meta+휠은 브라우저에 남긴다.

## 4. D-day와 미래 고저점의 정확한 의미

화면에는 서로 다른 세 종류의 미래 정보가 있다.

| 종류 | 화면에서의 의미 |
|---|---|
| 점선 한 개의 고점·저점 | 선택한 대표 예시 경로 안에서 가격이 꺾인 날짜와 가격 |
| 가까운 고점·저점 후보와 D-day | 여러 예시 경로에서 첫 전환이 발생한 날짜들의 중앙값과 후보 범위 |
| 고점권 도달·큰 주기 고점 기준 | 큰 주기를 구성하기 위해 넣은 시간과 가격 가정 |

첫 전환 날짜의 중앙값과 점선 한 개의 고저점 날짜는 일치할 필요가 없다. 차트 안의 후보 표시나 D-day 수직선이 보인다고 그날 점선이 반드시 꺾이는 것은 아니다. 반등·조정 후보를 선택하면 구간을 확대하고 우측 패널에서 **중앙 날짜, 후보 범위의 시작·끝 날짜, 남은 일수, 전환 뒤 방향 후보, 계산 기준일**을 함께 읽는다. 좁은 차트 안에서 요약한 날짜 범위도 패널에서는 전체 값으로 확인한다. ‘여러 예시의 요약’ 또는 ‘미래 가정’이라는 구분으로 어떤 수치를 읽고 있는지 확인한다. [D-day 계산·선택 정보](../dist/lab-view.js)

고저점 발생일과 확인일도 다르다. 기본 세부 고저점은 반대 방향으로 12% 움직인 뒤 확인한다. 따라서 뒤늦게 확인된 점을 과거 발생일에 표시할 수 있지만, 그 발생 당일에 고저점이 확정되어 있었다고 해석하면 안 된다. 미래 예시의 확인일은 그 예시 안에서 계산된 확인일이다. [방향 전환 정의](./MARKET_STRUCTURE_METHOD.md)

미래 음영은 같은 가정에서 만든 경로들의 날짜별 10·90 분위수 범위다. **실제 미래가 그 안에 들어갈 확률이 80%라는 뜻은 아니다.** 대표 경로가 일부 날짜에서 이 음영 밖으로 나갈 수도 있다. 계산의 재현 가능성과 미래 가격을 정확하게 맞히는 능력은 별개다. [미래 경로와 범위의 정의](./DETAILED_FORECAST_METHOD.md)

## 5. 미래 가정과 표시 설정

‘미래 가정’은 기본적인 4년 흐름, 더 빠른 고점권·고점 도달, 빠른 상승 뒤 긴 횡보, 늦은 고점 전환, 기존 저점 이탈을 비교한다. 고점권에 빨리 도착하는 것과 최종 고점이 빨라지는 것을 별도 조건으로 다룬다. ‘3년 상승·1년 하락’은 이 비교에서 유지하는 큰 가정이며, 가격 자료가 증명한 불변 법칙은 아니다. [시간 가정과 수식](./DETAILED_FORECAST_METHOD.md)

### 모형이 사용하는 입력과 가정

우측의 **모델과 검증 아이콘**은 모형 설명 패널을 연다. 맨 앞에서 모형의 반영 범위를 확인하고, 그 뒤에 날짜표·수식·과거 평가를 읽는다. 자세한 정의는 [현재 모형이 반영하는 것과 반영하지 않는 것](./MODEL_SCOPE.md)에 정리했다.

| 구분 | 현재 반영 범위 |
|---|---|
| 실제 입력 | 날짜와 완료된 UTC 일말 달러 가격. 시가총액·공급량·거래량·ETF 자금 흐름·시장 유동성·온체인 지표는 입력하지 않는다. |
| 가격에서 계산하는 특징 | 로그수익률, 이전 최고가 대비 하락폭, 가격 규칙으로 구분한 국면과 최근 90일의 변동성. |
| 세부 움직임 | 과거 가격의 잔차를 연속 블록으로 재표본화한다. 28일은 블록 길이 분포를 조절하는 설정이며, 모든 블록의 길이나 시장 국면의 학습된 평균 기간이 아니다. |
| 지정한 큰 틀 | 48개월 시계, 명목 36개월 상승·12개월 하락, 고점권 선행·체류 기간, 미래 가격 기준과 마지막 거시 저점의 조건. |

과거 국면의 길이를 비교하는 화면과 미래를 생성하는 모형의 입력은 구분한다. 현재 미래 생성기는 **기간 단축 속도나 국면별 체류시간 분포를 역사에서 학습하지 않는다.** 최근 변동성을 반영하고 같은 조건에서 경로를 재현할 수 있다는 성질도 미래 방향·전환일을 증명하지 않는다. 이 구분과 가격 기준의 설정값, 종점 조건, 검증 표본의 한계를 [모형 범위 설명](./MODEL_SCOPE.md)에서 먼저 확인한다.

### 표시 범위와 가격 눈금

하단 **‘6개월’은 최근 45일과 앞으로 6개월**, **‘3년 전망’은 최근 1년과 앞으로 3년**, **‘전체’는 2010년부터 앞으로 3년**이다. 상단 설정의 ‘보기’에서는 미래의 첫째·둘째·셋째 1년 창도 고를 수 있다. 표시한 3년 밖의 거시 기준은 정확한 수치 표에서 확인하며 그래프 안으로 당겨 그리지 않는다.

상단 1D는 일별 관측 가격, 1W는 주별 마지막 가격을 사용한다. 하단 기간 버튼과 역할이 다르다. 주별 선은 일말 자료를 묶은 것으로 실제 장중 캔들이 아니다. 하단 **로그·선형** 버튼은 세로축의 눈금을 전환한다. 로그에서는 같은 배율 변화, 선형에서는 같은 달러 차이가 같은 높이가 된다. 옆의 **‘자동’은 가격축을 표시 데이터에 맞추는 상태 설명이며 버튼이 아니다.** 맞춤 아이콘은 기본 기간을 복원한다. [조작 연결](../dist/workbench-chrome.js), [가격축](../dist/atlas-price-chart.js)

### 레이어·설정·저장

우측 **레이어**에서 모의 경로 범위, 고저점, 전고점 대비 낙폭, 상승·횡보·하락, 피보나치 되돌림을 켜거나 끈다. 되돌림 선은 최근 기준점이 확인된 때부터 표시하며 과거 전체에 소급하지 않는다. 상단 **설정**에는 가격 단위·보기 또는 현재 비교 그래프의 조건과 ‘처음 화면’을 둔다. **미래 가정** 버튼에서는 기본·빠른 전환·횡보 연장·늦은 전환·하락 확대를 고른다. 이 시나리오들은 추정 확률이나 확정 전망이 아니다.

상단 다운로드는 현재 그래프를 SVG로 저장한다. 레이어 패널의 ‘계산 자료 저장’은 미래 계산 결과를 JSON으로 저장한다. 화면에서 저장한 자료와 발행 연구 스냅샷은 날짜가 다를 수 있다. [설정과 내보내기](../dist/lab-view.js)

## 6. 관측 종료일, 계산 기준일, 연구 보고서 날짜

**실제 자료 날짜**는 현재 그래프에 사용한 마지막 완료 일말 관측을 뜻한다. 하단의 KST 갱신 확인 시각을 누르면 우측 패널에서 현재 차트의 관측일과 자동 배포 자료의 관측일을 확인할 수 있다. **계산 기준일**은 D-day와 미래 표시 기간을 계산하는 기준이며, 후보 선택 상세와 계산식에서 확인한다. 실시간 거래 가격이나 컴퓨터 시각과 동일한 개념이 아니다. [갱신 상세](../dist/viewport-workspace.js), [후보 선택 정보](../dist/lab-view.js)

사이트는 포함된 자료와 유효한 브라우저 저장 자료를 먼저 읽는다. 마지막 자료가 현재 UTC 날짜보다 하루 넘게 뒤처져 있으면 최신 완료 자료 갱신을 시도한다. 갱신에 성공하면 그래프를 다시 계산하며, 실패하면 기존 자료를 유지한다. 따라서 실제 자료 날짜를 먼저 확인해야 한다. [자료 선택·갱신 구현](../dist/app.js), [제공자 자료 처리](../dist/data-source.js)

발행된 과거 검증표와 연구 문서는 **2026-10-20 UTC 자료로 만든 고정 연구 결과**다. 웹 화면이 더 최근 관측을 받더라도 이 검증표가 새로운 자료와 모든 시나리오의 적중률을 자동으로 다시 측정한 것은 아니다. [연구 스냅샷](./DETAILED_FORECAST_METHOD.md), [발행 검증값](../dist/forecast-validation.js)

## 7. 미래 예시를 평가할 때 확인할 근거

**우측의 모델과 검증 아이콘을 누르면** 우측 패널에서 모형의 입력·가정·미반영 변수부터 큰 주기의 기준 날짜, 대표 예시의 고저점 목록, 계산식, 과거 평가, 민감도를 확인할 수 있다. 설정 메뉴를 먼저 열 필요는 없다. [모형의 반영 범위](./MODEL_SCOPE.md), [상세 패널](../dist/viewport-workspace.js)

기존 평가에서 MAPE라는 가격 오차 기준으로는 모든 평가 기간에서 가격을 그대로 둔 기준선보다 오차가 컸다. 장기 2·3년의 평균 절대 로그오차는 더 작았지만, 표본이 작고 척도에 따라 결과가 달라 일관된 예측 우위가 확인되지는 않았다. 음영 범위 역시 실제 결과를 정해진 확률로 포괄하도록 보정되지 않았다. 변동성 등 가정을 바꾸면 첫 전환 후보일이 크게 움직일 수 있다. 차트에는 ‘가정’을 표시하고 이 평가 결과는 근거에서 확인한다. [과거 평가와 민감도](./DETAILED_FORECAST_METHOD.md)

그래프가 정교해졌다는 사실을 미래 날짜의 수학적 증명으로 받아들이지 않는다. 이 도구가 검증 가능하게 제공하는 것은 **주어진 자료와 가정을 어떤 수식으로 변환했는지**, 그리고 **그 방법이 과거에서 어떤 오차를 냈는지**다.

## 8. 리서치와 원자료를 찾는 위치

우측 세로 도구 모음의 **리서치 자료**는 근거 우선순위 표, **원자료**는 일별 가격 표, **통합 차트**는 그래프로 이동한다. 각 표는 화면 높이에 맞춰 행 수를 정하고 이전·다음 페이지로 이동한다. 제목 검색과 CryptoCon 필터로 좁힐 수 있다. 한 화면 구성을 위해 예전 무한 스크롤을 페이지 이동으로 바꿨다. 제목은 원문을 열고 근거 등급은 우측 패널에 읽는 이유와 한계를 연다. 긴 상세도 패널 안에서 페이지를 넘긴다. A–D는 활용 등급이며 미래 적중 확률이 아니다. [자료 정렬](../dist/evidence-index.js), [표와 상세](../dist/evidence-view.js)

우측 **선택 데이터**는 고정한 날짜·구간의 수치와 출처, **모델과 검증**은 입력·가정·수식·과거 평가, 아래 **도움말**은 그래프 읽는 법을 연다. 하단 갱신 시각은 현재 차트 관측일·자동 배포 자료 관측일·자동 확인 시각·실행 기록을 연다. UTC는 차트 날짜의 기준, KST는 갱신 확인 시각의 표시 시간대다. 이 브라우저가 직접 받은 자료와 자동 배포 번들의 날짜도 구분한다. [상세 패널](../dist/viewport-workspace.js)


GitHub Actions는 매일 03:20·09:20·15:20·21:20 KST에 최신 완료 UTC 일말 자료를 확인한다. 지연 가능성이 있어 예약 시각과 실제 확인 시각을 구분한다. 자료가 날짜·연속성·가격 검증을 통과하면 그래프 번들과 배포를 갱신한다. 새 일봉이 없으면 가격은 그대로이고 확인 시각만 갱신한다. 실패하면 마지막 유효 자료를 보존한다. 고정 연구 결과는 자동으로 덮어쓰지 않는다. [갱신 프로그램](../scripts/refresh-data.mjs), [워크플로](../.github/workflows/refresh-data.yml).

기존 세부 분석은 계산식 마지막의 ‘이전 상세 분석 도구’ 또는 `?page=compare&legacy=1`에서 연다. 이 보관용 화면만 문서 스크롤을 사용한다. 기본 여섯 그래프, 자료 표, 원자료 표는 뷰포트 안에서 조작한다.

## 9. 개선 이유와 검증 기록의 범위

개선 전 화면과 코드에서 확인한 주요 문제는 흩어진 분석, 기본 노출된 전문 설정, 고정 폭 그래프, 호버 중심 설명이었다.

현재 설계는 차트 안에 방향 후보와 D-day를 통합하고, 선택 정보·근거·계산식을 필요할 때 여는 우측 패널로 모은다. 가격 좌표는 패널을 제외한 실제 표시 폭에 맞추며, 작은 화면에서는 패널이 차트 위에 겹쳐 열린다. 기존 연구 모형과 원자료는 유지한다. [변경된 화면](../dist/index.html), [패널 레이아웃](../dist/chart-details-panel.css)

**v1.5의 실제 검수와 공개 배포 결과는 [다섯 영역 검증 기록](FIVE_REGION_VERIFICATION.md)에 기록한다.** 코드의 설계 설명을 배포 성공이나 모든 기기의 검수 완료로 해석하지 않는다. v1.4 당시 도킹·360px 겹침·클릭·키보드·설정·긴 자료 검수는 [이전 우측 패널 검증](RIGHT_PANEL_VERIFICATION.md)에 보존한다. 아래 v1.2·v1.3 기록도 해당 버전의 이전 결과이며 현재 결과와 구분한다.

### v1.2의 이전 검증 기록

| 확인 항목 | 확인 범위 |
|---|---|
| 자동 검사 | `npm test` 9개 테스트 파일, 정적 참조·단일 HTML 검사 통과. 19개 모듈 통합 빌드 성공. 테마 수정 후 단일 HTML에서 어두운 배경·밝은 글자와 내부 흐름 그래프 표시 확인. |
| 기본 조작 | 데스크톱 그래프 전환, 포인터·키보드 선택, 고저점 숨김 상태의 이전·다음 이동 확인. |
| 날짜 경계 | 늦은 전환의 2030년 기준점은 3년 그래프 선택에서 제외. 날짜 입력 유효성, 고점 후보 선택 후 표시 변경 시 통계 유지 확인. |
| 전체 자료 | 2010년부터 미래 3년까지 그래프에 비정상 좌표 없음. 전체 분기 최대 하락 보기에서 Home으로 2010년 3분기 선택 확인. |
| 작은 화면 | 390 CSS 픽셀 폭의 브라우저 검수 화면에서 콘텐츠 폭 375픽셀, 가로 넘침 없음. 포인터·키보드 조작 확인. 실제 휴대전화 시험은 아님. |
| 리서치 | 목록이 24행에서 36행으로 추가되고, 자료 상세에서 근거와 한계를 여는 동작 확인. |

당시 v1.2 검수 중 앱 오류는 관찰되지 않았다. 단일 HTML의 새 스타일 포함과 기본 테마 처리를 수정했다. 버전별 빌드·CI·공개 배포는 [릴리스](https://github.com/twoimo/bitcoin-cycle-atlas/releases)와 [Actions](https://github.com/twoimo/bitcoin-cycle-atlas/actions) 기록을 함께 확인한다. 위 결과는 실제 기기의 터치 품질이나 모든 보조기술에서의 접근성 적합성까지 보장하지 않는다.


### v1.3의 이전 검증 기록

뷰포트·CryptoCon·주기 갱신에 대한 당시 검증 범위는 [v1.3 검증 기록](VIEWPORT_VERIFICATION.md)에 별도로 남겼다. 이전 버전의 무한 스크롤·화면 높이 결과를 이번 개편의 검증 결과로 재사용하지 않는다.
