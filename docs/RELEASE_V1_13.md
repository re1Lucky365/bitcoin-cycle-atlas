# v1.13.0 — 연구 작업 흐름과 자유 이동

최대로 축소한 차트에서도 좌우·상하로 이동할 수 있다. 데이터 범위 밖에서는 실제 가격을 만들지 않고 빈 화면의 축과 이동 도구를 유지한다. 가로 이동은 Auto를 유지하고 세로 이동은 수동 가격 범위로 전환한다. 가격 차트 높이는 늘리지 않는다.

## 변경

- 간격 전환 시 UTC 중심·표시 기간·원 USD 수동 범위를 보존하고, 선택 시각은 대상 간격의 격자에 맞춰 유지. 봉 수 제한으로 기간이 조정되면 안내한다.
- `Alt+G`의 UTC 날짜·시각·시작–끝 이동, 시간축 드래그, 가격축 반전, 가격 자료만 Auto, 표시 시작 대비 %·시작=100.
- 지표별 값·축 숫자·스타일·표시 간격·지원 계산 입력 설정과 저장·공유 복원.
- 독립 연구 창의 순서·높이·최대화·접기, 연속 조작을 묶는 50단계 Undo/Redo.
- 길게 누른 터치 추적과 두 손가락 이동의 전환, 여러 두 점 측정의 원좌표·출처·메모 저장·잠금·숨김·삭제.
- 고정 미리보기의 주 가격/가격+연구 창 PNG·SVG, 관측·조건부·개별 연구 CSV. 원자료의 UTC·출처·USD·실제 행 수를 분리한다.
- 기존 차트 내부 하단 기간선, 우측 상단 D-day·여섯 색 범례와 십자선 흔들림 수정을 유지한다.

## 검증과 범위

616/616 자동 케이스·시나리오, 사이클·성능·정적 자산·독립 HTML 및 제한된 요청 소유권 형식 검증을 통과했다. 실제 브라우저에서 최대 축소 이동, 빈 화면·복원, 설정·저장, 연구 창, 측정·Undo, 320/390/844px 배치와 3,004행 Coinbase CSV 내용을 확인했다.

물리 터치 기기·브라우저별 이미지 클립보드는 이번 검수 범위에 포함되지 않는다. PNG/SVG 미리보기와 생성 상태는 확인했으나 추가 이미지 파일의 수신 내용은 도구 제한으로 검증하지 못했다. 가격 모형의 예측 성능이 개선됐다는 의미가 아니다.

구현 대응표, 재현 경로, 캡처 및 정확한 검증 한계는 [B01–B12 구현 보고서](RESEARCH_WORKFLOWS_2026-10-23.md)를 참조한다. 배포 상태는 해당 커밋의 CI·Deploy Pages 결과를 따른다.
