# Bitcoin Cycle Atlas v1.4.0

차트 위아래의 상태·날짜·선택 값 영역을 차트와 하나의 오른쪽 패널로 통합했습니다. 현재 3년 그래프에 실제 반영한 데이터와 지정한 가정을 코드 기준으로 명확히 공개했습니다.

## 차트와 우측 패널

- 차트 안의 BTC/USD·최근 일말 가격·관측일, 오른쪽 가격 눈금과 날짜 십자선.
- 차트 안의 반등·조정 후보와 D-day. 누르면 후보 구간을 확대하고 날짜 중앙값·범위·의미를 우측에서 확인.
- 선택 값·근거·계산식·업데이트·도움말·자료 상세를 하나의 패널에서 열람.
- 그래프 종류와 설정도 같은 패널에서 선택. 설정 요소의 실제 동작과 현재 선택을 유지.
- 데스크톱 320px 도킹, 600px 이하 겹침 패널. 닫기·Escape·포커스 복원, 페이지별 긴 자료 열람.
- 상단·하단 카드와 큰 호버 설명창 제거. 기본 화면은 하나의 차트 뷰포트.

## 모델 범위

실제 입력은 과거 일별 가격과 날짜입니다. 수익률·국면·최근 90일 변동성을 계산하지만 시가총액·공급·거래량·유동성·ETF 흐름은 입력하지 않습니다. 미래 48개월 시계, 선행·체류 기간, 가격 지수와 거시 저점 낙폭은 지정한 조건이며 학습된 기간·가격 예측치가 아닙니다.

계산식과 재현성의 검증은 미래 가격·전환일의 수학적 증명이 아닙니다. 사후 평가에서 일관된 예측 우위는 확인되지 않았습니다. 이번 릴리스는 이 범위를 설명하고 UI를 개선하며, 새로운 시총 모형을 구현했다는 주장이 아닙니다.
