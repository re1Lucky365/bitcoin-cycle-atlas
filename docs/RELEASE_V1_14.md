# v1.14.0 — 간결한 모바일 차트와 조작

모바일에서 가격을 가리는 정보를 줄이고, 값 목록·연구 창·하단 도구가 기존 차트 영역을 나누어 사용하도록 개선했다. D-day UI는 제거했으며 장기 경제 가정과 사이클 계산 모형은 유지한다.

## 변경

- D-day HUD·지표 항목·진입점 제거. 옛 공유 링크와 저장 지표 구성에서도 해당 UI가 되살아나지 않는다.
- 모바일의 가격·여섯 색 범례 묶음 숨김: 폭 620px 이하, 또는 폭 950px 이하이면서 높이 500px 이하. 색 원과 기간선 자체는 각각의 표시 설정을 따른다.
- 데스크톱 가격 범례는 크기가 제한된 SVG로 관측 가격선·완료 캔들을 구분. 혼합 구간은 실제 보이는 두 종류와 자료별 종료일을 표시하며 관측 종가를 실시간 현재가로 부르지 않는다.
- 거래량은 새 접속·초기화에서 숨김으로 시작. 사용자가 명시적으로 저장한 표시 선택은 유지한다.
- 좌상단 값 목록은 이름·값 한 줄과 내용에 맞는 폭으로 간소화. 전체 접기, 목록 높이 선택, 내부 스크롤을 제공하고 터치의 설정·눈·삭제 조작을 유지한다.
- 목록과 연구 창의 공간을 함께 계산하고 짧고 넓은 화면은 가로로 나눈다. 여러 연구 창은 선택·이동으로 접근하며 최소화·숨김·삭제·최대화·독립 축을 보존한다.
- **차트 집중 보기 → 정보 다시 표시**로 정보를 일시 감추고 복원. 저장된 지표·창 상태를 바꾸지 않는다.
- 주요 사건·기간·날짜 이동·축·상태를 한 줄 하단에 통합. 모바일 기간 선택과 더보기, 위로 펼치는 사건 목록으로 추가 조작에 접근한다.
- 모바일 트레이의 SVG 크기·닫기, **차트 내보내기**, **작업 화면·공유** 진입점을 정리. 가상 키보드에 대응하는 대화상자 높이와 고정 제목·저장 영역을 적용한다.
- 폭에 맞는 가격축 여백·숫자 표시를 일·시간·빈 차트와 export에 연결. 20개 합성 포인터 회귀로 드래그 마지막 좌표, 축·값 추적·pinch 전환과 취소를 보강한다.
