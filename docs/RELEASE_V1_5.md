# Bitcoin Cycle Atlas v1.5.0

TradingView의 최신 공식 안내를 다시 조사해 상단·좌측·중앙·우측·하단의 역할을 정리했습니다. 자주 쓰는 차트 조작은 바로 보이는 위치에 두고, 상세와 근거는 하나의 우측 패널에서 읽습니다.

## 다섯 영역

- **상단:** BTCUSD, 1D·1W, 그래프 종류, 다섯 미래 가정, SVG 저장, 설정.
- **좌측:** 십자선(C), 이동(H), 두 지점 측정(M), 측정 지우기, 확대·축소·초기화.
- **중앙:** 실제 가격과 미래 가정, 가격·날짜 십자선, 고저점·D-day. 포인터를 따르는 가격과 우측에 고정한 선택값을 구분.
- **우측:** 선택 데이터, 레이어, 모델과 검증, 다음 후보 이동, 차트·리서치·원자료 페이지, 도움말.
- **하단:** 가까운 6개월·3년 전망·전체, 날짜 이동, 로그·선형, 자동 축 상태, 기본 기간 맞춤, UTC와 KST 갱신 확인 시각.

상단 1D·1W는 가격의 표시 간격이고 하단 기간 버튼은 화면에 보이는 범위입니다. 6개월은 최근 45일과 앞으로 6개월, 3년 전망은 최근 1년과 앞으로 3년, 전체는 2010년부터 앞으로 3년을 표시합니다. ‘자동’은 축 맞춤의 현재 상태이며 버튼이 아닙니다.

900px보다 넓은 화면에서는 상세가 기본 320px로 도킹하며 경계로 폭을 조절합니다. 900px 이하에서는 차트 위에 겹쳐 열고 배경 조작을 막으며, Tab·Escape·포커스 복원을 제공합니다. 하단은 데스크톱 한 줄, 620px 이하 두 개의 작은 줄로 표시합니다.

## 실제 가격을 사용하는 두 지점 측정

두 날짜의 일별 가격을 골라 경과 UTC 일수, 달러 차이와 변화율을 차트에서 확인합니다. 클릭과 Enter·Space를 지원하고 측정 지우기·Escape로 제거합니다. 미래 지점을 포함하면 ‘가정 포함’으로 표시합니다. 관측값 대조에서 2026-02-05 → 2026-06-30은 145일·약 −$4,969.61·−7.826817%로 독립 원자료 계산과 일치했습니다.

## 모델 범위는 유지

**이번 버전은 모델 입력을 확장한 릴리스가 아닙니다.** 현재 모형은 날짜·일별 가격에서 수익률·국면·최근 변동성을 계산합니다. 시가총액·공급·거래량·유동성·ETF 흐름은 수집·모형 연결·추가 효과 검증이 구현되지 않았습니다. 거시 기간과 가격 수준의 중요한 부분은 지정된 가정입니다. 수식 재현성은 미래 가격이나 전환일의 증명이 아니며, 일관된 예측 우위도 확인되지 않았습니다.

## 확인한 범위와 남은 확인

13개 테스트 파일과 정적 참조 검사를 통과했고, 27개 모듈·5,940개 관측의 단일 HTML을 빌드했습니다. 실제 브라우저에서 360px부터 1366px까지의 화면, 도킹·겹침, 측정·축·그래프 전환과 자료 왕복을 확인했습니다. 실제 휴대전화 하드웨어의 터치 검수는 수행하지 않았습니다. SVG 저장 클릭에 콘솔 오류는 없었으나 다운로드 포착이 시간 제한으로 끝나 실제 다운로드 파일은 검증하지 못했습니다.

공개 커밋·CI·Pages·릴리스 첨부 해시의 확인 결과는 아래 검증 기록에서 별도로 관리합니다. 정확한 소스와 실제 실행 링크로 공개 상태를 확인할 수 있습니다.
