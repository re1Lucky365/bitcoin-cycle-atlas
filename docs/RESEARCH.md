## 확인한 핵심 기능

원본의 자가 설명과 [2024년 이용 기록](https://bitcointalk.org/index.php?topic=5512441.msg64612416)을 종합하면 핵심은 네 가지 출발점을 선택해 과거 가격 경로를 같은 시작가격으로 맞추는 비교 도구입니다.

| 기준 | 원본에서 확인한 개념 | 이 구현의 명시적 규칙 |
|---|---|---|
| 반감기 | 반감기를 출발점으로 여러 시기를 비교 | 네 실제 반감기 날짜의 Coin Metrics UTC 일말값 |
| 저점 | 이전 고점과 다음 반감기 사이의 저점 | 명시된 역사 고점부터 다음 반감기 전날까지의 최소 일말값 |
| 고점 | 다음 반감기 이전 고점이라는 설명과 역사적 시장 고점 사용 기록 | 2011·2013·2017·2021년의 연간 최고 일말값, 2025년은 잠정 시장고점 기준 |
| 이전 고점 돌파 | 이전 구간의 고점을 넘어선 날부터 비교 | 역사 저점 뒤 일말값이 등록된 이전 고점 가격을 처음 엄격히 초과한 날짜 |

원본은 과거의 시작가격을 현재 시작가격에 맞춰 스케일링했습니다. 실제 스크린샷에는 **환산된 차트와 실제 관측 가격을 구분하는 툴팁**, 로그 USD 축이 보입니다. 이 구현은 그 분석 방식을 유지하고 한국어 조작부, D+경과일 축, 100 기준 지수, 원자료 탐색, 다운로드, 계산 규칙 공개를 더했습니다. 시각 디자인과 프런트엔드 코드는 새로 작성했습니다.

### 원본의 고점 설명과 실제 범례 차이

2024-10-08 게시물에는 고점 비교의 최신 기준이 **2021년 11월**로 기록되어 있습니다. 이미 2024년 사전 반감기 구간에서 새로운 최고가가 나타났으므로, 이를 기계적으로 “다음 반감기 전 모든 관측 중 최고값”이라고 해석하면 실제 범례와 일치하지 않습니다. 따라서 이 구현에서는 **역사적으로 선택한 고점 연도의 연간 최댓값**이라는 계산 규칙을 직접 명시했습니다. [근거 게시물](https://bitcointalk.org/index.php?topic=5512441.msg64612416)

Coin Metrics 데이터에서도 2020 반감기부터 2024 반감기 전날까지의 최고 일말가는 **2024-03-13, $73,081.5759053185**입니다. 이 구간 최댓값을 2021년 고점이라고 부르지 않습니다. 반감기 비교와 역사적 고점 비교는 서로 다른 기준 선택입니다.

### 약 4년 비교 창과 정확한 1,461일 선택

원본 기록에는 2012년 11월부터 2016년 11월까지의 반감기 경로가 있습니다. 이는 실제 다음 반감기인 2016년 7월에서 자르지 않았다는 증거입니다. 저점 범례에도 2011년 11월–2015년 11월, 2015년 1월–2019년 1월, 2018년 12월–2022년 12월처럼 약 4년 창이 나타납니다. 다만 원본이 1,460일, 1,461일, 달력 4년 중 무엇을 정확히 사용했는지는 확인하지 못했습니다. ## 데이터 출처와 실제 확보 결과

데이터는 [Coin Metrics Community](https://gitbook-docs.coinmetrics.io/packages/coin-metrics-community-data)의 `btc` / `PriceUSD` / `1d`입니다. 공식 [지표 정의](https://github.com/coinmetrics/docs-website/blob/master/asset-metrics/market/priceusd.md)는 이를 **표시된 날짜의 UTC 일말 기준가격**으로 설명합니다. 거래소별 실시간 시세나 장중 고저가와 동일한 값은 아닙니다.

| 항목 | 번들 스냅숏 |
|---|---|
| 최초 조회 시각 | 2026-10-21T09:16:20.212060+00:00 |
| 최신 독립 재대조 | 같은 날 10:40 UTC 전체 5,939행 일치; 10:39:14 UTC 최근 477행도 일치 |
| 첫 관측 | 2010-07-18 |
| 마지막 완료 관측 | 2026-10-20 |
| 관측 수 | 5,939 |
| 내부 결측일·중복 날짜 | 각각 0 |
| 값 검증 | 모든 가격이 양의 유한 숫자 |
| 마지막 일말 가격 | $82,898.9101560549 |
| 전일 대비 변화 | +1.1971841272% |
| API 응답 SHA-256 | `693094ea9309268ef608b97a4eaebac26eae2f8a128629c5c09416ffa8f9fb93` |

[번들 JSON](../dist/data/btc-daily.json)은 이 관측값과 출처·조회 시각·라이선스·응답 해시를 함께 담습니다. 가격을 합성하거나 소수의 예시 값으로 전체 경로를 보간하지 않았습니다.

실제로 검증한 키 없는 API 주소는 다음과 같습니다.

```text
https://community-api.coinmetrics.io/v4/timeseries/asset-metrics?assets=btc&metrics=PriceUSD&frequency=1d&start_time=2010-07-18&end_time=2026-10-21&page_size=10000
```

이 호스트는 HTTP 200과 `Access-Control-Allow-Origin: *`를 반환했습니다. 당시 새 문서에 기재된 `api.coinmetrics.io` 호스트의 동일한 키 없는 요청은 HTTP 401이어서, 구현은 실제 성공한 Community 호스트를 사용합니다. [공식 API 문서](https://docs.coinmetrics.io/api/v4/)

초기에 확보한 [공식 GitHub CSV](https://github.com/coinmetrics/data)는 마지막 유효 가격이 2026-05-23이었습니다. 이를 최신 자료로 표시하지 않고, 전체 API를 다시 조회해 **단일 API 응답으로 최신 번들 전체를 구성**했습니다.

### 갱신과 실패 처리

페이지는 번들 또는 최근 검증 캐시를 먼저 표시합니다. UTC 오늘과 마지막 관측일의 차이가 2일 이상이면 페이지를 열 때 갱신을 시도하며, 버튼으로 수동 갱신도 가능합니다. 사이트가 닫혀 있을 때 별도 서버가 정기 수집하는 방식은 아닙니다.

갱신 과정은 자산, UTC 자정의 일별 날짜 라벨, 실제 달력 날짜, 양의 유한 가격, 중복과 정렬, 필요한 역사 범위·반감기 날짜를 검사합니다. UTC 오늘과 미래의 미완료 관측은 제외합니다. 다음 페이지는 같은 origin·경로·조회 조건만 허용하고 반복이나 10페이지 초과를 오류 처리합니다. API·네트워크·스키마 오류 또는 더 오래된 데이터는 기존 검증 데이터를 대체하지 않습니다. 결측은 빈 상태로 유지하고 화면의 선도 결측을 건너 연결하지 않습니다.

각 행의 고점은 명시된 연도 내 최고 일말값입니다. 저점은 그 고점부터 다음 반감기 전날까지의 최소값이며, 돌파는 저점 뒤 일말값이 등록된 고점 가격을 **엄격히 초과**한 최초 날짜입니다. 날짜는 모두 UTC입니다.

| 고점 연도 | 고점 날짜 | 고점 USD | 후속 저점 날짜 | 저점 USD | 최초 고점 돌파 |
|---|---|---:|---|---:|---|
| 2011 | 2011-06-08 | 29.029921 | 2011-11-18 | 2.105066 | 2013-02-19 |
| 2013 | 2013-12-04 | 1,134.932231 | 2015-01-14 | 175.637641 | 2017-02-23 |

| 2025 | 2025-10-06 | 124,824.453667 | 구간 미완료로 미채택 | — | 미관측 |

2025년 연간 최고값은 완결된 연도에서 계산한 값입니다. 그러나 그것이 **현재 시장 사이클의 최종 고점**이라는 판단은 확정할 수 없으므로 화면에는 잠정 기준으로 표시합니다. 다음 반감기로 구간이 닫히지 않은 2026년 저점 후보는 저점 모드에 추가하지 않았습니다.

2022년의 데이터상 저점은 **11월 9일 $15,758.2912819988**입니다. 11월 21일은 **$15,778.0174047341**로 조금 더 높습니다. 두 날짜의 값은 공식 API와 공식 CSV가 일치했습니다. 장중 최저가나 개별 거래소 종가에서 널리 알려진 날짜를 이 데이터에 그대로 대입하지 않았습니다.

이 고점 연도 선택과 사후 최솟값 선택에는 미래 정보가 들어갑니다. 과거 시장을 비교하기 위한 기준이지, 당시 실시간으로 확정할 수 있었던 신호라는 뜻은 아닙니다.

### 수식과 동일 경과일

```text
경과일 = 관측 UTC 날짜 − 기준 UTC 날짜
가격 배수 = 실제 가격 / 기준 가격
100 기준 지수 = 가격 배수 × 100
환산 USD = 가격 배수 × 최신 기준 가격
수익률(%) = (가격 배수 − 1) × 100
낙폭(%) = (현재 가격 / 해당 범위의 이전·현재 누적 최고가 − 1) × 100
```

시간축은 행 번호가 아닌 UTC 날짜 차이입니다. 로그 축은 양수인 환산 가격·지수에 적용하며, 0이나 음수가 가능한 수익률에 일반 로그를 적용하지 않습니다.

2026-10-20의 2024 반감기 기준 경과일은 **D+913**입니다. 같은 경과일을 독립적으로 검산한 결과는 다음과 같습니다.

| 기준 반감기 | 동일 D+913의 실제 날짜 | 기준일 대비 수익률 |
|---|---|---:|
| 2012 | 2015-05-30 | +1,787.7326595% |
| 2016 | 2019-01-08 | +512.4200183% |
| 2020 | 2022-11-10 | +104.1697974% |
| 2024 | 2026-10-20 | +27.7175684% |

비교 엔진의 과거 중앙값은 같은 경과일의 관측을 가진 역사 사이클만 사용합니다. 숨긴 차트 경로와 무관하게 전체 역사 표본으로 계산하며, 현재 경로는 중앙값 표본에 넣지 않습니다. 표본이 없으면 값도 표시하지 않습니다.

### 고점권과 현재 구조의 검산

2025년 7월 최고 일말가 $120,068.01은 10월 6일 $124,824.45의 **96.1895%**였고, 남은 최고값 갱신 폭은 **3.9615%**였습니다. 95% 첫 진입은 **2025-07-13**이며 절대 최고가보다 **85일** 앞섭니다. 이 85일은 같은 사이클 내부 간격이지 이전 사이클보다 빨라진 정도가 아닙니다.

같은 95% 사건을 이전 회차의 달력 4주년과 비교하면 **98일·3.22개월**, 최근 두 회차의 반감기 경과일 중앙값과 비교하면 **76.5일·2.51개월** 빠릅니다. 90% 기준은 2021년 봄의 첫 고점권을 포함하여 최근 두 회차 반감기 기준에서 이번 진입이 **31일 늦습니다**. 임계값을 바꿔도 언제나 3~5개월 선행한다는 설명은 성립하지 않습니다.

7월 10일~10월 6일의 89개 관측 중 90% 이상은 **69개·77.53%**, 95% 이상은 **16개·17.98%**였습니다. 95% 최초 진입일부터 계산하면 관측 수가 86개여서 **16/86·18.60%**입니다. 분모가 다른 구간을 구별합니다. 95%의 7일 중 5일 지속은 **10월 6일**에야 확인됩니다.

현재 최고가 이후 **379일 = 고점→저점 후보 267일 + 이후 112일**입니다. 2026년 6월 30일 이후 최신 가격까지 **41.65% 반등**했으므로 최고가 미회복 기간과 지속적인 하락 기간을 같은 것으로 취급하지 않습니다. 저점의 달력 앞당김 **132 = 33 + (366−267)**은 정확한 날짜 항등식이며 원인이나 다음 반복의 증명이 아닙니다.

### 미래 날짜·가격은 조건부 계산

현재 저점 유지 모형은 과거 저점→다음 고점의 **1,059·1,062·1,067일**을 현재 후보에 더합니다. 고점 사례 환산 창은 **2029-05-24~06-01**이고, 현재의 고점권→최고가 85일 간격을 유지하면 95% 고점권은 **2029-02-28~03-08**입니다. 완결된 과거 하락기간 **364·366·406일**을 적용한 후속 저점은 **2030-05-23~07-12**입니다. 이번 **267일** 하락 반복은 별도 민감도로 **2030-02-15~02-23**입니다.

+48개월 모형의 고점은 **2029-10-06**, 저점은 **2030-06-30**입니다. 추가 3·4·5개월 단축은 이를 각각 달력 이동한 가정이며, 추정한 가속률이 아닙니다. 현재 저점 유지 모형에는 같은 단축을 추가하지 않아 이중 반영을 피했습니다. 미래 반감기의 미확정 날짜도 임의로 계산에 넣지 않았습니다.

고점가격은 `Q_next(α) = Q_current × (Q_current / Q_previous)^α`, α=0.50·0.75·1.00으로 **$169,692.77·$197,854.15·$230,689.06**을 산출합니다. 저점가격은 역사적 잔존비율을 적용한 가정 조합의 범위 **$26,260.98~$108,160.66**입니다. 현재 후보의 잔존비율은 미확정 값으로 구분합니다. 대표 점선은 편의상 α=0.75와 직전 완료 사이클의 잔존비율을 사용하며 기대값이 아닙니다.

점선은 가정한 사건 사이를 로그 가격으로 보간한 연결선입니다. 날짜 창·가격 음영 모두 확률·신뢰구간이 아니며 실제 결과는 밖에 있을 수 있습니다. 가격 가정은 전고점 갱신을 전제로 하므로 낮은 고점·장기 횡보 등 모든 미래 가능성을 포괄하지 않습니다. 유한한 과거만으로 최종 고점·저점이나 미래 날짜를 증명할 수 없습니다.

### 과거 검증에서 불리한 결과도 보존

2019-03-31과 2023-03-31에서 자료를 잘라 당시 정보만으로 재생했습니다. 90·180·365일 평균 절대백분율오차는 재생 **44.35·56.22·20.39%**, 가격 불변 기준 **36.06·29.13·47.73%**였습니다. 따라서 90일·180일에서는 단순한 가격 불변 기준이 더 낫고 365일에서는 재생이 더 낫습니다.

기준일은 사후 선택한 2개이며, 세 기간도 같은 시장 국면을 공유합니다. 이 결과는 6개의 독립 실험이나 미래 적중률이 아닙니다. 2025년 이후 현재 사이클은 검증 결과에서 제외했습니다. 730일 성능, 거시 사건일, α 가정, 확률 밴드 포함률을 검증한 것은 아닙니다. 방법론의 원칙은 [Forecasting: Principles and Practice 제5장](https://otexts.com/fpp3/toolbox.html)의 과거 정보만 쓰는 시계열 검증과 확률 예측구간 정의를 참고했습니다.
