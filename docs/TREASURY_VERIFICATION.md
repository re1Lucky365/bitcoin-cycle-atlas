# MSTR·BMNR·통합 리서치 검증 기록

검토일: **2026-10-24**. 대상 버전: **v1.18.0**. 이 문서는 재무 입력의 일관성, 모델 계산, 출처 연결과 화면 동작의 검증 범위를 기록합니다. 미래 수익률·가격 적중률을 검증한 보고서는 아닙니다. 공개 배포의 최종 상태는 해당 소스 커밋의 GitHub Actions 실행 및 릴리스 메타데이터로 확인합니다.

## 1. 출처와 금융 입력

MSTR 32개·BMNR 22개 신규 출처에서 공식 공시·회사 설명·외부 분석·발췌 확인·메타데이터만 확보한 자료를 구분했습니다. 동일 회사의 보도자료와 SEC 첨부자료가 일치하는 것은 발행사 기록의 일관성입니다. 독립적인 수탁 잔액 감사로 세지 않습니다. X 접근 실패와 일부 PDF 발췌 확인은 접근 상태와 한계로 남겼습니다. 모든 영상·게시물을 빠짐없이 열람했다는 주장은 하지 않습니다.

같은 재무 기준일의 기말 보통주 수를 사용하며 EPS 가중평균 주식 수·가정 전환주식 수를 섞지 않습니다. 전환사채를 원금으로 차감할 때 해당 전환주식을 다시 분모에 더하지 않습니다. BMNR 2026-05-31 공시 수치로 계산한 보통주 장부 순자산은 $11,599,577,000과 일치합니다. 이후 최초 우선주 발행의 순현금·청산우선권·배당은 별도 조정으로 기록합니다.

MSTR의 2027–2029년 현금상환 청구 가능일별 원금 합계는 기준 원금 $6,713,659,000과 같습니다. 계약상 선택권 행사 여부와 미래 차환 가능성을 확정할 수 없으므로 모델에서는 전액 행사라는 조건을 명시합니다. 상세 수치와 출처는 [독립 교차검토](TREASURY_MODEL_REVIEW.md), [MSTR 조사](research/mstr-2026-10-24.md), [BMNR 조사](research/bmnr-2026-10-24.md)에 있습니다.

## 3. 모델의 직접 검사

`node tests/treasury-model.test.mjs`에서 **23개 검사**를 직접 실행했습니다. 단순 구현 반복보다 자본구조의 일관성을 확인하는 반례에 집중합니다.

- 같은 가격에서 원금 상환은 현금과 채무를 함께 줄입니다. 원금을 비용으로 다시 차감하지 않습니다.
- 자금이 부족하면 미지급액이 부채로 남습니다. 보유 코인 수가 음수가 되거나 부족액이 사라지지 않습니다.
- 순발행가와 주당 순자산의 관계, 주당 코인 수 증가의 별도 조건, 신규 주식의 분모 반영을 검사합니다.
- BTC에는 ETH 스테이킹 손실을 적용하지 않습니다. 기타 자산 할인은 BMNR에 한정합니다.
- 가장 최근 경영진 발표를 선택하고 자체 스트레스와 외부 가격조건의 출처를 분리합니다.
- 연구 지식일 이전 cutoff와 미래 재무·시장 입력을 거부합니다. 현재 연구를 과거 백테스트에 몰래 이용하지 않습니다.
- 세 조건의 날짜 격자가 같고 범위가 모든 경로를 포함하며 첫 값이 실제 주가와 같습니다.
- 순자산 소진 이후 가격 0은 명시한 청산 스트레스 규칙입니다. 법적 파산 시점을 예측하는 테스트가 아닙니다.

세부 수식·실제 조건부 출력과 누적 조달 요구량은 [모델 설명](TREASURY_MODEL.md)에 있습니다. 발행 규모의 시장 흡수 가능성, 미래 프리미엄, 세금과 모든 후속 자본거래의 복원은 검증하지 않았습니다.

## 4. 연구 글과 미래 근거

`tests/research-reader.test.mjs`의 **7개 직접 검사**는 488개 보관 Markdown의 본문·바이트·SHA-256이 리더 다운로드와 같은지, 492개 정식·별칭 ID가 해소되는지, 출처·교차검토 연결이 끊어지지 않는지 확인합니다. 원문 미디어의 온라인 가용성이나 제3자 전문의 완전 보관을 검증하는 검사는 아닙니다.

`tests/forecast-evidence.test.mjs`의 **7개 직접 검사**는 실제 BTC 기준·스트레스 모델의 미래 표식, 계산법과 기관 목표의 구분, 화면 범위 밖 표식 제외, 키보드·클릭 라우팅, 좁은 차트의 표식 간격과 빈 상태 초기화를 확인합니다. 미래 표식의 날짜는 공시 일정·계약 선택권·목표 연도·모델 설명 위치로 구분합니다.

연구 입력과 생성 카탈로그·Markdown이 다르면 `npm run verify:research`가 실패합니다. 원문 접근 수준·확인 한계는 [보존 설명](RESEARCH_PRESERVATION.md)을 따릅니다.

## 5. 실제 브라우저 화면

Chromium headless를 사용해 **1440×900 데스크톱, 390×844 모바일**에서 MSTR·BMNR을 각각 열고 실제 관측 가격, 일·주봉, 선·캔들, 역사 사건, 미래 근거, 시나리오 선택과 리서치 리더를 확인했습니다. 모바일은 Chromium의 touch 입력으로 차트 이동을 실행했습니다. 네 조합에서 JavaScript 오류와 문서의 가로 넘침이 없었습니다.

BTC 기본 화면의 미래 근거를 직접 클릭해 리더가 열리는지 별도로 확인했습니다. `?page=evidence&research-asset=BMNR`의 필터와 글 열기, 모바일 전체 높이 리더·닫기 버튼도 확인했습니다. 밝은 리더에 기존 어두운 대화창의 작은 글씨·회색이 상속되는 문제는 전용 본문 스타일로 수정했습니다.

이는 데스크톱 Chromium의 모바일 화면·터치 에뮬레이션입니다. 이번 변경에 대해 실물 Android·iOS·보조기기·모든 브라우저를 검증했다는 뜻은 아닙니다.

새로 생성한 단일 HTML을 네트워크가 차단된 상태에서 MSTR·BMNR × 데스크톱·모바일 네 조합으로 실행했습니다. 실제 가격, 2030·2035 자금조달 비교표, 미래 근거, 연구 리더와 Blob 기반 MD 다운로드가 동작했고 JavaScript 오류·문서 넘침이 없었습니다. 검사 컨테이너에 한국어 운영체제 글꼴이 없어 오프라인에서는 일부 글자가 사각형으로 표시되는 환경 한계가 있습니다. 온라인 화면은 웹 글꼴을 읽어 한국어를 표시했습니다. 별도 한국어 글꼴이 없는 운영체제에서 오프라인 글꼴까지 보장하는 시험은 아닙니다.

## 6. 빌드와 배포 검증 경계

전체 저장소 회귀 검사는 `npm test`로 수행합니다. Node test runner가 파일 단위로 집계하므로 파일 합계와 개별 assertion 합계를 혼용하지 않습니다. 정적 링크·ES 모듈·JSON 검사, 단일 HTML의 주식 데이터 포함 검사는 `verify:static`에 포함됩니다.

최종 로컬 실행은 **88개 테스트 파일 통과, 실패 0**이었습니다. 연구 생성물 검사는 출처 54개·역사 사건 43건·글 488개·ID 492개와 보관 Markdown 891,455바이트를 확인했습니다. 정적 검사는 625개 배포 파일·257개 참조, 단일 HTML은 90개 모듈·41,066,466바이트의 당시 빌드로 통과했습니다. 이후 빌드 크기와 소스 커밋의 최종 식별자는 릴리스 메타데이터와 파일 해시를 따릅니다.

기존 BTC의 사이클 교정·차트 복잡도 검사를 유지합니다. 복잡도 검사의 100개 SVG 노드·120개 예산은 제한된 계산 복잡도 검사이며 실제 브라우저 프레임 벤치마크가 아닙니다. TLA+ TLC 검사는 제한된 요청 소유권 상태 공간과 실패해야 하는 반례를 확인하며 금융 가격 모델의 정당성을 증명하지 않습니다.

CI·Pages·Release에서 연구 생성물과 소스를 검사합니다. 릴리스는 깨끗한 소스 트리에서 생성하며 버전과 태그, 태그와 테스트한 커밋이 일치해야 합니다. 기존 태그를 다른 커밋으로 옮기거나 이미 배포한 서로 다른 파일을 덮어쓰지 않습니다. 각 자산의 SHA-256과 정확한 소스 커밋을 함께 제공합니다.
