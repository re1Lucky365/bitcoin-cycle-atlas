# 실제 분·시간봉과 캔들 표시

## 자료와 시간

자료 출처는 Coinbase Exchange의 공개 `BTC-USD` candles API다. 이 값은 한 거래소의 실제 거래 OHLCV이며, 기존 장기 그래프의 Coin Metrics `PriceUSD` 일말 지수와 가격 정의가 다르다. 거래소 OHLC가 없는 날짜의 일말 가격을 가짜 시가·고가·저가로 바꾸지 않는다.

- 공식 문서: https://docs.cdp.coinbase.com/api-reference/exchange-api/rest-api/products/get-product-candles
- 공개 API: https://api.exchange.coinbase.com/products/BTC-USD/candles
- 문서 및 실제 응답 확인일: 2026-10-22.
- 배열 필드: Unix 초 기준 봉 시작 시각, 저가, 고가, 시가, 종가, BTC 거래량.
- 표시는 UTC이며 완료된 봉만 포함한다. 수집 시각과 마지막 봉 시각을 구분한다.
- 거래가 없어 비어 있거나 제공되지 않은 구간은 임의 가격으로 채우지 않는다.
- 실시간 거래 스트림이 아니다. 최초 요청과 명시적 새로고침으로 완료 봉을 조회하며, 현재 진행 중인 봉은 표시하지 않는다.

## 표시 간격

| 버튼 | 기초 자료 | 집계 |
|---|---|---|
| 1m | 60초 OHLCV | 원자료 |
| 5m | 300초 OHLCV | 원자료 |
| 15m | 900초 OHLCV | 원자료 |
| 30m | 900초 OHLCV | 연속된 15분봉 2개 |
| 1h | 3,600초 OHLCV | 원자료 |
| 4h | 3,600초 OHLCV | 연속된 1시간봉 4개 |
| 1D | 86,400초 OHLCV | 원자료 |
| 1W | 86,400초 OHLCV | 월요일 00:00부터 일요일 말까지 일봉 7개 |

집계 OHLC는 첫 시가, 실제 고가의 최댓값, 실제 저가의 최솟값, 마지막 종가이며 거래량은 합계다. 구성하는 봉이 하나라도 없으면 해당 집계 봉을 만들지 않는다. 4시간봉은 UTC 00:00·04:00·08:00·12:00·16:00·20:00 시작이다. 주봉은 주의 마지막 날짜에 그리되 상세 정보에 월요일부터 일요일까지 실제 범위를 표시한다.

조회는 요청당 최대 290개 기초 봉으로 나누어 공식 문서의 300개 제한 안에 둔다. 제공자가 요청 시작 시각보다 앞선 자료나 끝 경계 봉을 함께 반환해도 각 요청의 반열린 구간 `[start,end)`로 걸러 중복을 막는다. 공급자 응답의 중복 시각, 모순된 OHLC, 비정상 수치와 정렬 조건은 검증한다.

## 장기 전망과의 연결

분·시간 간격은 완료된 거래소 봉만 표시한다. 일·주 간격에서는 최근 실제 OHLC를 캔들로 보면서 장기 미래 가정의 점선을 유지할 수 있다. 캔들 제공 범위 이전은 Coin Metrics 일말 가격선으로 표시한다. 장기 모델의 기준일 이후 거래소 봉은 이 그래프에 끼워 넣지 않는다.

미래 점선의 시작값과 일별 국면·고점·저점 분석은 기존 Coin Metrics 기준을 유지한다. 실제 캔들 종가는 거래소별 가격 차이 때문에 점선의 기준값과 조금 다를 수 있다. 캔들의 변화율은 해당 봉의 시가 대비 종가이며, 일말 가격선의 변화율은 전일 종가 대비다. 선택한 캔들의 상세에는 시가·고가·저가·종가·거래량과 출처를 표시한다.

## 실패 및 저장 자료

공개 API가 실패하면 `dist/data/btc-ohlc.json`의 검증된 실제 저장 자료로 표시를 이어 간다. 저장 자료의 원래 수집 시각을 그대로 보여 주며 현재 가격 또는 실시간 자료로 표시하지 않는다. 원격 조회와 저장 자료 모두 실패하면 오류 상태를 표시한다. 간격을 바꾼 뒤 이전 요청이 도착해도 새 간격의 차트를 덮어쓰지 않는다.

저장 자료 재생성:

```sh
node scripts/refresh-ohlc.mjs
```

이 파일은 1m·5m·15m·30m·1h·4h·1D 각 180개, 1W 100개의 완료 봉을 보관한다. 브라우저의 새 조회는 표시 목적에 따라 더 많은 봉을 요청할 수 있다. 조회 수와 화면에 보이는 구간은 무제한 전체 거래 이력이 아니다.

## 검증

`tests/ohlc-data.test.mjs`는 원자료 필드 순서, 완료 경계, OHLC 오류 거부, 30분·4시간·주간 집계, 빠진 봉, 요청 분할·경계 중복 제거, 취소·HTTP 오류, 저장 시각 보존을 검증한다. `tests/chart-math.test.mjs`는 좁은 가격 범위에서 로그축이 분봉의 움직임을 지나치게 축소하지 않는지도 확인한다. 통합 화면과 모바일 범례 위치는 실제 브라우저에서 별도로 확인한다.
