# v1.25.0 · 자산 비교표와 다섯 단계 판단

## 사용자가 지정한 표

최근에 지정한 두 번째 이미지를 열·종목 구성으로, 첫 번째 이미지를 격자·색상 스타일로 사용한다. 이전의 세로형 BTC 사이클 판단표를 이 페이지에서 교체한다. 제목·메뉴·브라우저 제목은 **자산 비교표**다.

표는 하나이며 SPY, QQQ, NVDA, AAPL, GOOG, MSFT, AMZN, META, AVGO, PLTR, TSLA, HOOD, TLT, IEF, GLD, SLV, PDBC를 모두 표시한다. 자산군·분류·종목명, 표본 연수, 평균 상승%, 평균 낙폭%, 올해 첫 거래일 종가, 최근 종가, 연초 대비 등락률과 마지막 **판단** 열로 구성한다. 최신 날짜는 원자료에서 읽으며 참고 이미지의 과거 날짜·가격을 복사하지 않는다. 이동평균·RSI 열이나 관련 판정을 다시 도입하지 않는다.

대형 기술주 분류에 AVGO가 포함돼 있으므로 이를 잘못된 M7 명단으로 표시하지 않는다. 참고 이미지의 위험/안전 자산 구분은 무위험 보장을 뜻하지 않는다. 모바일은 종목명을 고정한 가로 스크롤과 자연스러운 세로 스크롤을 사용한다.

## 자료와 표본

초기 배포 자료는 **2026-10-23** 완료 거래일까지 **97,987개 일별 종가**다. 상장 초기까지 확보한 일별 자료를 바탕으로 표본 수를 계산하며, **현재 2026년은 평균 계산에서 제외**한다. 최초 상장 연도의 일부 기간을 포함하므로 표본 수는 완전한 12개월 연수와 다를 수 있다. 해당 셀에는 별표와 실제 관측 시작일을 제공한다.

PDBC는 2014-11-07부터 관측되므로 2014–2025의 **12개 연도**다. 이미지의 11년을 맞추기 위해 데이터를 빼지 않는다. 개별 가격의 기준은 Yahoo Finance의 분할 반영 종가이며 배당·분배금은 제외한다. 공급자 정의, 첫 거래일, 조회 시각, 응답 SHA-256과 같은 공급자의 별도 구간 재조회 결과는 [자료 확보 문서](ASSET_COMPARISON_DATA.md)에 기록한다. 이를 독립된 두 가격 공급자의 전체 데이터 검증으로 표현하지 않는다.

## 평균 낙폭과 MDD를 구별

각 과거 연도 y의 첫 관측 종가를 Bᵧ로 두고, 연중 최고·최저 **종가**를 사용한다.

- 연간 상승 = 100 × (연중 최고 종가 / Bᵧ − 1)
- 연간 낙폭 = 100 × (연중 최저 종가 / Bᵧ − 1)
- 표의 평균값 = 해당 연간 값의 동일 비중 산술평균

평균 낙폭의 기준은 고정된 연초 가격이다. MDD는 **앞서 나타난 고점 이후**의 최대 하락이므로 다른 값이다. 예를 들어 100 → 150 → 120에서는 연초 기준 낙폭이 0%이고 MDD는 −20%다. 엔진은 별도 감사용 연간 MDD도 계산하되 표의 평균 낙폭에 섞지 않는다.

## 마지막 열의 판단

U는 과거 평균 상승, D는 음수인 평균 낙폭, r은 올해 첫 종가 대비 최근 종가 변화다. 경계값은 표시용 반올림 전 수치로 비교한다.

| 표시 | 조건 |
|---|---|
| 적극 매수 | r ≤ D |
| 분할 매수 | D < r ≤ D/2 |
| 중립 | D/2 < r < U/2 |
| 분할 매도 | U/2 ≤ r < U |
| 적극 매도 | r ≥ U |

5개 미만의 과거 연도, 확인된 관측 공백, 올해 기준가 부재, 기준일 대비 7일 초과의 오래된 종가, 퇴화된 평균 범위는 **판단 보류**다. 불명확한 데이터를 중립이나 0%로 치환하지 않는다. 각 판단 버튼에서 해당 종목의 평균·현재 변화·실제 경계값·출처를 확인한다. CSV에도 같은 값과 설명을 내보낸다.

이는 과거 가격 범위에 대한 위치 분류다. 평균까지 반드시 반등하거나 평균 상승에 도달한 뒤 반드시 하락한다는 증거는 아니다. 1/2 경계와 5년 최소 표본은 명시적 운영 규칙이며 최적화·검증된 매매 전략이나 주문 비중이 아니다. 분배금 지급으로 인한 가격 하락은 동일한 투자 총손실을 뜻하지 않는다.

## 로딩·갱신·패키징

- 페이지가 숨겨져 있으면 17개 자산 자료를 읽지 않는다. 현재 날짜와 데이터가 같으면 모델을 다시 계산하지 않는다.
- 동시 요청을 합치고, 새로고침은 이전 행·CSV를 먼저 비운 뒤 자료를 다시 가져온다. 실패하면 판단을 보류하며 명시적 재시도만 요청한다.
- BTC 데이터 로딩 실패가 자산 비교표를 가로막지 않도록 페이지 준비 상태를 분리한다.
- 단일 HTML에는 같은 자산 자료를 내장한다. 오프라인에서는 외부 JSON 요청 없이 그 스냅샷을 사용한다.
- 자동 갱신에 전체 이력 재조회와 원자적 교체를 추가한다. 소스가 실패하거나 기존 세션이 잘리면 검증된 이전 번들을 보존한다.

## 검증 범위

v1.25.0 기준 로컬 통합 테스트 **1,015개가 실패·취소·skip 없이 통과**했다. v1.25.1 패치 포함 최종 수치는 **1,017개**다. 새 수집기 회귀 검사 6개, 계산 엔진 23개와 실제 17개 자산 검산을 포함한다. 360개 유한 가격 경로·262개 경계 사례·14개 의도적 코드 오류를 확인했다. 새해 첫 거래일 전의 정상 판단 보류를 검증기가 잘못 실패시키던 문제도 독립 검토에서 수정했다. [실행 결과·입력과 소스 해시](data/asset-comparison-integrated-verification.json) · [수치 검산 결과](data/asset-comparison-verification.json)

`npm test`, `npm run verify:asset-comparison`, `npm run verify:numerics`, 기존 형식 상태·연구·차트 성능 검증, 정적 참조 및 단일 HTML 동일성 검증을 실행한다. 새로운 수치 검산은 실제 17개 자산의 연도별 최고·최저와 시간 순서를 지키는 MDD를 별도 계산으로 대조하고 판단 경계 및 자료 보류 조건을 확인한다. 계산의 일관성 검증이 시장 수익성의 증명으로 확대되지 않도록 [방법론](ASSET_COMPARISON_METHODOLOGY.md)에 한계를 기록한다.

기존 `verify-cycle-table-integration.mjs`는 보존된 BTC 차트·사이클 컨트롤러의 회귀 검증으로 범위를 좁혔다. 새 자산 표의 비동기 로딩·한 개 표·오류 복구·CSV·재사용 동작은 별도의 현행 테스트로 검증한다. 예전 UI 검사 이름만 유지해 새 페이지를 검증한 것처럼 표시하지 않는다.

브라우저 검증 기록과 참고 이미지 비교는 프로젝트 루트의 [디자인 QA](../design-qa.md)에 기록한다.

## v1.25.1 · 모바일 열 겹침 보완

실제 390px 브라우저 검증에서 오른쪽으로 이동했을 때 고정 종목명 셀이 연초 대비 등락률의 앞자리를 가리고, 그 위 머리글에는 최근 종가가 남는 문제를 발견했다. 모바일의 종목명·등락률·판단 열 너비와 머리글을 함께 맞추고, 가로 이동 안내를 추가한다. 데스크톱의 병합 머리글·17개 행 구조와 가격 계산·판단 경계는 유지한다.

v1.25.1 실제 배포에서 390×844 및 320×740의 가로 스크롤 끝에 종목명·전체 등락률·판단이 겹치지 않고 표시되는 것을 확인했다. 320px의 판단 설명창은 가로 넘침 없이 경계값과 출처를 표시하고 정상적으로 닫힌다. 390×430의 짧은 창에서도 마지막 PDBC 행과 하단 설명까지 접근 가능했다. 데스크톱 표와 두 참고 이미지의 비교 및 최종 화면 증거는 [디자인 QA](../design-qa.md)에 기록했다.

패치 포함 전체 테스트 **1,017개 PASS**, 단일 HTML의 96개 모듈·7개 내장 자료와 정적 참조 278개 검증을 통과했다. 추가로 참고 이미지의 12개 자산·24개 평균값이 배당 조정 종가 계산과 일치하는 것을 확인하고, PDBC의 11년 수치가 2014–2024년과 일치한다는 수치 근거를 [대조 기록](data/asset-reference-metric-reconciliation.json)에 남겼다. 원본 계산식의 확인과 수치에서 도출한 추론은 구분한다.
