# v1.22.1 · 일별 원자료·수익률 비교·최대낙폭

BTC·ETH·MSTR·BMNR의 실제 관측을 자산 × 연도 히트맵, 월별 비교, 일별 상세로 연결했다. 수익률과 최대낙폭(MDD)을 같은 화면에서 비교하고 각 날짜의 이동평균·RSI·규칙 신호를 확인할 수 있다. 이미지의 표 구성을 참고하되 확인되지 않은 수익률이나 새 자산의 가격을 원자료로 입력하지 않았다.

v1.22.0 기능의 공개 CI와 Pages 배포 후, 자동 릴리스에 필요한 이 버전별 설명 문서가 빠진 것을 확인했다. v1.22.1은 이 패키징 문제를 보완하며 검증된 화면·계산 코드를 그대로 유지한다.

## 달라진 동작

- 연간 히트맵을 수익률과 연내 MDD 사이에서 전환한다. 2011년 이후 보기와 전체 이력 보기를 제공하고, 연도·월 선택을 해당 일별 관측에 연결한다.
- 일별 표에 종가, 직전 관측 대비, 연초 대비, 전고점 대비, 당시까지 MDD, SMA 50·200, RSI 14와 규칙 신호를 표시한다.
- 각 자산의 전체 누적 수익률·CAGR·MDD와 실제 시작일·종료일을 표시한다. 현재 고점 대비 낙폭과 이전 고점 회복에 필요한 상승률도 함께 확인한다.
- 출처·가격 정의·기준일, 부분기간과 확인된 결측을 표시한다. 전년 말 기준가격이 없는 첫해의 연초 대비 값에는 별도 표시를 붙인다.
- 일별 CSV와 연도별 비교 CSV를 제공한다. 화면의 선택 범위와 계산 기준을 유지하며, 부분기간 여부도 내보낸다.
- 지표를 전체 과거 관측에서 먼저 계산한 뒤 화면 필터를 적용한다. 연도·페이지를 바꿔도 같은 날짜의 지표와 신호를 유지하며, 미래 관측이 과거 판정을 바꾸지 않도록 검사한다.

## 셀 색상과 신호

수익률 셀의 초록·빨강은 이미 발생한 상승·하락을 뜻한다. 별도 신호 셀은 아래 규칙의 충족 여부를 텍스트와 색상으로 함께 표시한다. 규칙 버전은 `sma50-sma200-rsi14-v1`이다.

| 신호 | 조건 |
| --- | --- |
| 매수 · 초록 | 종가 > SMA 200, SMA 50 > SMA 200, 50 ≤ RSI 14 < 70. |
| 매도 · 빨강 | 종가 < SMA 200, SMA 50 < SMA 200, RSI 14 < 50. |
| 중립 · 황색 | 필요한 지표는 준비됐으나 매수·매도 어느 조건에도 해당하지 않음. |
| 자료 부족 · 회색 | 200개의 연속 유효 관측을 채우지 못했거나 확인된 결측으로 지표를 다시 준비하는 구간. |

SMA는 관측 종가의 단순평균이며 RSI는 14개 가격 변화로 초기화한 Wilder 방식이다. 주식은 실제 거래 세션을 사용하므로 휴장일을 가짜 가격으로 채우지 않는다. 큰 MDD나 수익률 셀의 색상만으로 매수·매도를 결정하지 않는다. **이 조합의 수익성·적중률은 검증하지 않았다.** 신호는 해당 종가가 확정된 뒤에 알 수 있는 추세 관찰 규칙이다.

## 계산과 자료 범위

MDD는 선행 고점에서 후행 저점까지 시간 순서를 보존한 **종가 기준** 최대 손실이다. 연간·월간 MDD에는 직전 기간의 마지막 기준 종가를 포함해 기간 시작의 하락도 반영한다. 전체 이력 MDD, 기간 MDD, 특정 날짜의 고점 대비 낙폭을 구별한다.

연간 수익률은 전년 마지막 유효 종가를 기준으로 계산하며, 기준점이 없는 첫 기간과 진행 중인 기간을 표시한다. CAGR는 실제 경과일과 `365.2425`일/년 규약을 사용하고 첫 달력상 기념일 전에는 제공하지 않는다. 2월 29일의 첫 기념일은 다음 해 2월 28일이다. 화면의 연도·월 필터는 별도로 표시한 전체 이력 요약의 계산 범위를 바꾸지 않는다.

BTC는 Coin Metrics 일별 기준 가격, ETH는 Coinbase ETH-USD 완료 일봉, 주식은 Yahoo 제공자 분할조정 종가를 사용한다. 가격수익률은 배당 재투자·스테이킹 보상·세금·수수료를 포함하지 않는다. 자산별 관측 시작일이 달라 전체 누적·CAGR·MDD를 같은 투자기간의 순위로 해석할 수 없다.

- ETH 자료는 2016-05-18부터 시작하며 최초 구간에 이틀의 결측이 있다. 결측은 보간하지 않는다.
- MSTR의 1998년 이후 이력은 BTC 전략 도입 전 닷컴 시기를 포함한다.
- BMNR 자료는 2025-06-05 이후 거래소 관측이며 더 오래된 OTC 시기를 대표하지 않는다.

## 검증

전체 CI에서 **942개 테스트가 통과**했다. 새 기능의 계산 엔진 18개·자료 연결 5개·화면 로직 11개 사례를 포함하며, 미래 정보 사용 방지, 기간 기준가격, 윤일·CAGR 경계, 결측·수치 경계, 부분기간 표시와 CSV 일치를 검사한다. 연구 보존·일별 재무 경로·정형 검증도 통과했다. 정적 검사는 파일 639개와 참조 276개를 확인했으며, 로컬에서 독립 HTML 재생성과 포함 자료·스타일의 일치도 검증했다.

독립 Python 산식으로 네 자산 **17,237개 관측**의 전체 이력 MDD·최신 낙폭과 BTC 연간 수익률을 재계산하고 구현과 대조했다. 이는 계산의 독립 검증이며, 모든 가격을 외부 공급자와 다시 대조했다는 뜻은 아니다. 외부 가격 대조는 Coinbase BTC-USD의 연말·최신 종가 **6개 날짜**를 실제 조회한 범위다.

이미지의 2021년 BTC 수익률 약 +66%는 Coin Metrics의 +59.720367%, Coinbase의 +59.403630%와 달랐다. 이미지의 원자료·기준일이 확인되지 않아 앱 값을 이미지 숫자에 맞추지 않았다. [가격 정의·산식·출처와 제한](DAILY_DATA_RESEARCH.md), [입력 해시·관측 범위·외부 요청 기록](data/daily-data-crosscheck-2026-10-25.json)을 보존한다.

이 릴리스는 pstack의 병렬 분할과 독립 검토 원칙을 실제 사용 가능한 작업자에 적용했다.
