# v1.5 다섯 영역과 차트 조작 검증

검증일: **2026-10-22 UTC**. 이 기록은 통합 담당자의 실제 브라우저·원자료 대조와 별도 담당자의 반응형 검수를 합친 것이다. 상단·좌측·중앙·우측·하단의 배치와 조작을 확인했다. **공개 커밋·CI·Pages·릴리스·첨부 파일 검증은 아직 Pending**이며 아래 표에 별도로 구분한다.

이번 변경은 UI와 차트 조작이다. 원자료와 미래 생성 모형은 변경하지 않았다. **시가총액·공급·거래량·유동성·ETF 흐름의 수집, 모형 연결, 추가 예측 효과 검증은 구현하지 않았다.** 현재 경로는 가격 기반의 조건부 시뮬레이션이며, 이 검수는 미래 예측 정확도의 검증이 아니다. [현재 모델 범위](MODEL_SCOPE.md)

## 변경 범위

| 영역 | 구현한 동작 |
|---|---|
| 상단 | BTCUSD, 일별 1D·주별 1W, 여섯 그래프 선택, 다섯 미래 가정, SVG 저장 진입점, 차트 설정 |
| 좌측 | 십자선 C, 이동 H, 두 지점 측정 M, 측정 지우기, 확대·축소·초기화 |
| 중앙 | 가격·날짜 십자선, 포인터를 따르는 상태줄, 실제·가정 구분, 고저점·D-day, 두 지점 측정 |
| 우측 | 고정한 선택 데이터, 레이어, 모델과 검증, 다음 전환 후보, 차트·리서치·원자료 페이지, 도움말 |
| 하단 | 가까운 6개월·3년 전망·전체, 날짜 이동, 로그·선형, 자동 축 상태, 기본 기간 맞춤, UTC와 KST 갱신 시각 |

리서치·원자료 아이콘은 각 표 페이지로 이동한다. 자료의 근거 상세와 모델 설명은 같은 우측 패널에서 읽는다. 하단은 데스크톱에서 한 줄, 620px 이하에서 두 개의 작은 줄로 배치한다. ‘자동’은 축의 현재 동작을 설명하는 상태이며 버튼이 아니다. [배치 구현](../dist/workbench-chrome.js), [패널 구현](../dist/viewport-workspace.js), [레이아웃](../dist/chart-details-panel.css)

## 가격·날짜와 측정의 독립 대조

두 날짜의 정확한 일별 가격을 원자료에서 별도로 읽어 차트 측정값과 비교했다. 로그·선형 표시 좌표와 관계없이 원래 달러 가격을 사용한다. [측정 계산](../dist/chart-math.js), [측정 표시](../dist/atlas-price-chart.js)

| 실제 관측 측정 | 시작 | 끝 | 독립 계산 결과 |
|---|---|---|---|
| 두 점 클릭 | 2026-02-05, $63,494.6884456458 | 2026-06-30, $58,525.0753614845 | 145일, −$4,969.613084161298, −7.826817023309751% |
| M·키보드 | 2026-06-30, $58,525.0753614845 | 2026-07-01, $60,065.5999105786 | 1일, 약 +$1,540.52, +2.632247% |

첫 측정의 차트 표시와 독립 원자료 계산이 일치했다. 두 번째 측정은 M으로 도구를 선택하고 키보드로 끝점을 정해 확인했다. 미래 예시의 **2026-11-05 → 2026-11-29** 측정은 **24일·약 +17.6%**와 함께 **‘가정 포함’**을 표시했다. 이 미래 수치는 실제 관측 수익률이나 전망의 적중률이 아니다.

## 조작·상태 유지 검수

| 확인 항목 | 실제 결과 |
|---|---|
| 이동 모드 | 2025.10.21–2029.10.22 표시 창을 2025.02.19–2029.02.20으로 이동. 이동만으로 상세 패널이 열리지 않음. |

| 패널 너비 | 키보드로 320 → 340px 조절 후에도 선택 날짜·가격 유지. 1366px에서 패널을 420px까지 확대한 뒤 901px로 축소하면 패널 외곽 339px·차트 480px으로 재제한. `aria-valuemax/now=339` 일치. 레일 테두리 1px 누락을 수정한 뒤 별도 담당자가 재검수. |

| 여섯 그래프 | 가격과 미래·4년 비교·구간 길이·고점권 도달·월·분기·CryptoCon 순서로 도형 수 32/21/16/27/54/15 확인. 전환 시 차트가 실제로 변경. |
| 비가격 레이어 | 해당 그래프에 적용되지 않는 가격 레이어 조작 숨김. |
| 설정 보존 | 시나리오 선택과 체크 상태가 패널 전환 뒤에도 유지. |

## 자동 검사와 산출물 범위

- `npm test`: **13개 테스트 파일 통과**.
- 정적 참조와 Pages 기본 경로 검사 통과: 검수용 임시 파일 제거 뒤 **41개 파일·66개 참조**, `/bitcoin-cycle-atlas/` 기본 경로.
- 단일 HTML 빌드 성공: **27개 모듈, 5,940개 관측**. 브라우저에서 내장 데이터 차트와 새 다섯 영역, 모델 패널의 미구현 입력 표시를 확인했다. 최종 단일 HTML은 **4,321,831바이트**이며 릴리스 첨부 해시는 공개 패키지가 만들어진 뒤 확인한다.
- SVG 저장 버튼 클릭에서 콘솔 오류는 관찰되지 않았다. 그러나 브라우저 다운로드 포착이 **12초 제한으로 끝나 실제 내려받은 SVG 파일은 검증하지 못했다.** 내보내기 파일 검증을 통과로 기록하지 않는다.
