# 3년 전망 구현 검증

검증 기록일: **2026-10-21**. 대상은 [3년 모델 설명](THREE_YEAR_MODEL.md), [고정 계산 결과](THREE_YEAR_RESULTS.json), `dist/`의 정적 웹 앱이다. [README](../README.md)에서 실행 방법과 공개 배포 상태를 확인할 수 있다.

이 기록은 계산 구현과 화면 동작의 확인 범위를 설명한다. 테스트 통과, 수학적 항등식, 과거 가격 예측 성능, 원격 배포 성공은 서로 다른 결과다.

## 1. 고정 스냅숏과 분석 범위

| 항목 | 고정 값 또는 처리 원칙 |
|---|---|
| 연구 기준일 | 2026-10-21 KST |
| 마지막 완료 관측 | 2026-10-20 UTC |
| 전망 표시 종료 | 2029-10-21 |
| 내장 자료 | 2010-07-18~2026-10-20, Coin Metrics BTC/USD UTC 일말 관측 5,939개 |
| 3년 전망 갱신 | 원자료를 갱신해도 분석 기준일·사이클 기준점을 자동으로 바꾸지 않음 |
| 미래 경로 | 날짜·고점 배수·낙폭·파동을 정한 조건부 계산 |
| 가격 음영 | 선택 고점의 ±25%에 따른 민감도. 확률 구간으로 보정하지 않음 |

2025-10-06 최고값과 2026-06-30 저점 후보는 해당 관측 범위에서 선택한 잠정 기준점이다. 그 날짜의 미래 확정성이나 이후 가격에 대한 보증은 없다. 그래프 표시 끝점을 새 고점·저점으로 만들지 않으며, 그 이후에 계산된 사건은 표시 범위 밖이라고 구분한다.

새 스냅숏을 발행하려면 기준일, 가격 범위, 기준점, 모델 JSON, 그림, 검증 기록을 함께 갱신해야 한다. 현재 버전은 실시간 예측 서비스가 아니다.

## 2. 자동 계산 검사

공개 준비 전 로컬 검증에서 `node --test tests/*.test.mjs`의 **7개 테스트 파일이 통과했고 실패는 0**이었다. 새 모형 내부의 **11개 검증 항목**도 통과했다. 공개 저장소의 최신 커밋에 대한 원격 CI 결과는 GitHub Actions 실행 기록으로 별도 확인해야 한다.

| 검사 범위 | 확인한 성질 | 확인하지 않는 것 |
|---|---|---|
| 날짜 산술 | 허용 A/D 조합, 월말·윤년, D=0, 음수 A, 순이동 제한 | 실제 시장 전환일의 예측력 |
| 경로 계산 | 양수·유한성, 관측 앵커 연결, 가정한 가격 경계 | 실제 일별 파동의 시점·진폭 |
| 정보 절단 | 과거 기준일 뒤의 관측을 해당 시점의 계산 입력에서 제외 | 모형·평가 기점의 사후 선택 편향 제거 |
| 스트레스 분기 | 현재 저점 후보 이탈과 다음 회차 저점의 구분 | 후보 저점 유지 확률 |
| 계산 재현 | JSON 재실행 일치, 항등식과 가격 경계 검산 | 시장이 동일 방정식을 따른다는 증명 |
| 자료 카탈로그 | 대표 50행·보조 18개·고유 HTTPS URL 68개, 순위와 부모 ID 연결 | 모든 외부 원문의 상시 접근 가능성 |

재실행은 저장소 루트에서 수행한다. **Node.js 24 이상이 필요**하며, 재현 환경은 **Node.js 24**를 권장한다. 이는 `package.json`의 `engines.node >=24` 조건과 같다.

```bash
npm test
```

검사 파일은 [tests](../tests)에 있으며 모델 구현은 [outlook-engine.js](../dist/outlook-engine.js)에 있다. 새 모형의 경계 조건과 보조 역사 분석의 검사는 별개 테스트 모듈에 보존한다.

## 3. 수학적 관계와 과거 성능의 구분

명목 최고점 N, 명목 최고점보다 고점권에 일찍 도달하는 시차 A, 도달 후 최고가까지의 형성 기간 D를 정의하면 다음 관계가 성립한다.

```text
고점권 도달 Z = N − A
조건부 최고가 P = N − A + D
순이동 P − N = D − A
```

잔차가 0인 것은 정의에 따른 항등식이다. A=D이면 고점권 도달이 빨라도 최고가 날짜가 유지된다는 관계를 설명하지만, 앞으로의 A와 D를 시장에서 알아낼 수 있다는 주장은 아니다. 95% 고점권 계산의 분모에는 관측 범위의 최종 최고값을 쓰므로 역사 해석에 사후 정보가 포함된다.

새 모델의 역사 평가는 **2014-12-18와 2018-12-30** 두 기점에서 당시까지의 관측만 사용했다. 모형과 기점은 사후에 선택했으며, 현재 2025/2026 사이클은 이 평가 표본에 포함하지 않았다.

| 이후 기간 | 모형 가격 MAPE | 가격 유지 기준 MAPE | 평가 기점 수 |
|---|---:|---:|---:|
| 12개월 | 138.86% | 39.70% | 2 |
| 24개월 | 377.72% | 73.54% | 2 |
| 36개월 | 126.75% | 95.11% | 2 |

**MAPE에서는 세 기간 모두 단순 가격 유지보다 나빴다.** 저점 유지 가정은 두 기점 중 한 기점에서 실패했고, 그 실패를 표본에서 제외하지 않았다. 기간별 로그 오차 결과도 [전체 JSON](THREE_YEAR_RESULTS.json)에 공개한다. 지표를 바꿔 상대 결과가 달라지는 구간만 선택해 예측력이 검증됐다고 표현하지 않는다.

12·24·36개월 평가는 같은 두 기점에서 겹치는 미래 기간을 사용한다. 따라서 독립 실험 여섯 건으로 세지 않는다. 시간순 입력 절단이 미래 관측의 직접 누수를 줄이더라도 사후 설계·소표본·시장 구조 변화의 문제를 없애지는 않는다. 검증 원칙은 [FPP3 제5장](https://otexts.com/fpp3/toolbox.html)의 시간순 교차 검증과 예측구간 설명을 참고했다.

이전 2030 거시 시나리오 및 730일 역사 경로 재생의 평가와 가격 범위는 별도의 보조 분석이다. [CYCLE_TIMING.md](CYCLE_TIMING.md), [FORECAST_RESULTS.json](FORECAST_RESULTS.json)을 새 3년 모델 결과와 구분한다.

## 4. 브라우저 확인 범위

데스크톱 브라우저 미리보기에서 다음 동작을 확인했다.

- 기본·이른 전환·늦은 전환·저점 이탈 시나리오의 날짜 및 표시 범위 구분.
- A의 상한·하한 조작에 따른 D 허용 범위와 안내 표시.
- 현재=100 / USD 단위 전환, 방법론 펼치기, 기존 사이클 비교 페이지 진입.
- 자료 표의 24→36→48→50행 추가 표시와 마지막 50개 자료 ID의 고유성.
- 자료 상세의 원문·선정 이유·한계·관련 보조 링크 표시.
- 그래프 사건 레이블의 겹침 수정 결과와 독립 PNG의 수식·눈금·설명문 간격.

자료 제목은 표에서 한 줄로 표시하고, 긴 설명은 상세에서 읽는다. 대표 자료 50개와 보조 링크 18개는 [자료 읽기 순서](EVIDENCE_PRIORITY.md)와 연결된다. 이 기록은 별도 모바일 브라우저 실행, 모든 브라우저의 호환성 시험, 모든 보조기술을 대상으로 한 접근성 감사까지 수행했다는 뜻은 아니다.

현재 코드의 정적 페이지를 직접 확인하려면 다음 명령을 사용한다.

```bash
python3 -m http.server 8000 --directory dist
```

브라우저에서 `http://localhost:8000`을 연다.

## 5. 단일 파일과 공개 배포의 검증 경계

단일 HTML 빌드는 JavaScript 13개 모듈, CSS, 가격 관측 5,939개를 내장했다. 저장소 루트에서 출력 위치를 지정해 재생성한다.

```bash
node scripts/build-standalone.mjs build/Bitcoin_Cycles_Comparison.html
```

내장 스냅숏은 외부 가격 요청 없이 기본 화면을 실행할 수 있다. 외부 원문 열기와 수동 가격 갱신은 네트워크에 의존한다. 대표 도표는 [Bitcoin_Three_Year_Outlook.png](figures/Bitcoin_Three_Year_Outlook.png)다.

PNG 도표를 다시 생성할 때는 Python 3와 `matplotlib`, `numpy`, 한글 폰트가 필요하다. 다음 명령으로 Python 패키지를 설치할 수 있다.

```bash
python3 -m pip install matplotlib numpy
```

한글 폰트는 `BCA_FONT_DIR`로 지정한 디렉터리 또는 Matplotlib이 찾을 수 있는 운영체제의 설치 폰트에서 선택한다. 지정 디렉터리의 하위 폴더를 포함한 `.ttf`·`.otf`·`.ttc` 파일에서 한글 지원을 확인하며, 같은 외형 재현에는 NanumGothic Regular·Bold를 권장한다. 3년 도표의 `--font-dir`는 `BCA_FONT_DIR`보다 우선한다. 도표의 기본 출력 위치는 `build/`이며 `BCA_OUTPUT_DIR`로 변경할 수 있다. 폰트 파일은 저장소에 포함하지 않는다. 이 요건은 PNG 재생성에 관한 것이며 정적 페이지 실행·Node.js 테스트와는 별개다.

공개 저장소 [twoimo/bitcoin-cycle-atlas](https://github.com/twoimo/bitcoin-cycle-atlas)가 생성됐으며 기본 브랜치는 `main`이다. GitHub Pages의 소스는 GitHub Actions로 설정했다. **첫 CI·Pages·릴리스 실행은 대기 중이고, 원격 실행 성공과 라이브 페이지 게시 성공은 아직 이 기록에 포함하지 않았다.** 게시 후에는 해당 커밋의 Actions 결과, 태그와 릴리스 파일, 실제 실행 페이지를 각각 확인해야 한다. 로컬 테스트 결과로 원격 게시 성공을 대신하지 않는다.

## 6. 데이터와 코드의 이용 조건

가격 원자료와 이를 변환한 데이터는 Coin Metrics의 [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) 조건을 따른다. [데이터 JSON](../dist/data/btc-daily.json)에 출처와 처리 내용을 보존한다. 이 조건은 데이터에 관한 것이며 프로그램 코드에 동일한 라이선스를 부여한다는 뜻이 아니다. 이 문서는 별도의 코드 라이선스를 새로 부여하지 않는다.
