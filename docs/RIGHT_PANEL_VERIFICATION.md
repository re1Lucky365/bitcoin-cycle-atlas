검증일: 2026-10-22 UTC. v1.3 소스 `bba55a8f0a2d15b4191558b8e9bf9b7374b7bf4c` 위의 변경을 확인했다. 가격 자료와 미래 생성기의 수식은 변경하지 않았다. 이 기록은 화면 동작과 모형 설명을 검증하며 미래 적중률을 보증하지 않는다.

## 변경과 독립 검토

상단 상태·후보 날짜 카드와 하단 선택 정보줄을 제거했다. 가격·관측일과 후보 D-day는 차트 안에 표시하고, 값·근거·모델·갱신·도움말·자료 상세·그래프 선택·설정은 하나의 오른쪽 패널에서 연다. 패널 구현, 모델 입력 감사, 실제 브라우저 검수를 서로 다른 담당자가 수행했다.

모델 감사는 현재 화면이 호출하는 `buildDetailedForecast()`를 직접 추적했다. 과거 가격·잔차·최근 변동성과 지정한 기간·가격 가정을 구분했다. **시가총액·공급·거래량·유동성·ETF 흐름은 미반영**이다. 화면의 모델 첫 페이지와 [전체 모델 범위 문서](MODEL_SCOPE.md)에 이를 명시했다. 모델 구조와 평가 시점은 사후 설계이며 미래 검증을 완료했다고 표현하지 않는다.

## 발견하고 수정한 결함

- 닫힌 도킹 레이아웃에서 main의 자동 너비·자동 마진 때문에 차트가 중앙의 좁은 열로 수축했다. 너비 100%와 마진 0, grid stretch로 수정했다.
- 모바일 겹침 패널이 존재하지 않는 두 번째 grid 열을 기준으로 폭을 계산해 우측 21px만 보였다. 모바일의 grid 영역을 첫 열로 지정한 후 320px 전체 패널을 확인했다.
- 고점에 겹친 십자선 점이 클릭을 가로채면서 반올림된 좌표의 이웃 날짜를 선택할 수 있었다. 십자선의 pointer events를 제거해 원래 고점의 data-date로 선택했다.
- 후보 상세에서 방향키로 이동한 뒤 크기가 변하면 후보 날짜로 복귀할 수 있었다. 사용자 선택과 패널 자동 열기를 분리하고 키보드 이동 시 후보 고정을 해제했다.
- 설정은 원본 DOM을 옮기고 페이지 분할을 중지하여 이벤트와 값을 유지한다. 일반 설명은 링크·서식을 보존하는 DOM Range로 나눈다.
