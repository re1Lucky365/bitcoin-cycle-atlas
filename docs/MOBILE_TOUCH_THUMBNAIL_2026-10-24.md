# 모바일 터치·공유 썸네일 보완

검증일: 2026-10-24 KST. 기준은 원격 `80bfc7e4ffed9c937c82cfa68287d57d47f15cd8` / v1.14.0이며, 보완 자산은 v1.14.1이다. 원격의 모바일 도구·하단 바·길게 눌러 추적·기록·분석 pane 기능을 유지했다.

## 수정

- 터치의 암묵적 캡처가 SVG 자식에서 안정적인 plot 컨테이너로 이전될 때, 자식의 버블링 `lostpointercapture`를 전체 제스처 취소로 처리하던 오류를 수정했다. 컨테이너 자체의 캡처 손실·실제 취소·모드 변경은 계속 취소한다.
- 그래프 주석에서 시작한 드래그도 탐색할 수 있다. 짧은 탭은 원래 선택을 유지하고, 실제 드래그 뒤 호환 클릭만 억제한다. 버튼·입력·메뉴는 기존 경계를 유지한다.
- 모바일(뷰포트 620px 이하)은 지표 이름·값을 항상 접는다. `indicator-list=open`, 초기화, 템플릿, 크기 변경도 이 레이아웃 정책을 따르며 지표 자체를 숨기거나 삭제하지 않는다. 관리는 기존 인디케이터 메뉴에서 가능하다.
- 데스크톱 범례는 관측·가정·6색 사이클·실선/점선 의미를 24px 높이 한 줄로 압축했다. 좁은 데스크톱 plot에서는 가로 스크롤과 키보드 접근을 허용한다. 원격 v1.14의 휴대전화 범례 숨김 정책은 보존했다.
- 새로운 1200×630 PNG 일러스트와 OG/Twitter 공유 메타데이터를 추가했다. 궤적은 장식이며 실측 차트·미래 가격 예측이 아니다. 이전 거절된 텍스트 중심 시안은 배포 자산에서 제거했다.
- X 원문의 산술·시각·ATH 정의 정정은 [독립 대조 보고서](X_CYCLE_CROSSCHECK_2026-10-24.md)를 따른다. 실제 관측·기간 계산·예측 모형은 변경하지 않았다.

## Android 실제 입력

대상: `emulator-5554`, Android 14 ARM64, 1440×3120 @505dpi, Chrome 113.0.5672.136. CSS 뷰포트는 약 457×861이다. `galaxy-emu`의 네이티브 swipe와 Chrome Android 원격 디버깅 읽기값을 함께 사용했다. 핀치는 CDP의 두 접점 터치 입력이며 JS `dispatchEvent`로 위조한 이벤트가 아니다.

주석 시작 드래그·탭의 분리 및 실제 캡처 손실·취소 경계는 유지된 DOM 이벤트 harness에서 회귀 검증했다. 특정 주석 좌표를 이용한 추가 네이티브 시도에서는 계측 입력 수신을 확인하지 못했으므로 그 시도를 성공으로 세지 않는다. 새 자산 버전의 동일 소유 탭 재탐색 후 일반 긴 스와이프는 다시 확인했다.

위 수치는 한 에뮬레이터/구형 Chrome에서의 입력 범위 검증이다. 9회의 범위 변경은 페인트 FPS가 아니며, 전체 기기의 지연·프레임률·실물 Galaxy·iOS·Safari 검증을 주장하지 않는다. 기존 Chrome을 업데이트하거나 실물 기기를 조작하지 않았다.

## 로컬 검사

- `npm test`: **650/650** 통과. 새 캡처 이전·주석 드래그 회귀는 원래 구현에서 실패하는 것을 먼저 확인했다.
- `npm run verify:static`: 통과, 공유 PNG의 실제 1200×630 바이트 규격·공개 절대 경로도 검사.
- `npm run verify:cycle`: 통과, 관측 종료일 2026-10-22와 기존 보정 산출물 보존.
- `npm run verify:performance`: 통과, Node SVG 경계 103개 요소 / 예산 120. 브라우저 페인트 벤치마크는 아님.
- `npm run verify:formal`: 기존 TLC 1.7.4 정상 모델·깨진 모델·구현 mutation 검증 통과. 시장 요청 제어 구현은 수정하지 않았다.
- 시스템 Java 기본 경로는 없고 Homebrew Java 링크도 실행 불가였다. 설치·전역 설정 변경 없이 이미 있는 Android Studio JBR 25.0.3을 검증 스크립트의 `JAVA` 환경변수로 지정했다.
- 독립 HTML 생성·정적 검사 통과. 생성물은 세션 임시 경로에만 보존했다.
- 데스크톱 실제 렌더: 1440px 뷰포트에서 12개 범례 항목 모두 같은 y=121px, 범례 높이 24px, 내부 폭/내용 폭 858px로 잘림 없음.
