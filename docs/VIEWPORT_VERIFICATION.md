## 변경 범위

가격·방향 후보·D-day·선택 정보·실제 자료 갱신 시각을 한 뷰포트에 모았다. 긴 설명과 수식은 요청 시 페이지로 열고, 자료 표와 원자료 표도 화면 높이에 맞춰 페이지를 나눈다. 여섯 그래프는 하나의 아이콘 메뉴에서 전환한다.

TradingView의 [공식 화면 구성](https://www.tradingview.com/support/solutions/43000748166-how-to-configure-your-supercharts/), [상태줄](https://www.tradingview.com/charting-library-docs/latest/ui_elements/Legend/), [시간축](https://www.tradingview.com/charting-library-docs/latest/ui_elements/Time-Scale/) 문서를 참고했다. 자체 SVG에서 오른쪽 가격축, 최근 실제 일말 가격 표시, 날짜·가격 십자선, 포인터 중심 확대, 가로 이동, 초기화 아이콘을 구현했다. 원자료에 없는 OHLC나 거래량은 생성하지 않았다.

## 검수에서 발견하고 수정한 문제

1. 제거한 설명 요소를 참조해 그래프 갱신이 멈추던 부분을 수정했다.
2. 작은 화면에서 설정의 select 높이가 늘어나던 flex 배치를 수정하고, 360 × 640에서 전체 설정 높이 363px로 내부 잘림이 없는 것을 확인했다.
3. 현재 차트의 브라우저 갱신 날짜와 CI 번들 날짜가 섞이지 않도록 각각 기록했다.
4. 구간 이동의 음수 반올림 때문에 같은 거리 왕복 시 하루 차이가 나는 문제를 독립 검수에서 찾았다. 양·음 이동량을 대칭으로 반올림하도록 수정했다. 1,170일 창의 ±25%가 정확히 ±293일이며 양방향 12회 왕복 후에도 원래 범위를 보존하는 회귀 검사를 통과했다. 실제 데스크톱에서도 2026-03-17–2029-05-29 → 2025-05-28–2028-08-09 → 2026-03-17–2029-05-29로 왕복 복귀하는 것을 확인했다.

## 남는 범위

모바일 기본 핀치는 브라우저에 남겼고 Ctrl/Meta+휠을 가로채지 않는다. 브라우저·키보드 검수로 실제 기기 터치 품질이나 모든 보조기술의 적합성을 대신하지 않는다. GitHub 예약 실행과 제공자 자료 도착은 지연될 수 있다. 공개 본문·색인·소개·AI 요약을 구별하며 전체 X 계정·유료 본문·모든 영상의 검토를 주장하지 않는다. 미래 경로는 조건부 가정이며 수학적으로 증명된 시장 일정이나 보정된 확률 구간이 아니다.
