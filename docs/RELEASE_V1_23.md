# v1.23.0 · 시스템 감사와 ETH 상태·수치 경계·반복 계산 개선

기준 버전은 v1.22.1, 커밋 `64c8207cb044d8990289c5a7d39972e21b74c240`이다. pstack의 병렬 분할, 실제 반례 재현, 별도 프로파일과 교대 성능 측정, 형식 검증 스킬 생성·유지 절차를 적용했다. 실제 사용 가능한 에이전트로 실행했으며 제공되지 않는 Cursor 실행기나 모델을 사용했다고 주장하지 않는다.

## 사용자에게 달라지는 동작

- ETH의 **데이터 출처와 조회 상태** 버튼이 정상적으로 정보 창을 연다. 정의되지 않은 HTML 이스케이프 함수 호출을 수정하고 실제 버튼 경로를 회귀 검사한다.
- ETH 초기 조회가 취소된 뒤 뒤로/앞으로 캐시에서 복원돼도, 아직 자료가 없는 화면을 준비 완료로 공개하지 않는다. 유효한 관측 또는 재시도 가능한 오류를 그렸을 때만 처음 한 번 공개한다. 숨긴 화면의 늦은 콜백은 렌더링하지 않는다.
- ETH 가격 조회가 진행되는 동안 사용자가 이동한 날짜·가격 범위를 보존한다. 새로운 가격 응답이 새로 선택한 범위를 초기화하지 않도록 요청과 화면 선택의 소유권을 구분한다.
- 일별 원자료의 페이지 이동은 숨겨진 월별 표를 다시 만들지 않는다. 월별 보기를 열 때는 현재 자산·연도·지표로 계산한다.
- 비교 화면은 이미 계산한 일별·주별 국면과 전환점을 재사용한다. 임계값이나 가격 자료가 바뀌면 기존 무효화 규칙에 따라 새로 분석한다.

## 수학과 자료 경계

- 연말·월말을 가로지르는 일별 누락을 이전 기간의 완전성 표시에도 반영한다. 같은 누락 날짜를 메타데이터에 명시하더라도 중복 계산하지 않는다. 주식 휴장일은 누락 세션으로 추정하지 않는다.
- 달력 월 이동은 0000–9999년의 유효한 날짜를 보존하고 윤년·월말을 처리한다. JavaScript `Date.UTC`의 0–99년 보정 때문에 다른 세기로 이동하던 문제를 없애고, 지원 범위 밖 결과는 명시적으로 거절한다.
- 큰 값의 중앙값과 Theil–Sen 기울기, 극단적인 비율의 로그수익률, 기하평균의 중간 계산 손실을 줄인다. 수학적 결과는 유한한데 중간식만 넘치는 사례를 안정적인 식으로 처리한다. 최종 백분율·기울기 자체가 표현 불가능한 경우에는 성공 결과에 `Infinity`나 `NaN`을 포함하지 않는다.

이 수치 경계 반례를 실제 BTC 시세의 대규모 오류로 일반화하지 않는다. 정상 관측의 결과 동등성과 변경된 경계 사례는 [수치 감사](SYSTEM_NUMERICAL_AUDIT_2026_10_25.md)에 구분한다. MDD는 종가 기준이고, 매수·중립·매도 규칙의 수익성이나 예측 확률을 검증한 변경은 아니다.

## 재실행 가능한 검증

`.agents/skills/verify-eth-state/`에 프로젝트용 검증 절차를 추가한다. 실제 초기화 함수와 실제 부팅 스크립트를 실행하는 회귀, 코드와 대응하는 TLA+ 모델, 의도적으로 보호를 제거한 임시 코드 대조, 복원 후 재검증을 함께 둔다. [상태 모델과 대응](formal-eth/README.md), [통합 감사](SYSTEM_AUDIT_2026_10_25.md), [성능 측정](SYSTEM_PERFORMANCE_AUDIT_2026_10_25.md)을 참고한다.

```sh
npm test
npm run verify:numerics
npm run verify:treasury-paths
npm run verify:formal
npm run verify:research
npm run verify:eth-events
npm run verify:cycle
npm run verify:performance
npm run verify:static
npm run build:standalone
node scripts/verify-static.mjs --standalone build/Bitcoin_Cycles_Comparison.html
```

새 수치·ETH 상태 검증은 CI·Pages·릴리스 게이트에 포함한다. 시간 측정은 실제 컨트롤러와 계산·표/SVG 생성 범위를 대상으로 하며 네트워크·브라우저 페인트의 측정으로 확대하지 않는다. 유한 상태 모델의 전수 탐색과 유한 입력 검사는 전체 프로그램의 무제한 증명 또는 미래 시장 정확도의 증명이 아니다.
