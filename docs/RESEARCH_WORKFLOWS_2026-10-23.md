# 연구 작업 흐름 개선 — B01–B12 구현 보고서

**작성일:** 2026-10-23 UTC. **구현 시작 기준:** `a71cdc3`(PR9 병합 이후). **대상 버전:** v1.13.0, 캐시 `1.13.0-research.1`. 구현과 지원 범위, 자동 검사 및 실제 브라우저 결과를 [검증 기록](#9-검증-기록)에 기록한다. 원본 조사에서 통과한 검사 수나 과거 캡처를 이번 변경의 결과로 합산하지 않는다.

## 1. 목적과 근거의 경계

사용자가 요청한 [개선 후보 B01–B12](research/tradingview-2026-10-23/02-gap-backlog.md)를 BTC 연구 작업에 맞게 반영한다. 이동·선택·설정·복구·저장 과정에서 날짜, 원가격, 자료 출처와 조건부 가정의 의미를 유지하는 것이 목적이다.

[TradingView 원본 조사](research/tradingview-2026-10-23/README.md)의 공식 문서, 32개 사용 흐름, 실제 UI 관찰과 접근 제한은 그대로 보존한다. 당시 v1.12.0 비교표는 당시 코드의 상태이며, 이 문서의 새 기능을 검증한 기록이 아니다. 반대로 이번 자체 구현을 TradingView 전체 동작과 동일하다고 판정하지 않는다. 원본 데스크톱 조사 당시의 모바일 관찰 한계도 유지한다. 별도로 추가된 모바일 후속 조사와 이번 구현의 반응형 화면 검수는 각각의 증거 범위로 구분한다.

장기 가치평가 입력, 대표 경로, 경제 가정 간 범위, 완료 봉 정책, 여섯 색 기준점의 선정 규칙은 이번 UI 확장의 연구 대상이 아니다. 더 자유로운 화면과 저장 도구가 예측 정확도의 개선을 뜻하지 않는다. [모형 범위](MODEL_SCOPE.md), [사이클 선정 규칙](CYCLE_MILESTONES.md)을 함께 읽는다.

## 3. 이동·확대·축의 사용자 계약

### 최대 축소와 자료가 없는 화면

날짜 이동을 현재 로드한 첫·마지막 가격에 묶지 않는다. 지원 날짜 범위인 1800–2400년 안에서는 자료 이전·이후로 이동할 수 있으며, 표시할 가격이 없으면 빈 화면 메시지와 축·이동 기능을 유지한다. 이는 해당 날짜에 가격 자료나 미래 가정이 있다는 의미가 아니다. 일·주의 미래 경로는 기존 모형이 실제로 산출한 날짜에만 표시하고, 분·시간은 완료된 실제 봉만 표시한다. [이동 계산](../dist/chart-navigation.js), [빈 가격 화면](../dist/empty-price-chart.js)

데스크톱 가격 영역 드래그는 가로 날짜와 세로 원 USD 가격 범위를 함께 옮긴다. 가로 이동만으로는 Auto를 해제하지 않고, 세로 이동이 시작되면 현재 가격 범위를 수동 범위로 잡는다. 터치의 수직 이동은 `H` 이동 도구로 시작해 페이지 세로 스크롤과 구분한다. 차트의 최대 축소는 이동 기능의 종료 조건이 아니다.

가격축을 위아래로 드래그하면 Y 범위를 확대·축소하고, 가격축을 두 번 누르면 **Auto**로 돌아간다. 이 조작은 날짜 범위를 초기화하지 않는다. 날짜축의 좌우 드래그는 시간 간격을 조절한다. **기본 범위**, `0`, `Alt+R`은 전체 보기 복구 동작이며, 이 변경도 실행 취소할 수 있다. [축 조작](../dist/price-axis.js), [이동 이벤트](../dist/chart-navigation.js)

### 간격 전환과 직접 입력

`1m·5m·15m·30m·1h·4h·1D·1W` 사이 전환에서는 UTC 중심과 기간을 가능한 범위에서 유지한다. 대상 간격의 최소 폭·최대 봉 수·날짜 범위에 맞춰야 하면 표시 기간을 조정하고 이유를 안내한다. 원 USD 수동 Y 범위는 보존한다. 선택 시각을 대상 간격의 시작 격자로 옮기는 것은 실제 봉의 존재를 보증하지 않는다. 완료 봉이 없는 위치에 가짜 OHLC를 만들지 않는다. [전환 정책](../dist/chart-view-policy.js)

**날짜·기간으로 이동**은 단일 시점 또는 명시적 시작–끝을 받는다. 모든 입력은 UTC이며, 분·시간은 해당 간격의 봉 시작 시각을 사용한다. 끝이 시작보다 빠르거나 아직 완료되지 않은 분·시간 봉을 입력하면 이동하지 않고 오류를 표시한다. 현재 로드한 범위 밖의 유효 입력은 조회 결과와 빈 화면을 통해 확인한다. 일·주 직접 기간 입력은 최대 36,600일, 분·시간은 최대 6,000봉이다. 이 한도는 실제 자료의 보유 기간을 뜻하지 않는다. [입력 검사](../dist/chart-view-policy.js), [이동 창](../dist/chart-go-to.js)

### 표시 단위

| 모드 | 화면 값 | 기준과 눈금 |
|---|---|---|
| USD | 원가격 `P` | 기존 로그·선형 선택 |
| 최근 관측 = 100 | `100 × P / 최근 관측 가격` | 기존 기준값을 유지하는 지수; 로그·선형 선택 |
| 표시 시작 대비 % | `100 × (P / 표시 시작 가격 − 1)` | 현재 표시 구간의 첫 유효 가격; 선형 |
| 표시 시작 = 100 | `100 × P / 표시 시작 가격` | 현재 표시 구간의 첫 유효 가격; 선형 |

시작 기준 모드는 화면을 이동하면 기준 날짜·가격도 달라지므로 설정·값 표시·내보내기 메타데이터에 기준을 밝힌다. 유효 기준가격이 없으면 값을 임의로 원 USD처럼 표시하지 않는다. 가격축 반전은 화면의 위아래 방향만 바꾸며 수익률 부호·원자료·저장 측정은 그대로다. **가격 자료만 자동 맞춤**은 가격선·캔들로 축을 맞추고 가정 범위와 기준점이 축을 넓히지 않도록 한다. [단위 계산](../dist/price-display.js), [가격 차트](../dist/atlas-price-chart.js), [분·시간 차트](../dist/intraday-chart.js)

## 4. 지표 값·설정·범례

기존 전체 접기 계약을 유지한다. 목록을 접으면 모든 지표 제목·값 행을 숨기고 복구 화살표를 남기며, 지표 도형·가격·OHLC는 유지한다. 지표가 하나일 때도 동일하다. 명시적 URL 설정이 없는 모바일은 기본 접힘이다. `indicator-list=open/closed`는 새로고침·저장한 작업 화면·지표 템플릿에서 보존한다. 이전의 ‘대표 한 행’이나 현재 세션만의 접기와 구분한다. [상태](../dist/indicator-state.js), [목록](../dist/indicator-workbench.js)

**값 표시**, **도형 눈 아이콘**, **목록 전체 접기**, **연구 창 최소화**, **지표 제거**는 독립 동작이다. 값을 숨겨도 최신 값 계산을 유지하고, 다시 표시하면 현재 값으로 복원한다. 가격 단위가 % 또는 시작 기준 100이면 값 행도 그 단위와 기준을 표시한다. 기존 OHLC 원가격과 전봉 종가 대비 변화율은 출처와 함께 구분한다. [값 표시](../dist/indicator-readouts.js)

설정 창은 해당 그래프가 실제로 소비하는 항목만 노출한다. 선이나 원 테두리에는 굵기 배율, 실제 채움에는 채움 배율, 수치축을 가진 항목에는 축 숫자 표시를 제공한다. 색상·관측/가정 실선·점선 규칙은 바꾸지 않는다. 전체 투명도는 0.15–1, 굵기는 원래 값의 0.5–3배, 채움은 0–1배 범위다. 같은 설정을 반복 적용해 굵기나 투명도가 누적되지 않도록 원래 속성을 기준으로 적용한다. [설정과 실제 SVG 적용](../dist/indicator-settings.js)

| 연구 | 실제 계산에 연결한 입력 |
|---|---|
| 4년 비교 | 저점·반감기·달력 구간의 출발점 맞추기 |
| 구간 길이 | 전체 상승·하락 / 상승장 내부 / 하락장 내부 |
| 월·분기 | 월·분기 집계, 수익률·최대 하락·실현 변동성·신고가 일수, 최근·전체 범위 |
| CryptoCon 검증 | 고점 시기·수정 / 고점권 진입 / 가격 목표·결과 |
| 고점권 도달 | 기존 계산을 유지하며 실제 스타일·값·축·표시 간격만 조절 |

간격 조건은 **표시 조건**이다. 예를 들어 일·주 전용 사이클 주석을 분봉 자료로 재계산하지 않는다. 독립 연구 창을 분·시간 화면에서 함께 열더라도 연구의 원래 일별·경과일 자료와 단위는 유지한다. 모든 간격을 해제하면 해당 지표의 그래프가 보이지 않는 이유를 설정 창에서 안내한다. [설정 창](../dist/indicator-settings-dialog.js), [연구 렌더러](../dist/atlas-analysis.js)

가격 범례와 여섯 색 원·기간선 범례는 **우측 상단 D-day 아래 한 묶음**으로 유지한다. 넓은 화면의 여섯 색 한 줄, 좁은 화면의 3열 배치를 사용하며, 모바일 지표 목록은 이 묶음 아래의 제한된 공간에서 펼친다. 기간선은 확대해도 가격 그래프 안 **하단**에 놓고 차트 높이·날짜 좌표를 늘리지 않는다. 실제 원의 일별 날짜·가격과 기간 양 끝점은 그대로다. [HUD 스타일](../dist/cycle-milestones.css), [기간선 렌더링](../dist/cycle-milestones-view.js)

## 5. 연구 창의 최대화·순서·높이

각 연구 창 제목에는 실제 설정과 순서·최대화·최소화·숨김·제거를 구분한 조작을 둔다. 제목을 두 번 눌러 최대화하고 복원할 수 있다. 최대화는 차트 내부에서 한 연구 창에 공간을 집중하며, 다른 창의 추가 상태·순서·개별 높이를 지우지 않는다. 최소화는 제목을 남기고, 숨김은 해당 창을 표시하지 않는다. [연구 창 제어](../dist/analysis-dock.js)

아래 경계를 드래그하면 높이를 바꾼다. 경계에 키보드 초점을 둔 상태에서는 `↑/↓`로 20px, `Shift+↑/↓`로 60px, `Home/End`로 최소·최대 높이를 고른다. 기본 330px, 저장 가능한 일반 높이는 240–900px이며 경계 두 번 누르기로 기본값에 돌아간다. 드래그 도중 매 이동을 실행 취소 이력에 쌓지 않고, 놓을 때 한 번의 크기 변경을 기록한다.

0개·1개·여러 개 창 모두 같은 제한 영역을 사용한다. 좁은 화면에서는 조작 버튼을 줄바꿈하고 창 내부·목록을 스크롤한다. 최대화 전후의 창 목록 스크롤 위치도 복구한다. 반감기 이후 경과일, 사이클 출발값=100, 월·분기, CryptoCon 주장의 독립 축은 주 가격의 UTC 날짜·USD 축으로 바꾸지 않는다. [배치 스타일](../dist/analysis-dock.css), [분석 계산](../dist/atlas-analysis.js), [주장 대조](../dist/cryptocon-audit.js)

| 저장 수단 | 포함하는 것 | 포함하지 않는 것 |

| 공유 URL·저장한 작업 화면 | 현재 간격·날짜 범위·가격 단위·수동 USD 범위·축 반전·가격만 Auto·가정·지표 설정·연구 창 순서/높이/최대화·목록 접힘 | 실제 가격 자료 복사본, 연구 측정 객체, 실행 취소 이력 |
| 지표 템플릿 | 추가·숨김·최소화·전체 접기, 실제 지표 설정과 연구 창 배치 상태 | 주 가격의 날짜 범위, 시장 자료, 탭의 전체 변경 이력 |
| 브라우저 연구 측정 저장 | 최대 100개 원 UTC/원 USD 좌표·출처·관측/가정 구분·가정 이름·자료 기준·메모·색·잠금·숨김 | 다른 기기·다른 브라우저 자동 동기화, 공유 URL 포함 |
| 실행 취소·다시 실행 | 현재 탭의 명시적 조작 전후 상태; 기본 최근 50개 변경 | 서버/브라우저 간 영구 이력, hover, 비동기 가격 수집 결과 |

URL은 허용한 키와 유효 범위만 읽는다. 지표 설정은 `indicator-settings`, 창 배치는 `pane-order`·`pane-heights`·`pane-maximized`, 수동 축은 `price-min/max`, 추가 축 옵션은 `axis-inverted`·`price-only-auto`로 저장한다. 이전 설정 링크의 분석 입력은 새 지표 설정으로 읽으며, 기본값 복원 후 옛 입력이 되살아나지 않도록 명시적 빈 설정도 구별한다. [URL·작업 화면](../dist/workspace-state.js), [지표 상태](../dist/indicator-state.js), [템플릿](../dist/indicator-preferences.js)

**실행 취소**는 `Ctrl/⌘ Z`, **다시 실행**은 `Ctrl/⌘ Shift Z` 또는 `Ctrl/⌘ Y`이다. 입력란·열린 대화상자에서는 텍스트 편집의 기본 키를 가로채지 않는다. 한 드래그·연속 휠·설정 명령은 한 변경 단위로 기록하고, 복원 중에는 새로운 이력을 만들지 않는다. 화면 복원 시 진행 중 요청·제스처를 취소해 늦은 이전 요청이 복원한 상태를 덮지 않도록 기존 요청 소유권과 연결한다. [이력 모듈](../dist/workspace-history.js), [통합 상태 복구](../dist/lab-view.js)

**저장한 연구 측정**은 완료한 임시 두 점 측정에서 시작한다. 달력 경과 시간과 저장 당시 로드된 원자료 봉 수를 따로 기록한다. 좌표를 수정하면 실제 원자료와 일치한다는 의미를 제거하고 사용자 좌표로 표시하며, 더 이상 유효하지 않은 봉 수를 비운다. 가정을 바꿔도 저장한 좌표는 자동 재계산하지 않으며 저장 당시 다른 가정의 측정임을 표시한다. 잠금은 편집·삭제를 막고 숨김은 보존을 유지한다. 브라우저 저장 실패에는 현재 탭의 상태를 유지하고 실패를 안내한다. [측정 상태·계산](../dist/research-annotations.js)

## 7. 내보내기와 자료 정체성

**차트 내보내기** 창을 열면 그 순간의 SVG·메타데이터·CSV 행을 동기적으로 고정한다. 이후 화면 재계산이나 PNG 변환이 진행되어도 미리보기와 실제 파일이 서로 다른 시점의 자료가 되지 않게 한다. 형식·범위·자료를 고른 뒤 **저장**하고, 지원 브라우저에서는 **이미지 복사**를 사용할 수 있다. 클립보드 권한·기능 실패는 성공으로 알리지 않고 안내한다. [스냅샷과 UI](../dist/chart-export-workbench.js)

| 출력 | 포함 범위 | 해석 |
|---|---|---|
| PNG·SVG / 현재 가격 화면 | 현재 가격 SVG의 날짜·가격축·보이는 기간선·연구 측정, 출처·단위·가정·UTC 메타데이터 | 화면의 가격 단위·반전·수동 범위를 유지한다. |
| PNG·SVG / 현재 가격 + 보이는 연구 창 | 가격 SVG와 현재 보이는 펼친 연구 창을 순서대로 수직 합성 | 숨김·최소화 창은 제외하고 제외 목록을 안내한다. 각 연구의 독립 축·설명·출처를 유지한다. |
| Coin Metrics 관측 CSV | 표시 기간과 실제 로드한 일별 가격의 교집합 | 원 USD, 실제 관측만. 주봉 화면에서도 원자료의 일별 간격을 명시한다. |
| Bitstamp·Coinbase 관측 CSV | 선택한 자료의 실제 완료 OHLC와 현재 범위의 교집합 | 원 USD·BTC 수량과 해당 간격. 누락·미완료·미래 봉을 생성하지 않는다. |
| 조건부 경로 CSV | 관측 기준일 이후, 현재 기간 안의 선택한 가정 경로 | 관측값과 별도 파일. 하단·상단은 경제 가정 간 범위이며 확률구간이 아니다. |
| 개별 연구 CSV | 현재 보이는 연구 창이 실제 계산한 자료 | 고유 축·단위를 유지한다. 주 가격 날짜 필터를 적용하지 않는다. 월·분기 등 페이지가 있는 연구는 현재 표시 내용 기준이다. |

연구 렌더러의 `exportData()`는 `{id, label, source, interval, unit, kind, rows, columns, note}`를 반환한다. 4년 비교의 원 USD·출발 지수·경과일, 구간 길이의 실제 일수·미완료 상태, 월·분기 실제 집계, 고점권 진입의 원가격·사후 고점 대비 비율, CryptoCon의 원주장·분류·실제 대조값을 구별한다. 수치가 없는 항목은 근거 없이 채우지 않는다. [분석 내보내기](../dist/atlas-analysis.js), [CryptoCon 내보내기](../dist/cryptocon-audit.js)

빈 자료나 오류가 있는 CSV는 다운로드할 수 없게 하고, 실제 로드된 범위와 저장할 범위를 별도로 표시한다. CSV 텍스트의 수식 시작 문자를 방어한다. PNG는 메모리 예산에 따라 해상도를 제한하며, SVG는 같은 출처 표시가 있는 벡터를 사용한다. 이는 브로커 체결 내역·진행 중 실시간 봉·계정의 전체 자료를 내보내는 기능이 아니다. [파일 생성](../dist/chart-export.js)

## 8. 이번 범위에 포함하지 않은 것

BTCUSD 자료 제공자의 역할은 그대로다. 종목·거래소 선택기, 라이브 틱과 미완료 봉, 서버 알림, 리플레이, 주문·브로커 연결, Pine·커뮤니티 스크립트, 스크리너, 포트폴리오, 계정·클라우드 동기화는 이번 B01–B12 구현에 포함하지 않는다. 유료 기능의 권한이나 외부 서비스의 접근 제한을 우회하는 구현도 없다. [원본의 별도 제품 범위](research/tradingview-2026-10-23/02-gap-backlog.md#5-별도-제품-범위로-남기는-것)

기존 주석 이미지의 표기, 역사 관측의 사후 기준점, 현재 조건부 가정의 후보는 계속 구분한다. 새로운 화면 조작·지표 설정·저장 기능이 원본 이미지와 모든 값·날짜가 동일하다는 주장을 추가하지 않는다.

형식 검증 첫 시도는 Java 실행 권한의 `EPERM`으로 중단됐다. 소스를 바꾸지 않고 동일한 고정 TLC 1.7.4를 실행 권한 재시도 후 통과시켰다. 범위는 제한된 비동기 요청 소유권 모델이며 전체 프로그램·수치 계산·가격 모형·pagination·liveness의 증명이 아니다. 성능 검사는 결정적인 렌더링·검색·원자료 선택 회귀이며 물리 기기의 프레임 시간 측정이 아니다.

### 검증의 남은 경계

물리 휴대전화에서 길게 누르기·스크롤·두 손가락 전환 및 브라우저별 이미지 클립보드는 이번 세션에서 실행하지 않았다. 터치 전환과 중단 경로는 실제 제어 모듈을 장착한 합성 포인터 회귀로 검증했다. 저장 실패·좌표 편집의 오류 경계는 자동 검사 결과이며, 위 실제 브라우저 표의 성공 경로와 구분한다. 분석 창의 모든 조합·모든 기기·모든 네트워크 실패를 실제 실행한 것은 아니다.
