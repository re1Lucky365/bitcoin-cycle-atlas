# 모바일 단계별 시나리오 25개

**표시:** 실행 확인 / 선택 수락·부분 확인 / 메뉴 열람 / 문서만 / 차단. 한 항목 안에서도 상태가 다르면 나눠 쓴다. 모든 조작은 Android 14 ARM64 AVD의 Chrome 113에서 수행했다. 입력 좌표는 전체 1440×3120 화면 기준이며 다른 기기에 그대로 복사할 고정 자동화 좌표가 아니다.

## M01 · 안전한 모바일 작업 공간 만들기

1. 연결 목록·현재 앱·해상도·Chrome 버전을 읽었다. 실물 Android는 오프라인이고 emulator-5554만 연결됐다.
2. TradingView 앱 패키지 조회는 결과가 없었다. 임의 APK·앱 설치·업데이트·권한 변경은 하지 않았다.
3. Chrome 기존 example.com 탭을 보존하고 새 탭을 열어 TradingView /chart/에 들어갔다. 저장된 MAIN 레이아웃 URL은 사용하지 않았다.
4. Atlas도 두 번째 새 탭에서 열었다. Chrome 계정 동기화·Google 프로필·다른 탭에는 손대지 않았다.

**결과:** 모바일 웹 전용 조사. 실제 삼성 One UI, 물리 터치 센서·배터리 성능, 네이티브 앱 결과가 아니다. [환경](environment.json)

2. 검색란에 BTCUSDT를 입력했다. 소프트 키보드가 표시되고 여러 거래소 결과가 나타났다([MT03](captures/MT03.png)).
3. **BINANCE · Bitcoin / TetherUS** 행을 선택했다. 키보드와 검색 창이 닫히고 BTCUSDT 1D Candles가 표시됐다([MT04](captures/MT04.png)).

**실행 확인.** Binance BTC/USDT와 Atlas Bitstamp BTC/USD·Coinbase BTC-USD는 다른 시장이다. 같은 순간 가격·거래량이 달라도 UI 오차라고 판정하지 않는다.

3. Got it!을 누르고, 안내가 사라진 새 UI를 확인한 뒤 같은 동작을 다시 했다.
4. O/H/L/C·거래량 수치, 십자선·가격선·하단 날짜가 나타났다([MT06](captures/MT06.png)).

**실행 확인.** 문서 S01/S02의 추적 모드와 일치한다. MT06 선택 봉은 O81,754.46 / H83,528.98 / L81,603.52 / C82,635.55다. 현재 실시간 BUY/SELL 숫자와 선택 봉 OHLC는 구별한다.

## M07 · 가격축 길게 누르기와 축 종류

1. 차트 내부가 아닌 오른쪽 가격 눈금을 길게 눌렀다.

3. Logarithmic을 선택했다([MT11](captures/MT11.png)).

**로그 전환 실행 확인 / 나머지 축 종류는 메뉴 열람.** 모바일에서는 축 자체를 누르는 대체 경로가 있다. 메뉴에 보인다고 모두 전환 시험한 것은 아니다.

## M09 · 간격 선택과 가입 시트의 경계

1. 상단 D를 눌렀다. ticks·seconds·minutes·hours와 각 즐겨찾기 별이 보였다([MT15](captures/MT15.png)).
2. 1 hour를 선택했다. 상단 1h·접근성 설명 1 hour로 바뀌었다.
3. 그러나 **동일 MT16 캡처에서 이미 가입 안내가 차트 하단을 막았다**([MT16](captures/MT16.png)).

**간격 선택 수락·부분 확인.** 가림 없는 1h 조작·봉 데이터 정확성까지 검증한 것이 아니다. 초·tick 유료/시장별 가용성도 메뉴 노출만으로 판단하지 않는다.

## M10 · 차트 유형·후속 기능의 명시적 차단

1. Candles 아이콘으로 유형 목록을 열려 했지만 가입 시트가 유지됐다([MT17](captures/MT17.png)).
2. 배경을 눌러도 닫히지 않았다. Android Back은 Chrome **Leave site? / Changes you made may not be saved** 경고를 열었다([MT18](captures/MT18.png)).
3. Cancel을 눌러 페이지에 남겼지만 가입 시트는 유지됐다([MT19](captures/MT19.png)).
4. 가입·로그인·구독·제한 우회 없이 후속 TradingView 모바일 조작을 중단했다.

**차단:** 모바일 웹 차트 유형 변경, 지표 추가·설정, 그림 생성·편집·45도 정렬, Object Tree 조작, snapshot/CSV 수신. S05/S06/S07은 문서 참고다. 데스크톱 Basic→Plus CSV 제한과 이번 익명 가입 시트는 다른 원인이다.

4. 차트에서 다른 점을 눌러 05:00 UTC 봉의 OHLC를 읽었다([MA23](captures/MA23.png)).

**실행 확인.** 선택된 봉 시각은 최신 수신 봉 시각과 다르다. 저장 자료는 최신 네트워크 성공으로 부르지 않는다. 후에 받은 CSV의 마지막 봉은 09:00 UTC였다. 일·주 미래 가정/D-day 대신 시간봉에는 실제 Coinbase·UTC 범례가 남았다. 일부 오른쪽 가격 숫자의 끝 잘림도 관찰했다.
