# TradingView 심층 사용법 조사와 Atlas 개선 참고 자료

**조사일: 2026-10-23 KST · 공식 문서 24개 · 단계별 작업 흐름 32개 · 실제 UI 캡처 70장**

## 먼저 알아둘 결론

- 비교 핵심은 화면 모양보다 **가격·시간·출처·선택·복구의 의미**다. BTCUSD/BTCUSDT, Coin Metrics/Bitstamp/Coinbase, 완료 봉/실시간 진행 봉을 같다고 비교하면 안 된다.
- 봉 간격, 표시 기간, 로드된 데이터 범위는 다르다. TradingView 하단 기간 프리셋은 간격도 바꿀 수 있다.
- 지표 추가·숨김·값 표시·legend 접기·pane 최소화·삭제·즐겨찾기·계산 설정은 서로 다른 상태다.
- Atlas는 BTC 관측·조건부 장기 가정·사이클 근거를 읽는 연구 앱이다. TradingView의 거래·서버 알림·Pine·범용 다자산 터미널을 전부 복제하는 것이 곧 개선은 아니다.

## 실제 실행과 남은 제한

**실행 확인:** 일봉/선·캔들 전환, 사용자 기간 이동, 로그/백분율/100 축 전환, RSI 추가·설정 3탭 열람, pane 더블클릭 확대와 Undo 복원, 추세선 2점 생성과 Undo, 임시 측정, Bitstamp 비교 시리즈 추가, 명령 검색과 Cmd+K, 객체 트리/데이터 창 전환.

**메뉴 확인/생성 안 함:** 레이아웃 배치·동기화, 템플릿, 알림 생성 창, snapshot 메뉴, 우측 제품, 브로커 연결 창. 알림·주문·게시·구독은 실행하지 않았다.

**명시적 제한:**
- 새 레이아웃 생성/복사는 현재 계정의 저장 레이아웃 제한에 걸렸다. 기존 MAIN을 수동 저장하지 않았다.
- CSV Download는 Basic→Plus 업그레이드 안내로 끝났다. 수신 파일·CSV 스키마 검증은 완료하지 못했다.
- 기존 Replay 진행을 보존하기 위해 Continue/Start new·재생은 실행하지 않았다.
- 모바일 앱·실기기·모든 제스처·접근성·FPS는 이번에 검증하지 않았다.

종료 전 저장된 MAIN을 다시 로드해 원래 1W Candles·지표 접힘·신규 RSI/비교 시리즈 없음·All changes saved 상태와 Autosave=false를 확인했다. 이후 보완 촬영은 검색·도움말만 열었고 차트 구성은 바꾸지 않았다.

## 검증 요약

- PNG 70장을 6개 검수 시트로 전부 시각 검토했다. 잘못 잘린 단축키 2장과 검색 갱신 전 1장은 다시 촬영했다. 수정된 원본도 직접 확인했다.
- T40은 도형 생성 전 시도 기록이며 성공 증거가 아니다. T41은 실제 생성, T42는 Undo 증거다.
- 각 PNG의 SHA-256·크기·픽셀·설명은 manifest에 기록한다. 로컬 경로·가상 ref·개인 레이아웃 URL을 공개 manifest에 저장하지 않는다.
- 최신 코드 기준 `npm test`: **node:test 469/469 통과**, 실패/건너뜀 0. 이 숫자는 custom console 검사나 이전 작업의 수를 합친 총계가 아니다.
- Markdown 상대 링크·이미지 참조·공식 출처 수/고유 URL·32개 흐름·12개 후보·70개 manifest 일치를 별도 검사한다.

## 자료 사용 주의

TradingView 화면은 사용법 비교를 위한 실제 제품 UI 캡처이며 해당 상표·UI 저작권은 각 권리자에게 있다. 캡처에 보이는 지표 이름·차트 그림은 사용 예시이지 Atlas의 기능·재배포 가능한 Pine 소스가 아니다. 원시 지표 코드·자격증명·개인 메시지·실주문/계좌 내역은 수집·커밋하지 않았다.

공식 문서의 단계와 이 계정에서 실행된 단계는 구분해야 한다. 제한 항목을 후속 검증 없이 ‘지원 완료’로 바꾸거나, 이 문서를 예측력·매매 수익·새 아키텍처 승인 근거로 사용하지 않는다.
