# v1.18.0 — MSTR·BMNR 실제 가격, 자본구조 모델과 리서치 리더

BTC·ETH 차트에 **MSTR·BMNR 실제 일·주봉**, 경영진 주장과 재무 공시를 대조한 연구, 미래 조건의 출처 표식, 읽기 쉬운 연구 글 보관 화면을 추가합니다. 검토일은 **2026-10-24**입니다. 모델 결과는 명시한 조건의 계산이며 검증된 주가 예측이나 투자 성과를 뜻하지 않습니다.

## 차트와 자료

- 상단 종목 선택에서 BTCUSD·ETHUSD·MSTR·BMNR을 전환합니다. MSTR는 1998-06-11부터, BMNR은 2025-06-05부터 수집한 분할 조정 일봉을 사용합니다. 초기 저장본의 마지막 거래일은 2026-10-23이며 각각 7,137개·349개 세션입니다.
- 주식은 일·주봉, 실제 가격선·캔들, 이동·확대·십자선·로그/선형축을 제공합니다. 분·시간봉과 누락된 초기 OTC 가격을 합성하지 않습니다.
- Yahoo Finance와 Nasdaq의 최근 5개 거래일 가격을 대조했습니다. 종가 차이는 부동소수점 반올림 수준이며 전체 OHLC 차이는 $0.01 이내입니다. 거래량 차이와 전체 역사 이력 미검증 범위를 자료 정보에 남겼습니다.
- **MSTR 32개·BMNR 22개 신규 연구 자료**, **MSTR 22건·BMNR 21건 역사 사건**을 추가합니다. 주식분할, treasury 전환, 자금 조달, 우선주, 전환사채, 보고 기준 변경과 경영진 발표를 구분합니다.

## 미래 경로와 근거

- BTCUSD 장기 경로에 계산법·기관 가격조건의 클릭 가능한 근거 표식을 연결합니다. 기존 경제 가정과 역사 잔차 모델의 설명을 읽기 화면에서 확인할 수 있습니다.
- MSTR·BMNR은 보유 코인·현금·포함 자산에서 채무 원금·우선주 청구권·기타 부채·비지배지분을 차감한 뒤 보통주 수로 나눕니다. 프리미엄, 증자, 희석, 금융비용과 자산 매각을 시간에 따라 계산합니다.
- MSTR의 현금상환 청구 가능일, BMNR의 스테이킹·보상 수수료·우선배당을 별도 조건으로 반영합니다. 계약상 선택권을 확정 상환 사건으로 표현하지 않습니다.
- 스트레스·기준·채택 확대의 세 경로와 최소·최대 범위를 제공합니다. 범위는 신뢰구간이 아니며, 강세에 필요한 누적 자금 조달도 모델 설명에서 함께 확인합니다.
- MSTR는 2026-06-30, BMNR은 2026-05-31의 같은 날짜 재무구조를 사용합니다. BMNR 최초 우선주 발행은 별도 공개 조정입니다. **최신 보유량과 과거 주식 수를 섞은 현재 NAV로 표시하지 않습니다.**
- 세일러의 서로 다른 발표 연도·목표 기간, 톰 리의 날짜 없는 조건부 목표, VanEck의 2024년 ETH 2030 가정은 분리합니다. 당시 공개되지 않은 정보를 이용한 역사 백테스트로 재사용하지 못하도록 날짜를 검사합니다.

## 리서치 읽기와 보관

- 「리서치 읽기 순서」에서 종목·분류·검색으로 찾고 제목을 누르면 종이색 배경의 긴 글 리더가 열립니다. 작성자·발행일·확인 상태·핵심 주장·반대 근거·접근 한계·관련 글·원문 링크를 표시합니다.
- 기존 BTC·ETH 자료와 신규 자료를 합쳐 **488개 정식 글·492개 ID 연결**을 보관합니다. 과거에 검토된 자료는 이번에 모두 새로 검증한 것으로 표시하지 않습니다.
- 보관 범위는 **직접 작성한 요약과 분석, 메타데이터, 미디어 주소**입니다. 제3자 기사·영상·이미지의 전문 복제본은 포함하지 않습니다. 원문 미디어가 삭제되면 링크만으로 복원할 수 없습니다.
- 다운로드 Markdown과 저장된 Markdown을 동일한 직렬화 함수로 생성하고 SHA-256을 검사합니다. `Research_Library.zip`과 정확한 소스 커밋의 ZIP을 릴리스에 포함합니다.
