# v1.19.0 · 재무 시나리오 경계, BTC 평가 일관성과 허용 원문 읽기

MSTR·BMNR 시나리오에서 보유 수량·신주 발행·현금의 관계를 보완하고, BTC 기간별 평가와 미래 차트의 확대·연결을 수정합니다. 공식 CC0 자료 두 개에는 자체 연구 요약과 보관 원문을 구분하는 읽기 화면을 추가합니다. 검토일은 **2026-10-24**입니다.

이번 작업은 이미 병합된 PR #17과 게시된 v1.18.0에서 이어갑니다. 실패한 이전 요청의 로컬 변경이나 테스트 보고를 복구했다고 가정하지 않고 현재 소스에서 확인한 차이를 수정했습니다. [복구 기준과 검증 기록](RECOVERY_2026-10-24.md)을 제공합니다.

## MSTR·BMNR 재무 조건

- 코인 보유량이 경계 없이 증가하던 확대 조건을 보완합니다. MSTR는 BTC 최종 공급량 21m을 산술 경계로 사용합니다. BMNR은 회사 보고 공급 122.1m ETH의 5%인 6.105m ETH를 고정 보유 조건으로 사용합니다.
- 보유 여력에 맞게 신주 발행·순조달·매입을 함께 줄이고, 상한 초과 스테이킹 보상은 비용 조건에 따라 현금화합니다. 코인만 잘라내 현금·주식 수와 모순되는 경로를 만들지 않습니다.
- 공시 재무값, 경영진의 비용·가격 전망, 회사 보고 보유량과 분석자 가정을 구분합니다. 과거 재무 기준일과 명시된 후속 조정을 유지하며 최신 NAV로 표시하지 않습니다.
- 날짜·가격 세션·자산 종류·산술 overflow와 금융비용 조정의 입력 경계를 검사합니다.

상한은 거래 가능성이나 주가의 적정성을 입증하지 않습니다. MSTR 장기 확대 조건은 여전히 매우 큰 누적 조달을 요구합니다. BMNR의 고정 5% 수량·초과 보상 현금화도 앱의 정책 가정이며 미래 총공급 예측이나 경영진의 확약이 아닙니다. [수식·입력](TREASURY_MODEL.md)과 [공식 출처·전후 비교](TREASURY_RECOVERY_RESEARCH.md)를 함께 읽을 수 있습니다.

## BTC 모델 검증

- 긴 평가 기간을 추가했을 때 기존 짧은 기간의 평가 표본·오차가 바뀌던 문제를 수정합니다. 각 기간은 독립적으로 사용할 수 있는 과거 경로를 고릅니다.
- 각 결과에 실제 사용한 기준 연도와 마지막 자료 날짜를 남깁니다. 평가할 수 없는 기간은 제외 사유를 남기고 계산 가능한 기간의 결과를 유지합니다.
- 지원 범위 밖 달력 값과 잘못된 입력 날짜를 조용히 자르거나 제거하지 않습니다. 정상 미래 관측은 고정 기준일 모델의 학습에 사용하지 않습니다.

기존 정상 입력의 상세·장기 출력 동등성, 실패 반례와 회귀 실행은 [BTC 복구 검증](BTC_RECOVERY_VERIFICATION.md)에 기록했습니다. 이번 검사는 예측 적중률·고점과 저점 식별력의 입증이 아닙니다.

## 선·캔들 차트와 근거 링크

- MSTR·BMNR의 월별 계산점 사이로 확대해도 미래 경로를 읽을 수 있도록 표시 범위를 보완합니다. 표시용 보간은 **조건부 가정·보간**으로 구분합니다.
- 주봉에서도 모델의 실제 기준일과 시작 가격으로 미래선을 연결합니다. 주봉 시작일을 새 재무 기준일로 사용하지 않습니다.
- 실제 관측 OHLC 캔들과 미래 조건부 가격선·범위를 구별합니다. 화면 보간으로 미래 체결·OHLC·거래량을 만들지 않습니다.
- 로그축에서 양수와 0 사이의 연결을 생략하고 선형축 안내를 표시합니다. 하한의 0 경계 구간도 임의의 양수나 조기 0으로 만들지 않으며, 실제 0 값과 잔여가치 소진 경고를 보존합니다.
- 근거의 원문 모드를 포함한 직접 링크를 유지합니다.

## CC0 원문 두 개와 요약의 구분

- EIP-1559와 EIP-3675에 **연구 요약 / 보관 원문** 선택을 추가합니다. 두 자료는 이번 복구에서 공식 출처와 허용 범위를 직접 확인해 선정했습니다.
- 원문은 고정 커밋의 Markdown 파일 전체 **43,901바이트**입니다. 해당 판본의 CC0 라이선스도 별도로 보존합니다. 연결된 문서·웹 화면·영상·이미지까지 복제한 것은 아닙니다.
- **요약 MD 저장**과 **원문 MD 저장**을 구분하고, 판본·라이선스·검토 시각·바이트 수·원문 SHA-256을 제공합니다. 자체 요약에는 별도 원문 파일 링크를 둡니다.
- 원문은 일반 텍스트로 표시합니다. 포함 HTML·Markdown·코드는 실행하지 않습니다. 허용 원문을 보관하지 않은 기사·공시·영상에 원문 탭을 만들지 않습니다.

## 검증과 릴리스 파일

최종 코드의 **89개 테스트 파일 통과·실패 0**, 연구·정적·ETH 사건·사이클·성능·요청 소유권 형식 검사의 통과를 확인했습니다. 단일 HTML 생성·검증 결과는 **41,915,758바이트·91개 모듈·5,942개 가격 관측**입니다. 재무 모델의 32개 개별 테스트, 독립 수지 계산 1,694단계와 BTC·원문 리더·차트의 부분 검사는 [복구 검증표](RECOVERY_2026-10-24.md#6-검증-기록의-종류)에서 범위별로 구분합니다. 파일 수·개별 검사 수·계산 단계 수를 더한 새 합계로 표현하지 않습니다. 형식 검사는 제한된 비동기 요청의 소유권을 확인하며 가격 예측을 증명하지 않습니다.

생성된 읽기 자료는 **자체 요약 490개·ID 연결 494개·요약 899,503바이트**이며, 재무 출처 55개와 사건 43개를 포함합니다. CC0 원문 두 개와 라이선스는 별도 명세를 갖습니다. 실제 브라우저·배포·패키지 게시 결과는 해당 소스 커밋의 공개 기록으로 추가 확인합니다.
