# ETHUSD 실제 가격 차트

## 범위와 사용법

v1.15.0은 좌측 상단 종목명에서 **BTCUSD / ETHUSD**를 선택하는 검색 창과, ETH의 **실제 가격선·캔들**을 추가합니다. ETH에는 사이클 분석, 가치평가, 미래 경로, 미래 범위, 고점·저점 예측을 연결하지 않습니다. 기존 BTC 차트의 연구 기능은 BTC에서 사용합니다. v1.16.0에서는 추가 요청에 따라 [실제 역사 사건 표식과 출처](ETHEREUM_EVENTS_RESEARCH.md)를 연결했으며, 이 기록은 가격 계산이나 미래 예측을 포함하지 않습니다.

1. 상단 **BTCUSD → 종목 검색 → ETHUSD**를 선택합니다. `ETH`, `Ethereum`, `이더리움`으로 검색할 수 있습니다.
2. 상단에서 봉 간격과 선·캔들을 선택합니다. 새 ETH 링크의 기본값은 **1D · 가격선 · 로그축 · 최근 약 4년**입니다.
3. 드래그·휠·터치로 이동·확대하고, 십자선이나 방향키로 실제 O/H/L/C를 읽습니다. `C`는 십자선, `H`는 이동 도구입니다.
4. 일·주 화면의 하단 **1개월 / 6개월 / 1년 / 4년 / 전체**는 표시 범위를 바꿉니다. 분·시간 화면은 **최근 구간**으로 초기 조회 범위를 복원합니다.
5. 새로고침 아이콘은 거래소에 새 완료 봉을 조회합니다. 정보 아이콘에서 거래소·조회 범위·수집 시각·공백 수를 확인합니다.

종목을 바꿀 때 봉 간격·선/캔들·로그/선형 선택을 유지하고, 종목별 가격 범위·선택점·연구 설정은 초기화합니다. `?symbol=ETHUSD`로 ETH 화면을 직접 열 수 있습니다. 검색 창은 키보드 이동·Enter 선택·Esc 닫기와 모바일 키보드 영역을 지원하도록 구현했습니다. 구현: [종목 선택](../dist/symbol-selector.js), [ETH 화면](../dist/eth-view.js), [초기 상태·범위](../dist/eth-view-state.js).

## 자료의 정체성과 초기 수집 기록

자료는 **Coinbase Exchange 현물 ETH-USD**입니다. USD를 USDT로 대신하지 않으며, 전체 시장 지수나 여러 거래소의 합성 가격이 아닙니다. 선은 같은 완료 봉의 종가를 연결하고 캔들은 거래소가 제공한 실제 시가·고가·저가·종가를 표시합니다.

아래는 **2026-10-24 15:11:37.456 KST / 06:11:37.456 UTC 초기 수집본**의 고정 기록입니다. 이후 자동 갱신 자료의 범위·수집 시각은 [현재 JSON](../dist/data/eth-ohlc.json)을 확인합니다.

| 항목 | 초기 수집 결과 |
|---|---|
| 완료 일봉 | 3,809개, 2016-05-18 ~ 2026-10-23 UTC |
| 완료 주봉 | 543개, 2016-05-23 ~ 2026-10-12 **시작 주** |
| 최근 저장 간격 | 1m·5m·15m·30m·1h·4h·1D·1W 각각 180개 |
| 일봉 공백 | 2016-05-21, 2016-05-22; 빈 날짜 유지 |
| 최초 조사 시작 | 2016-01-01; 실제 최초 반환 일봉은 2016-05-18 |
| 저장 파일 | `dist/data/eth-ohlc.json` |

현재 진행 중인 UTC 일봉은 제외합니다. 주봉은 월요일 UTC부터 일요일까지 7개 완료 일봉이 있을 때만 생성하므로, 초기 수집 당시 10월 19일 시작 주는 제외됐습니다. 날짜 표시는 **봉 시작 시각**입니다.

## 간격과 집계

| 표시 간격 | 실제 기초 봉 | 처리 |
|---|---|---|
| 1m | 60초 | 거래소 원본 |
| 5m | 300초 | 거래소 원본 |
| 15m | 900초 | 거래소 원본 |
| 30m | 900초 × 2 | 연속된 두 봉만 집계 |
| 1h | 3,600초 | 거래소 원본 |
| 4h | 3,600초 × 4 | 연속된 네 봉만 집계 |
| 1D | 86,400초 | 전체 일봉 아카이브 |
| 1W | 86,400초 × 7 | 월요일 UTC 시작, 완전한 주만 집계 |

집계 시 시가는 첫 봉, 종가는 마지막 봉, 고가·저가는 실제 극값, 거래량은 실제 ETH 수량의 합입니다. 중복·시간 정렬·가격 범위·유한 양수 가격·완료 시각을 검사합니다. 누락 구간을 보간하거나 단일 종가에서 OHLC를 만들지 않습니다. 선도 실제 빈 구간에서 끊깁니다. 화면에는 거래량 패널을 추가하지 않습니다. [검증·집계](../dist/ohlc-data.js), [ETH 아카이브](../dist/eth-market-data.js), [렌더러](../dist/intraday-chart.js)

## 갱신·실패·수집 시각

처음에는 검증한 저장본을 사용합니다. **ETH 화면은 자동 폴링을 하지 않습니다.** 분·시간 화면에서 과거로 이동하거나 축소하면 필요한 실제 과거 봉을 추가 조회하며, 완료 봉 수와 실제 공백을 유지합니다. 수동 새로고침은 분·시간 자료를 다시 조회하고, 일·주 화면에서는 최근 최대 300개 일봉을 기존 아카이브에 병합합니다. 오래된 저장본과 새 조회 사이에 조사하지 않은 기간이 생기면 갱신을 거절하고 기존 자료를 유지합니다.

[정기 갱신 workflow](../.github/workflows/refresh-data.yml)는 **매일 03:20·09:20·15:20·21:20 KST**에 ETH 갱신도 시도하도록 구성했습니다. GitHub 예약 실행은 지연될 수 있습니다. `npm run refresh:eth`는 최근 7일을 다시 확인하며, 최초 구축 시 최대 290개 일봉씩 과거를 조사합니다. 요청 시작 간격은 최소 125ms입니다. 전체 일봉과 모든 최근 간격의 검증이 끝난 뒤에만 임시 파일을 원자적으로 교체합니다. 실패하면 이전 파일과 원래 수집 시각을 보존합니다. [갱신 스크립트](../scripts/refresh-eth.mjs)

수동·정기 갱신 모두 실제로 다시 받은 행만 수집 시각을 변경합니다. 오래된 일봉의 `retrievedAt`과 최초 아카이브 수집 시각 `firstCollectedAt`을 보존합니다. 주봉의 수집 시각은 구성 일봉 7개의 수집 시각 중 가장 늦은 값이며, 무관한 최신 갱신 시각을 과거 주봉에 붙이지 않습니다.

## 구현 경계

| 파일 | 역할 |
|---|---|
| `site-entry.js` | 종목 판별 후 BTC 또는 ETH 진입점을 동적으로 로드 |
| `eth-view.js`, `eth-view-state.js` | ETH 도구·실제 가격·표시 범위·조회 상태 |
| `eth-market-data.js` | ETH 상품 확인, 전체 일·주 자료 검증, 안전한 최근 병합 |
| `ohlc-data.js` | BTC-USD / ETH-USD 허용 목록, 실제 OHLC 파싱·집계 |
| `market-data-controller.js` | 종목별 독립 캐시·저장본·취소 가능한 요청 |
| `intraday-history.js` | 상품을 포함한 탐색 식별자, ETH 이력 시작점, 과거 페이지 조회 |

ETH 진입점은 BTC 앱과 BTC 데이터·연구 작업공간을 초기화하지 않습니다. 시간축·가격축·제스처·실제 봉 렌더러는 공유하며, ETH에 BTC 사이클이나 미래 가격 계산을 실행하지 않습니다. 종목 전환은 별도 문서 탐색으로 요청 수명도 분리합니다. 별도 모델이나 예측 데이터는 ETH 저장본에 없습니다.

## 재현 가능한 검사

Node.js 24 이상에서 실행합니다. 아래는 실행 방법이며, 전체 배포·기기 검수 완료를 뜻하지 않습니다.

```bash
node --test --test-isolation=none tests/eth-market-data.test.mjs tests/eth-chart-rendering.test.mjs tests/symbol-selector.test.mjs
npm test
npm run verify:static
npm run build:standalone
node scripts/verify-static.mjs --standalone build/Bitcoin_Cycles_Comparison.html
```

데이터 검사는 상품 혼합·USDT 치환 거절, 실제 저장 OHLC, 공백, 완전한 집계, 원래 수집 시각, 실패 시 기존 파일 보존을 확인합니다. 렌더러 검사는 8개 간격의 선·캔들 값과 ETH 표시, 실제 선택 정보, 여러 해의 시간축, 빈 구간을 확인합니다. 주봉 수집 시각 검사는 실제 `drawIntradayChart`의 선택 설명까지 읽습니다. 종목 선택 검사는 검색·키보드·URL 상태 분리를 확인합니다. 독립 실행 HTML에도 ETH 저장본을 포함합니다.

실물 모바일·브라우저별 제스처·공개 배포 상태는 해당 실행의 실제 검수와 Actions 결과로 확인해야 합니다. 이 문서는 그 검수를 완료했다는 기록이 아닙니다.

## 공식 출처

- [TradingView — Symbol search: tips for finding assets](https://www.tradingview.com/support/solutions/43000746682/): 상단 종목 검색과 이름·상품·데이터 소스 식별 방식 참고.
- [Coinbase Exchange — Get product candles](https://docs.cdp.coinbase.com/api-reference/exchange-api/rest-api/products/get-product-candles): OHLC 응답 순서, 허용 간격, 요청당 최대 300개, 체결이 없는 구간의 자료 누락 안내.
- [Coinbase ETH-USD 캔들 API](https://api.exchange.coinbase.com/products/ETH-USD/candles): 실제 조회 주소. 각 조사 구간 URL은 저장본 `sourceUrls`에 기록합니다.
