- 기존 시장·주식 검증을 변경 전 그대로 실행: 두 모델과 실제 코드 변이 검사가 통과했다. 기존 동기화 커밋 `c7fbf50c34a45386300336756b5fd42a0fab0363` 이후의 가격 정보 링크·CSS·모듈 URL 변경은 요청 소유권 모델의 상태·가드를 바꾸지 않는다. 스킬의 동기화 기록은 최종 코드 검증 뒤 갱신한다.
- 기준 커밋의 107개 최상위 JavaScript 모듈에 정적 오류 규칙 14개를 적용: ETH 정보 창의 `esc` 미정의를 독립 확인했다. `evidence-view.js`의 행 감소 루프와 `market-data-controller.js`의 비동기 페이지 진행 루프는 실제 종료 조건을 확인해 오탐으로 분류했다.
- 배포된 v1.22.1 ETH 화면에서 정보 버튼을 직접 클릭: 대화상자가 열리지 않고 `eth-view.js?v=1.22.0`의 `renderInfo`에서 `ReferenceError: esc is not defined`가 발생했다. 테스트 fixture만의 오류가 아니다.
- BTC의 수동·게시 스냅샷 갱신을 검토: 수동 완료 뒤 늦은 게시 응답은 자료 객체 소유권으로 거절되고, 더 오래된 종료일은 채택되지 않는다. 이 읽기 검토에서 새로 재현한 BTC 갱신 결함은 없다. 브라우저·네트워크의 모든 실행 순서를 증명했다는 의미는 아니다.
