# 성능·수학·상태 전이 심층 점검

검토 기준은 공개 v1.20.0 커밋 `347997f02d3674259d4ad6e1f788419bde4811bd`다. 이전 보고의 통과 수를 재사용하지 않고 현재 코드를 실행했다. 이번 v1.21.0은 재현한 입력 손실과 수치 오류를 수정하고, 관측 화면을 먼저 공개하며, 같은 계산·모듈의 중복을 줄인다.

## 발견한 문제와 처리

| 영역 | 재현한 문제 | 수정과 검증 |
|---|---|---|
| 주식 자료 갱신 | 시작·종료일과 행 수가 정상이어도 과거 세션 하나가 빠진 응답이 기존 파일을 덮어씀 | 이전의 모든 세션이 새 전체 응답에 존재해야 교체. 실패하면 원래 바이트 유지. 정상적인 분할 조정 전체 교체는 허용 |

금융 수치 경계의 반례를 실제 시세의 대규모 오류로 일반화하지 않는다. 예를 들어 선형식의 약 53% 상대 오차는 `1e-200`과 `1e200`이라는 유한한 극단 입력에서 재현했다. 정상 관측의 가격 경로와 범주형 분석 결과에 대한 비교는 별도 고정 입력 기록으로 확인한다.

[최종 통합 비교](data/system-math-integration-2026-10-24.json)에서 여섯 2035년 경로의 20,142행은 새 평가 상태를 제외하면 정확히 같았다. 시장 분석은 되돌림 수치 1,338개만 마지막 자리 수준으로 달라졌고 최대 정규화 차이는 약 `1.77e-15`였다. 그 외 분석 결과는 정확히 같았다.

## 성능 측정

시간은 Node의 계산과 SVG 문자열 생성에 한정했다. 각 쪽 두 번 준비 실행 뒤 변경 전·후를 번갈아 일곱 번 측정했다. 해시와 전체 결과 비교는 타이머 밖에서 수행했다.

| 동일 입력 작업 | 변경 전 중앙값 | 변경 후 중앙값 |
|---|---:|---:|
| MSTR 세 조건과 첫 SVG 생성 | 933.31 ms | 699.94 ms |
| 미래 90일 구간을 연속 20회 다시 그리기 | 97.11 ms | 12.74 ms |

첫 작업 시간은 25.0% 줄었다. 모든 측정에서 10,071개 재무 행과 SVG 문자열은 그대로다. 기본 128개 원천 표본으로 2050년까지 BTC 다섯 조건의 모든 필드도 기존 단일 API와 새 단일·일괄 API가 정확히 같았다. [측정 범위·전체 표본·프로파일](SYSTEM_PERFORMANCE_AUDIT.md)을 제공하며, 이후 수치 수정과 분리해서 재현할 수 있는 패치도 보존한다.

동일한 `7e90d01` 입력의 단일 HTML은 **46,329,219 → 8,201,994바이트**, 82.30% 감소했다. 각각 다섯 번의 결과가 해시까지 일치했고 모듈 93개·연결 228개·JSON 여섯 개·CSS 22개·favicon을 유지했다. 통합 수정 뒤 최종 HTML은 **8,203,762바이트**다. [패키징 감사](SYSTEM_STANDALONE_AUDIT.md)에서 두 측정 입력과 검증 범위를 구분한다.

이 숫자는 브라우저 페인트·입력 지연·모바일 메모리 측정이 아니다. 차트의 전체 경로 검증은 여전히 선형이고, 전체 범위를 그리는 비용은 보이는 자료 수에 비례한다. 전역 재무 결과 캐시는 도입하지 않았다. 같은 날짜의 가격이 수정되면 새 호출에서 다시 계산한다.

## 수학적 항등식과 해석

보통주 잔여가치를 `코인 가치 + 현금 + 포함 자산 − 선순위 청구권`으로 정의한다. 비용 지출은 비용과 코인 매각비용만큼 잔여가치를 줄인다. 원금 지급은 같은 금액의 채무도 줄이므로 매각비용이 없을 때 잔여가치를 보존한다. 원금이 실제 채무보다 많지 않다는 전제가 필요하며, 이번에 그 전제의 구현 오류를 고쳤다.

금융 상태가 한 번 흡수되면 기존 청산 스트레스 규칙에 따라 운영·발행을 중단하고 주가 가정 0을 유지한다. 코인 가격 상승으로 동결 잔고의 잔여가치가 양수가 되어도 보통주 회복을 계산하지 않는다. `components.insolvent`는 당일 잔여가치, `valuationState`는 경로의 종료 상태다. 둘의 의미를 섞지 않는다. MSTR·BMNR 각각 실제 재무 모형의 충격·회복 결과를 근거 화면에 전달하는 회귀 검사도 추가했다.

[수학 감사](SYSTEM_MATH_AUDIT.md)와 [재무 경로 정의](TREASURY_PATH_MODEL.md)는 실수 산술의 항등식, 유한한 수치 경계 검사, 시장 가정을 구별한다. 반감기·4년 패턴·재표본 블록·잔차 평균회귀·재무 항등식이 미래 가격 정확도나 발생 확률을 증명하는 것은 아니다. 특히 고저점 표식은 모의 경로의 사후 반전 구분이며, 세 조건의 음영은 가능한 손실 전체의 경계가 아니다.

## 상태 전이와 프로젝트 스킬

pstack `create-formal-verification-skill` 절차로 `.agents/skills/verify-equity-state/`를 만들었다. 생산 초기화 코드와 실제 inline boot script를 실행하는 재생, TLA+ 모델, 임시 제품 코드 변이, 재실행 명령과 동기화 기록을 함께 둔다. 기존 BTC·ETH의 `verify-market-state`는 별도로 유지하고 코드 변경 이력을 다시 대조한다.

주식 모델은 요청 세대 3개, 일·주 표시, 자동·사용자 지정 구간을 탐색한다. **303,261개 생성 / 46,252개 구별 / 대기 0**에서 현재 불변식이 통과했다. 이전 부팅 순서와 잘못된 모델 구성 여섯 개는 지정된 반례를 낸다. 실제 UI 재생 28개가 통과하고, 보호 장치를 제거한 실제 코드 변이 일곱 개는 각각 의도한 assertion에서 실패하며 복원 후 다시 통과한다.

[상태 전이도 PNG](formal-equity/comparison/chart.png) · [Mermaid](formal-equity/comparison/chart.mmd) · [반례 이야기](formal-equity/comparison/stories.md) · [모델과 코드 대응](formal-equity/README.md)

그림은 사용자 관점의 요약으로 상태 아홉 개와 전이 열한 개를 표시한다. 생성 요약에는 생략한 투영 전이 31개를 별도로 기록하고, 두 모델의 출처가 없는 가드 목록은 비어 있다. 그림을 전체 내부 전이 관계로 해석하지 않는다. 정지 문서에 늦은 callback을 전달한 검사는 방어 강화이며 특정 브라우저 스케줄러의 실측 사실이 아니다.

## 통합 검증

현재 소스에서 일반 `npm test`와 단일 프로세스 실행 모두 **908개 검사, 실패·취소·건너뜀 0개**를 확인했다. 독립 일별 검산은 여섯 경로의 2050년까지 **53,010개 재무 전이와 26,505개 ETH 잔차**, 잘못된 입력 거절 열 가지를 대조했다. 기본 UI와 릴리스 계산의 종료일은 2035년이며 검산의 2050년과 구별한다.

```sh
npm test
npm run verify:research
npm run verify:eth-events
npm run verify:treasury-paths
npm run verify:formal
npm run verify:cycle
npm run verify:performance
npm run verify:static
npm run build:standalone
node scripts/verify-static.mjs --standalone build/Bitcoin_Cycles_Comparison.html
```

단일 HTML 검사는 모든 모듈의 원본 소스와 연결, JSON 전체, CSS·favicon을 비교한다. 실제 Node VM 파서·링커로 93개 생산 모듈을 확인하고 별도 작은 그래프를 평가해 공유 인스턴스·순환·동적 가져오기를 실행했다. 매핑 삭제·소스 변경·BTC 값 변조를 놓치지 않는 대조군도 포함한다. 브라우저의 실제 `file://` 실행은 이 결과에 포함하지 않는다.

자체 연구 요약 490개·식별자 494개, 재무 출처 55개·역사 사건 43건, 허용된 CC0 원문 두 개를 그대로 유지했다. 외부 저작물 전문을 추가하지 않았다. 자료 제공자의 진위, 최신 회사 재무 전체, 조달 가능성, 주가 예측 우위, 물리 모바일 기기의 전체 동작은 이번 검사의 증명 범위 밖이다.

## 독립 검토와 공개 경로

작성자가 아닌 별도 작업자가 수학·자료·상태 변경과 패키징을 검토했다. 최대 유한값의 새로운 로그 반례와 Node 24.0 호환성 문제를 추가로 발견해 게시 전에 수정했다. [독립 검토 기록](SYSTEM_INDEPENDENT_REVIEW.md)과 원본 측정·모델 JSON을 함께 보존한다.

pstack은 `9580c23696ac8d7abed0c166f2f9918800afb819` 판본의 병렬 소유권, 원인 수정, 증거 확인, 상태 전이 및 검증 스킬 생성·유지 절차를 사용했다. 실제 실행은 GPT-6 Astra 작업자와 현재 제공된 GitHub·명령 도구로 수행했다. 사용할 수 없는 Cursor Task·Grok·Opus를 실행했다고 주장하지 않는다.

기준 브랜치·커밋·PR·릴리스를 읽은 뒤 새 변경만 준비했다. 관련 없는 PR #12는 통합하지 않았다. 공개 시에는 작은 blob과 SHA만 담은 tree를 검증하고, 최종 소스 커밋과 CI·Pages·릴리스의 일치를 확인한다. 공개된 정확한 결과는 [Actions](https://github.com/twoimo/bitcoin-cycle-atlas/actions)와 [v1.21.0 릴리스](https://github.com/twoimo/bitcoin-cycle-atlas/releases/tag/v1.21.0), 릴리스 메타데이터를 따른다.
