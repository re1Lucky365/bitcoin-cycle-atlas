# v1.21.0 · 성능·수학·상태 전이 감사

공개 v1.20.0을 기준으로 자료 손실, 재무·수치 경계와 초기 화면의 실제 결함을 재현하고 수정했다. 중복 계산과 단일 HTML 포장을 줄였으며, 모델·실제 코드·고의로 깨뜨린 대조군을 함께 검사하는 프로젝트 스킬과 상태 전이도를 추가했다. [전체 감사 보고서](SYSTEM_AUDIT_SUMMARY.md)를 제공한다.

## 달라진 동작

- MSTR·BMNR의 관측 차트를 먼저 열고 코인 자료와 전망은 별도로 준비한다. 계산 중 바꾼 간격·시나리오·날짜 구간을 보존한다.
- 주식 전체 자료에 과거 세션이 빠졌으면 기존 파일을 유지한다. BTC 전체 자료의 일반 일자 누락도 갱신·캐시 진입 전에 거부한다.
- 실제 채무보다 많은 원금을 지급하지 않으며, 극단적인 유한 가격의 선형·로그 되돌림 계산을 안정화한다.
- 미래 전망과 근거에 평가 상태를 표시한다. 잔여가치 소진 후 0을 유지하는 조건과 당일 잔여가치의 의미를 구별하고 실제 모델의 공식을 그대로 보여 준다.
- MSTR 세 조건의 공통 BTC 준비 계산을 한 호출에서 공유하고 미래 차트의 구간·표식 검색을 줄인다.
- 단일 HTML은 모듈당 한 번의 data URL을 import map으로 연결한다. 같은 모듈을 의존 경로마다 반복 포함하지 않는다.

## 측정과 검증

동일 입력, 변경 전·후 일곱 회 교대 측정에서 MSTR 세 조건 계산과 첫 SVG 생성의 중앙값은 **933.31 → 699.94 ms**로 25.0% 줄었다. 90일 구간 스무 번 다시 그리기는 **97.11 → 12.74 ms**였다. 금융 출력과 SVG 문자열의 정확한 동등성을 타이머 밖에서 검사했다. 브라우저 페인트·네트워크·모바일 입력 지연을 측정한 값은 아니다.

고정 입력 단일 HTML은 다섯 회씩 재생성해 **46,329,219 → 8,201,994바이트**, 82.30% 감소를 확인했다. 모듈 93개·연결 228개·JSON 여섯 개·CSS 22개·favicon을 보존했다. 통합 뒤 최종 파일은 **8,203,762바이트**다. 실제 `file://` 브라우저 실행은 별도 미검증 범위로 남긴다.

일반 `npm test` **908개**, 연구 보존·ETH 사건·일별 재무·사이클·성능·정적·단일 HTML 검사가 통과했다. 두 상태 검증을 `npm run verify:formal`에서 함께 실행한다. 주식 모델은 **46,252개 구별 상태**를 완전 탐색했고 실제 UI 재생 **28개**, 의도적인 실제 코드 변이 **7종**을 확인했다. 기존 캔들 요청 모델은 **2,081개 구별 상태**, 실제 회귀 **30개**와 저장 응답 가드 제거 대조군을 유지한다.

## 모델과 보존 범위

MSTR·BMNR의 정상 저장 입력에서 금융 경로는 유지했다. 새 `valuationState`는 이미 적용하던 흡수 규칙을 명시한다. 최신 NAV, 미래 조달 가능성, 주가 예측 정확도나 보정된 발생 확률을 입증한 변경은 아니다. BTC의 4년 패턴을 주식에 복사하지 않으며 기존 자산 경로와 회사의 보유량·현금·청구권·희석 계산을 연결한다.

자체 연구 요약 490개와 허용된 CC0 원문 두 개의 범위는 그대로다. 공개 외부 자료의 전문을 추가로 복제하지 않았다. 릴리스의 재무 JSON은 화면과 같은 여섯 2035년 경로를 생성하며 소스 커밋·입력 해시·흡수 상태 의미를 기록한다. 2050년 독립 검산의 종료일과 구별한다.

이 릴리스는 pstack 지침을 실제 사용 가능한 GPT-6 Astra 작업자와 도구로 병렬 적용했다. 별도 독립 검토에서 추가 반례를 찾아 수정했으며, 사용할 수 없는 Grok·Opus 실행으로 표시하지 않는다. 정확한 게시 소스와 결과는 첨부 메타데이터 및 해당 커밋의 Actions에서 확인한다.
