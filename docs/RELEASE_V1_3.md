# Bitcoin Cycle Atlas v1.3.0

가격·방향 후보·D-day·선택한 값·갱신 시각을 한 뷰포트의 차트로 통합했습니다. 기본 화면의 탭 줄과 긴 설명, 별도 고저점 카드, 여백을 제거했습니다.

## 화면

- 아이콘 사이드바와 차트 내부 아이콘 메뉴.
- TradingView 구성을 참고한 오른쪽 가격축, 가격·날짜 십자선, 최근 관측 가격 표시. 휠 확대·가로 드래그·차트 내부 이동/확대/초기화 아이콘과 키보드 대안.
- 그래프 종류 하나의 메뉴로 가격과 미래, 4년 비교, 구간 길이, 고점권 도달, 월·분기, CryptoCon 검증을 전환.
- 실제 할당 높이와 폭으로 그리는 반응형 SVG. 선택 정보·모형 근거·긴 설명은 요청할 때 같은 화면 안에서 확인.
- 87개 자료를 우선순위로 정렬. 제목 검색·CryptoCon 필터·화면 높이에 맞는 페이지 이동.

## CryptoCon 검증

공식 목록 492항목의 제목을 점검하고 65개 고유 원본 URL을 접근 수준별로 기록했습니다. 전체 X 계정·유료 본문·모든 영상을 읽었다는 뜻은 아닙니다. 최초 전망, 수정 전망, 사후 설명을 분리했습니다.

95% 고점권에 2025년 7월 13일 처음 도달한 뒤 10월 6일까지 85일이 걸렸지만, 86일 중 16일만 95% 이상이었습니다. 그 사이 MDD는 −12.25%입니다. 기준을 99%로 바꾸면 선행일은 0일입니다. 날짜 창과 가격 목표의 적중 여부를 별도로 비교합니다.

## 주기 갱신

GitHub Actions가 매일 03:20·09:20·15:20·21:20 KST에 완료된 UTC 일말 자료를 확인합니다. 날짜·연속성·가격·기존 기록을 검증한 뒤 테스트·커밋·Pages 배포를 같은 실행에서 수행합니다. 실패하면 기존 자료를 유지합니다. 화면은 실제 확인 시각과 관측일을 구분합니다. 예약 실행은 GitHub 대기나 제공자 지연의 영향을 받을 수 있습니다.

고정 연구 계산·PNG·과거 검증표는 2026-10-20 UTC 표본을 유지합니다. 미래 경로와 D-day는 선택한 가정의 계산 결과이며 시장 일정의 수학적 증명이 아닙니다.

## 파일

단일 HTML, 고정 연구 PNG, 계산 JSON, 종합 연구 문서, 소스 ZIP, 메타데이터와 SHA-256 체크섬을 제공합니다. 종합 문서에 새 사용 안내와 CryptoCon 감사가 포함됩니다.
