시작 기준은 `0dcc7760d14c93f9038ea5ae26743a4dd9e06f03`이다. 2026-10-24 원격 `main`, 작업 브랜치, 열린 PR과 릴리스를 다시 읽어 확인했다. v1.19.0은 이미 게시되어 있으며 같은 태그를 다시 만들지 않는다.

## 완료 조건

MSTR는 기존 BTC 엔진이 실제로 반환하는 일별 조건부 경로를 소비한다. BMNR는 ETH 과거 자료에서 만든 별도 경로를 소비한다. 세 코인 조건을 각각 회사 재무 전이에 넣고, 같은 날짜의 주당 결과를 차트와 근거 화면에 표시한다. 일·주 단위 선과 모의 경로봉을 구분하며, 계산·표시·공개 릴리스의 소스가 일치해야 한다.

이번 검증은 경로 연결, 회계 수지, 경로 의존성, 입력 경계와 화면 동작을 확인한다. 과거 시점의 전체 기업 공시를 복원한 주가 예측 백테스트나 보정된 확률구간을 제공하지 않는다.

## 데이터와 소유권

기초자산 생성기는 `buildTreasuryAssetPaths({symbol, btcHistory, ethHistory, asOf, endYear, seed})`이다. 반환값은 `{asset, asOf, endDate, scenarios, metadata, warnings}`이며 `scenarios`에는 `stress`, `base`, `bull`의 일별 `date`, `price`, 출처와 방법이 있다. 실제 장중 OHLC를 만들어 넣지 않는다.

재무 엔진은 `buildTreasuryForecasts({symbol, history, assetPaths, ...})`로 세 결과를 한 번에 계산한다. 기존 단일 선택 API는 같은 계산을 재사용한다. `assetPaths`가 없는 목표 연결 계산은 전후 비교에 사용하는 별도 유효 모드로 남긴다.

| 소유 범위 | 담당 |
|---|---|
| BTC 재사용·ETH 경로·자료 경계 | 자산 경로 에이전트 |
| 일별 회계·모델 문서·회계 회귀 | 재무 경로 에이전트 |
| 별도 검산·반례·최종 읽기 검토 | 독립 검토 에이전트 |
| 차트·화면·자료 로딩·통합·원격 게시 | 주 담당자 |

생성물과 버전 갱신은 통합 담당자가 처리한다. 다른 담당자의 파일을 동시에 편집하지 않는다. 모두 이 세션에서 제공된 GPT-6 Astra 에이전트이며 pstack의 Grok·Opus·Cursor 전용 실행을 했다고 표시하지 않는다.

## 설계 선택

두 후보를 비교했다. 기초자산 경로를 별도 값으로 만든 뒤 기존 회계 전이를 재사용하는 구조를 선택했다. BTC 엔진을 ETH까지 범용화하거나 코인·회계를 새 결합 엔진에 복제하는 구조는 반감기·공급·평가 근거를 잘못 공유할 위험과 기존 BTC 출력 변경 범위가 커서 채택하지 않았다.

MSTR 조건은 BTC 엔진의 `stress`, `base`, `accelerated`와 연결한다. 경영진의 다른 가격 목표는 출처에 있는 주장으로 보존하고 연동 경로에 강제로 끼워 넣지 않는다. ETH에는 BTC의 4년 반복을 적용하지 않는다.

조건 범위는 세 개의 완결된 경로를 각각 재무 계산한 결과의 최소·최대다. 통계적 분위수·신뢰구간·적중확률로 표시하지 않는다. 일별 회계는 주말을 포함한 달력일을 사용하고, 주식 화면의 모의 구간봉은 표시 간격을 따로 관리한다. 모의 구간봉의 범위와 세 조건의 범위를 다른 필드로 보존한다.

## 검증 기록

검증 결과는 실행한 뒤 이 절과 별도 결과 파일에 기록한다. 작업을 시작했다는 사실을 통과로 기록하지 않는다. 설계상 확인할 반례는 동일 종착 가격의 다른 경로, 주말 비용과 상환, 미래 관측 추가, 일별 입력 누락·중복, 잔여가치 0, 주봉의 실제·모의 구간 분리다.

## 게시 전 통합 검증

2026-10-24 현재 소스에서 93개 테스트 파일이 모두 통과했다. 연구 생성물 490개 요약·494개 식별자·55개 재무 출처·43개 사건과 CC0 원문 두 개의 일치, ETH 사건 생성물, 정적 경로, BTC 사이클 보정, 차트 경계, 요청 소유권 형식 검사와 정상/결함 대조를 확인했다. 단일 HTML은 46,006,275바이트·93개 내장 모듈로 생성하고 프로젝트 경로와 내장 관측을 검사했다. 실제 file:// 브라우저 실행이나 실물 휴대기기 검증으로 확대하지 않는다.

독립 보고서는 2026-10-23 고정 관측의 6개 조건·53,010개 일별 재무 전이와 26,505개 ETH 잔차, 10개 거부 경계를 기록한다. 소스·입력 해시는 실행 전후 일치를 확인했다. 관련 경로봉/렌더러/기존 분봉의 개별 검사는 19+5+4개다.

독립 검토에서 중복 고저점, 오래된 코인 앵커, ETH 출처 정체성, 비동기 초기 범위, 주봉 평가일, 주말 날짜 이동, 모의 자석 측정 표시와 두 자체 연구 본문이 같은 URL로 합쳐지는 회귀를 수정했다. 각 담당자의 마지막 검토에 미해결 중대 결함은 없다. 코드 검토·자동 검사 범위와 공개 화면 검증은 구별한다.

위 기록은 게시 전 소스에 고정된다. PR·CI·실제 배포·릴리스 자산의 결과는 해당 PR 및 GitHub Actions, 릴리스의 정확한 커밋에서 최종 확인한다.
