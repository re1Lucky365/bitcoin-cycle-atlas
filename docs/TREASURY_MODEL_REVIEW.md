# Treasury model: independent evidence and implementation review

검토일: 2026-10-24. 대상: MSTR·BMNR 연구 JSON, 생성된 출처 레지스트리, `treasury-model.js`, 미래 근거 연결, 관련 수치 테스트. 이 문서는 출시 전 발견한 문제와 실제 검증 범위를 기록한다. 예측 적중률이나 투자 성과에 대한 검증은 아니다.

## 1. 재무 기준과 주장 판정

MSTR의 계산 기준은 [2026년 6월 말 10-Q](https://www.sec.gov/Archives/edgar/data/1050446/000105044626000044/mstr-20260630.htm)다. 846,000 BTC, 현금 $1,711,837,000, 단기투자 $736,145,000, 채무 원금 $6,713,659,000, 우선주 청산우선권 $15,462,056,000, 기타부채 $565,495,000, 기말 보통주 371,603,000주를 같은 날짜에서 가져왔다. 기타부채 계산에서는 채무 **장부가**를 총부채에서 제외한 뒤 채무 **원금**을 별도로 차감한다. 전환사채를 차감하는 동시에 같은 채권의 전환주식을 분모에 더하지 않는다.

10월 보유량은 최근 동향 자료로 분리되어 있다. 최신 BTC를 과거 보통주 수로 나누는 현재 NAV는 계산하지 않는다. 실제 실행에서 MSTR는 재무일 2026-06-30, 주가일 2026-10-23, `currentNavClaim: false`를 반환했다. BMNR도 2026-05-31 재무구조와 최초 BMNP 발행의 명시적 조정을 사용하는 과거 구조 민감도다. 이후 모든 매입·매각·발행·전환을 복원한 재무제표는 아니다.

세일러 목표는 서로 다른 발표다. [2024 Nashville 자료](https://assets.contentstack.io/v3/assets/bltdef7a3f3c28ddd84/blt8053254ac26aa0a4/66a7a137cfbd232be87d6bbc/Bitcoin_Nashville_24_Saylor_Presentation.pdf)의 2045년 $13m과 [2025 Prague 자료](https://assets.contentstack.io/v3/assets/bltdef7a3f3c28ddd84/blt32a376ef7e228b72/68597f38cbfa9d7c860d952d/Bitcoin_Prague_25_Saylor_Presentation.pdf)의 21년 후 $21m을 합치지 않는다. 후자의 2046년은 2025+21의 산술이다. 앱의 12월 31일 배치는 연간 가격조건을 연결하는 모델 규칙이며 발표자가 지정한 일·월이 아니다. 두 대용량 PDF는 공식 사이트의 링크·발표일과 검색 가능한 발췌만 확인했으므로 `verified-excerpt`로 남겼다.

최종 생성물에서도 Prague 자료의 접근 등급·두 주장·PDF 전체 미열람 한계가 원본 JSON, 생성된 treasury 카탈로그, 통합 읽기 레지스트리, Markdown 보관물에 일치하는 것을 직접 확인했다. 초록만 확인한 학술 자료 역시 `verified-excerpt`가 유지된다.

### 교차검증이 증명하는 범위

- 회사 10-Q·8-K·보도자료·대시보드 간 숫자의 일치는 **동일 발행사의 보고 일관성**이다. 독립적인 수탁잔고 감사가 아니다.
- [VanEck의 자본구조 연구](https://www.vaneck.com/us/en/blogs/digital-assets/matthew-sigel-deconstructing-strategy-mstr-premium-leverage-and-capital-structure/)는 발행사 외부 분석이지만 BTC·MSTR·STRK·STRF 보유 이해관계를 공개했다. 무관계 평가기관의 보증이나 독립적인 목표가 합의로 표현하지 않는다.
- [39개 BTC 보유기업 연구](https://arxiv.org/abs/2505.14655)는 초록과 연구 범위를 확인했다. 시간에 따라 변하는 정보흐름·동조성은 고정 2배 레버리지, 인과관계, 미래 주가 적중률을 증명하지 않는다. 초록 확인 수준을 `verified-excerpt`로 명확히 했다.
- BMNR의 날짜 없는 ETH·주가 목표는 `conditional`로 보존한다. VanEck의 2024년 ETH 2030 조건과 톰 리의 날짜 없는 목표에 같은 달성시점을 부여하지 않는다.

## 2. 발견 사항과 수정 기준

| 항목 | 발견 내용 | 검토 상태 |
|---|---|---|
| MSTR 스테이킹 손실 | 공통 스트레스 설정이 BTC에도 5% slashing 손실을 적용했다. | BMNR에만 적용하도록 수정된 코드를 확인. 현금이 충분한 100 BTC 사례를 실행해 1년 후 100 BTC 유지 확인. |
| 경영진 목표 선택 | 목표연도 순 정렬은 가장 최근 발언과 다른 목표를 선택할 수 있다. | 발표일 우선 정렬로 수정 확인. 실제 경로는 Prague $21m·2046을 선택. |
| 스트레스 출처 | 자체 BTC 50%·30% 조건이 WisdomTree 소스로 연결되어 있었다. | `mstr-model-method`로 수정 확인. 기준 시나리오의 $275k·$710k는 WisdomTree, 강세는 Saylor로 분리. |
| 미래 근거 버튼 | 회사 자료만 조회하여 통합 레지스트리의 계산법·기관 평가 소스 버튼이 누락되었다. | 차트 담당자가 통합 레지스트리 lookup으로 수정했다고 보고. 데이터 수준에서 모든 참조 ID의 해소를 직접 확인. |
| 기타자산 할인 | BMNR의 비유동 지분·영업권 회수율 가정이 MSTR 단기투자에도 공통 적용되었다. | BMNR에 한정하고 MSTR 할인율을 0으로 수정한 코드 확인. MSTR는 공시 단기투자 금액 고정이며 미래 수익·손실을 추정하지 않는다고 표시. |
| 과거 정보 이용 | 현재 연구를 과거 cutoff에 넣으면 당시 알려지지 않은 발표를 이용할 수 있다. | 현재 연구 지식일 이전 cutoff를 명시적으로 거부하는 guard 확인. 역사 백테스트를 지원한다고 표시하지 않는다. |
| 날짜 오류 테스트 | 새 cutoff guard로 기존 오류 메시지 정규식과 불일치. | 오류 기대값 및 별도 과거 cutoff 검사가 수정됨. 최종 직접 실행에서 23개 모두 통과. |

## 3. 실제 실행한 확인

연구 JSON의 출처 중복과 모든 `sourceIds`·`crossCheckIds` 참조를 확인했다. MSTR 현금상환 청구 가능일의 원금 합계는 $6,713,659,000으로 기준 원금과 일치했다. 청구 가능일은 계약상 선택권이며 실제 상환 확정일이 아니다. 모델은 각 날짜에 전액 현금상환하는 별도 조건을 적용한다.

저장된 실제 주가 자료를 이용해 MSTR·BMNR × 스트레스·기준·채택 확대의 6개 계산을 직접 실행했다. 각각의 첫 값이 2026-10-23 관측 종가와 같고, 음수·무한대·NaN 가격이 없으며, 세 조건의 최소·최대가 선택 경로를 포함하는지 확인했다. 모든 경로·미래 표식의 출처 ID가 통합 연구 레지스트리에서 해소되었다. MSTR 기준 경로의 채무는 2027-09-15에 $5,703,659,000, 2029-06-15에 0으로 감소했다. 원금 지급과 채무 제거가 함께 일어나며, 현금·BTC가 부족할 때 미지급액을 기타부채로 남기는 단위 테스트도 확인했다.

최종 명령 **`node tests/treasury-model.test.mjs`**를 직접 실행하여 23개 테스트가 모두 통과한 것을 확인했다. `node --test tests/treasury-model.test.mjs`도 종료코드 0이었지만 이 환경에서는 파일 단위 1개 pass만 표시하므로 단위 테스트 개수의 근거로 사용하지 않았다. 두 최종 명령 전후에 모델·테스트 파일의 SHA-256이 같아 검사 중 파일이 변경되지 않았음을 확인했다. 전체 저장소 테스트·브라우저·배포 검사는 이 문서의 독립 검증 범위에 포함하지 않는다.

## 4. 남아 있는 해석상의 한계

조건부 자산가격의 로그 보간, 발행 연율, 프리미엄 수렴, 무상 희석, 운영비, 수수료는 분석자가 지정한 민감도다. 미래 가격의 경험적 확률분포나 예측력을 추정한 값이 아니다. 세 경로 음영을 신뢰구간으로 해석하지 않는다.

MSTR의 연 금융비용 대용치는 기준 공시 당시 우선배당·이자 예상액이다. 실제 확정 채무만을 더한 수치나 전체 영업비용이 아니다. 모델은 상환 뒤에도 금융비용 감소를 가정하지 않는 보수적 단순화를 공개한다. 단기투자자산은 잔여가치에 포함되지만 현금지출 waterfall에서 자동 현금화하지 않으므로 실제 현금관리와 차이가 있다. BMNR의 7일 스테이킹 연율을 장기 유지하거나 추가 비용을 차감하는 과정도 미래 보상 확정이 아니며, 원 보고 수익률의 비용 범위가 불명확하면 중복 차감할 수 있다.

잔여가치 소진 이후 주가 가정을 0으로 유지하는 규칙은 스트레스 종료 규칙이다. 법적 도산 시점·청산 회수액·이후 재조달 가능성까지 추정한 것은 아니다. 연구 보관물은 직접 작성한 설명·검증·메타데이터와 원문 미디어 링크이며 제3자 전문·영상·이미지의 완전 백업이 아니다.
