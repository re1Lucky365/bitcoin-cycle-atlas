# 기초자산 경로와 MSTR·BMNR 재무 계산

검토일은 2026-10-24다. 이 문서는 BTC 또는 ETH의 일별 조건부 경로가 회사의 보유량, 현금, 선순위 청구권, 주식 수를 거쳐 주당 가치로 변환되는 방식을 설명한다. 가격의 적중률이나 실제 조달 가능성을 검증한 문서가 아니다.

## 1. 두 계산 방식의 구분

| 모드 | 기초 코인 가격 | 재무 계산 시점 | 용도 |
|---|---|---|---|
| `asset-linked-daily` | [기초자산 경로 모듈](../dist/treasury-asset-paths.js)이 반환한 각 날짜의 가격 | 주말을 포함한 매일 | 변동하는 코인 경로를 주식의 재무 구조에 연결 |
| `target-interpolation` | 기존 출처별 가격 조건 사이의 로그 보간 | 약 30일 간격과 연말, 가격 조건일, 상환일 | 이전 목표 연결 방식과 비교 |

두 모드는 [treasury-model.js](../dist/treasury-model.js)의 같은 재무 계산을 사용한다. 별도 엔진에 발행, 상환, 비용 처리를 복제하지 않았다. `assetPaths`가 있으면 날짜와 코인 가격의 입력만 달라진다. 이전 목표 연결 방식은 명시적 비교 기준으로 남아 있다.

MSTR 연동 방식은 BTC 화면의 `buildLongHorizonForecast()`를 직접 호출한 결과를 사용한다. 재무 `stress`, `base`, `bull`은 BTC 엔진의 `stress`, `base`, `accelerated`와 연결된다. 이 경로에 세일러의 별도 목표 가격을 강제로 적용하지 않는다. 세일러의 목표를 사용하던 기존 확대 조건은 비교 모드에 남는다.

BMNR 연동 방식은 Merge 이후 ETH 관측의 수익률 블록을 사용한다. BTC의 4년 주기를 ETH에 복사하지 않는다. 기본 조건의 2030년 기준선은 현재 가격 유지, 스트레스는 $360, 확대는 $22,000이다. 현재 가격 유지와 2030년 이후 기준선 유지는 앱 가정이다. $360과 $22,000의 외부 평가 출처와 의미는 [기존 재무 계산 설명](TREASURY_MODEL.md)에 있다. 재표본 잔차가 더해지므로 실제 모의 경로는 기준선의 목표값을 통과하도록 강제되지 않는다.

## 2. 입력과 반환값

`buildTreasuryForecasts(options)`는 같은 입력으로 세 조건을 한 번씩 계산해 `{stress, base, bull}`을 반환한다. UI는 이 묶음을 재사용할 수 있다. `buildTreasuryForecast(options)`는 같은 묶음에서 요청한 조건 하나를 반환한다.

기초자산 입력의 구조는 다음과 같다.

```js
{
	asset: 'BTC',
	asOf: '2026-10-23',
	endDate: '2035-12-31',
	scenarios: {
		stress: {id, path, method, sourceIds, anchors, training},
		base: {id, path, method, sourceIds, anchors, training},
		bull: {id, path, method, sourceIds, anchors, training},
	},
	metadata,
	warnings,
}
```

각 `path`는 `{date, price, baselinePrice?, kind, sourceIds?}` 행의 배열이다. 재무 입력 경계는 다음 조건을 검사한다.

- 코인 종류, 기준일, 종료일, 조건 식별자가 재무 입력과 일치한다.
- 경로는 기준일부터 종료일까지 중복, 역순, 빈 날짜 없이 모든 달력 날짜를 포함한다.
- 코인 가격과 선택적인 기준선 가격은 유한한 양수다.
- 첫 코인 가격은 주식 정규화에 사용한 관측 코인 가격과 일치하고 관측 날짜도 주식 기준일과 같다. 숫자가 같아도 오래된 코인 앵커는 연동 모드에서 거부한다.
- `training.maxSourceDate`가 기준일을 넘지 않는다.
- 사용한 출처 ID, 계산 방법, 명시적인 가격 기준선 목록이 있다.

금융 입력의 공시 시점 검사는 계속 적용한다. 현재 연구 입력을 과거 투자 성과 백테스트로 재해석할 수 없도록 연구 지식 기준일보다 오래된 가격 기준일은 거부한다. 같은 날짜의 코인 UTC 종가와 뉴욕 주식 종가는 서로 다른 시각이다. 일별 연결이 분 단위 동시 시세를 복원하지는 않는다.

각 반환값은 `pathMode`, `path`, `milestones`, `assumptions`, `assetPath`, `diagnostics`를 갖는다. `assetPath`에는 선택한 코인 경로의 방법, seed, 가격 기준선, 학습 자료 범위, 한계가 들어 있다. 코인 경로 전체를 중복 저장하지 않는다. 주식 경로의 `components.coinPrice`가 실제로 소비한 코인 가격이다. `coinBaselinePrice`는 제공된 경우 가격 기준선을 별도로 남긴다.

## 3. 일별 평가와 재무 처리 순서

코인 보유량을 $H$, 코인 가격을 $P$, 현금을 $C$, 기타 포함 자산을 $O$로 둔다. 채무 원금, 우선주 청구권, 기타 부채, 비지배지분을 각각 $D$, $L$, $B$, $I$로 둔다. 보통주 수는 $N$, 시장 배수는 $m$이다.

$$
A=HP+C+O-D-L-B-I,
\qquad S_t=\begin{cases}
0 & \text{이 날짜까지 한 번이라도 잔여가치 소진}\,,\\
m_t\dfrac{\max(A_t,0)}{N_t} & \text{그 외}\,.
\end{cases}
$$

기준일의 $m$은 관측 주가를 과거 재무 구조의 주당 잔여가치로 나눈 값이다. 이 배수는 현재 NAV 프리미엄이 아니다. 이후 $m$은 각 조건의 지정 배수로 3년 반감 수렴한다. 프리미엄의 확률분포를 추정하거나 추가 시장 베타를 적합하지 않는다.

기준일 행에는 새 비용을 적용하지 않는다. 다음 날짜부터 `dt = 경과 달력일 / 365.25`로 아래 순서를 실행한다. 연동 모드의 인접 행은 하루 간격이다.

1. 해당 조건의 기타 자산 할인을 적용한다.
2. 순 스테이킹 비율에 따라 보유 코인을 증가시킨다.
3. 보유 상한을 넘는 보상을 0.5% 매각비용 차감 후 현금으로 옮긴다.
4. BMNR 스트레스 조건의 일회성 슬래싱 손실을 지정한 시점에 적용한다.
5. 금융비용과 연 $50m 운영비 가정을 현금에서 지출한다. 부족한 금액은 코인을 매각한다. 미지급액은 부채로 남긴다.
6. 해당 날짜까지 도래한 원금을 상환한다. 미지급 원금은 기타 부채로 재분류하며 사라지지 않는다.
7. 무상 희석을 주식 수에 적용한다.
8. 순발행가가 주당 잔여가치보다 높고 보유 여력이 있으면 보통주 발행을 계산한다.
9. 일말 잔여가치와 주가를 계산한다.

상환 후에도 연 금융비용을 자동으로 낮추지 않는 기존 단순화는 유지한다. 새 계약이나 비용 절감을 추정한 것이 아니다. 슬래싱 시점은 실제 사고일 예측이 아닌 기존 조건이다. 위 정책 수치와 원래 출처, 추가 가정은 [재무 모형](TREASURY_MODEL.md)에 정리되어 있다.

주말에도 코인 가치, 비용, 스테이킹, 상환, 발행 가정을 계산한다. 여기서 발행은 연간 비율을 일별로 배분한 연속적인 모델 가정이며 실제 주말 주식 발행 기록이 아니다. 차트의 표시 간격과 회계 계산 날짜는 별개다.

### 발행과 보유 상한

계획 신주 수는 $\Delta N_{plan}=N((1+i)^{dt}-1)$이다. 순발행가가 잔여가치를 높이는 조건을 통과한 뒤 보유 여력에 맞춰 마지막 발행을 축소한다.

$$
\Delta N=\min\left(\Delta N_{plan},\frac{\max(K-H,0)P}{qQ(1-f)}\right),
\qquad F=\Delta NQ(1-f).
$$

여기서 $K$는 보유 상한, $Q$는 제시 발행가격, $f=0.02$는 발행비용, $q=0.9$는 코인 투자 비율이다. 코인 매입과 잔여 현금은 같은 순조달 $F$를 분배한다.

$$
\Delta H=qF/P,\qquad \Delta C=(1-q)F,
\qquad \Delta H P+\Delta C=F.
$$

MSTR의 21m BTC는 최종 공급의 느슨한 산술 경계다. 매수 가능 수량이나 시장 흡수력을 뜻하지 않는다. BMNR의 6.105m ETH는 회사 보고 공급 122.1m에 경영진의 5% 전략을 적용한 고정 가정이다. 미래 ETH 공급의 상한이 아니다. [상한의 출처와 한계](TREASURY_RECOVERY_RESEARCH.md#3-보유-상한과-보존-식)

### 같은 종착 가격이어도 결과가 달라지는 이유

비용을 충당하기 위해 낮은 가격에서 코인을 팔면 더 많은 수량을 사용한다. 상한에 도달하는 날짜가 달라지면 발행할 수 있는 주식 수도 달라진다. 따라서 처음과 마지막 코인 가격이 같아도 중간 경로에 따라 누적 조달액, 보유량, 주식 수, 최종 주가가 달라질 수 있다.

신규 회귀 검사는 종착 ETH 가격이 같은 두 경로의 초기 고가·저가 순서를 바꾼다. 실제 출력에서 누적 조달액, 주식 수, 주가가 달라짐을 확인한다. 코인 수량에 고정 배수만 곱하는 구현으로는 이 검사를 만족할 수 없다.

## 4. 조건 범위, 0 경계와 고저점 후보

세 기초자산 대표 경로는 각각 독립적인 재무 계산을 통과한다. 각 날짜의 주가 세 개를 구한 뒤 그 최소·최대를 `path.low`, `path.high`에 저장한다. 코인 범위에 주식 배수를 곱해서 만들지 않는다. 이 범위는 분위수, 신뢰구간, 가능한 손실의 전체 범위가 아니다.

어느 조건의 일말 잔여가치가 0 이하가 되면 그 조건은 기존 청산 스트레스 규칙에 따라 이후 가격을 0으로 유지한다. 다른 조건의 주가가 양수이면 계속 계산한다. 범위 하한이 0이라는 이유로 선택한 경로를 0으로 만들지 않는다. 실제 주가의 옵션 가치나 법적 파산 절차를 모델링한 규칙은 아니다.

각 행의 `valuationState`는 소진 전 `active`, 소진일부터 `absorbed`다. `components.insolvent`는 **그 날짜의 잔여가치가 0 이하인지**만 나타낸다. 흡수 뒤 운영·발행 계산은 중단되지만 코인 가격은 계속 바뀌므로, 동결한 잔고의 산술적 잔여가치가 다시 양수가 될 수 있다. 그때 `components.insolvent`는 `false`여도 `valuationState`는 `absorbed`이고 주가 가정은 0이다. 이는 경영활동 재개·재구조화·주주 회복을 분석하지 않는 종료 규칙이다. 잔여가치 식만으로 흡수 이후의 주가를 다시 계산하면 다른 모델이 된다.

고저점 후보는 선택한 모의 주가 경로에 12% 방향 반전 규칙을 적용한 사후 요약이다. 12%는 앱이 선택한 표시 가정이며 별도의 최소 날짜 간격 필터는 없다. 후보 발생일과 모형 안에서 반전 조건을 충족한 날짜를 따로 기록한다. 시장의 실제 미래 전환일이나 4년 반복 법칙을 발견했다는 뜻은 아니다. `kind: 'simulated-turn'`과 `probability: null`로 구분한다. 잔여가치 소진은 별도의 `simulated-insolvency` 표식이다.

이 재무 엔진은 미래 OHLC를 반환하지 않는다. 차트가 일별 평가값으로 모의 구간봉을 구성하더라도 장중 체결 고가·저가를 예측한 것으로 설명할 수 없다. 선택 경로의 값과 세 조건의 범위도 다른 데이터다.

## 5. 저장 관측으로 재현한 비교

아래 계산은 2026-10-23 저장 관측, seed `20261022`, 종료일 2035-12-31을 사용했다. 기존 재무 구조와 정책은 유지했다. 각 새 경로에는 기준일을 포함해 3,357개의 일별 행이 있다. 금액은 USD이며 표시를 위해 소수 둘째 자리로 반올림했다.

| 종목·조건 | 기존 목표 연결 | 같은 목표를 일별 회계로 계산 | 새 기초자산 경로를 일별 회계로 계산 |
|---|---:|---:|---:|
| MSTR 스트레스 | $0.00 | $0.00 | $17.94 |
| MSTR 기준 | $598.58 | $598.34 | $819.52 |
| MSTR 확대 | $3,624.64 | $3,624.57 | $3,369.42 |
| BMNR 스트레스 | $1.37 | $1.37 | $0.37 |
| BMNR 기준 | $23.54 | $23.54 | $9.98 |
| BMNR 확대 | $318.55 | $318.24 | $139.29 |

두 번째 열과 세 번째 열의 차이는 회계 시간 간격 변경 효과다. 세 번째 열과 네 번째 열의 차이는 코인 가격 경로와 선택한 경제 조건 변경을 포함한다. 새 값을 더 정확한 목표가로 읽을 근거는 없다.

BMNR 확대의 2035년 모의 ETH 가격은 약 $9,399.11이다. $22,000은 기준선의 조건이고 실제 모의 경로의 강제 종착값이 아니다. 이 경로의 누적 순조달은 약 $1.218bn이다. MSTR 확대의 같은 날짜 모의 BTC 가격은 약 $883,524.23이며 누적 순조달은 약 $1.476tn이다. 조달액은 실제 확보 자금이나 회사 계획을 확인한 수치가 아니다.

## 6. 실행한 검증과 범위

직접 실행한 `node tests/treasury-model.test.mjs`의 기존 개별 검사 32개와 `node tests/treasury-path-integration.test.mjs`의 신규 개별 검사 14개가 통과했다. 신규 검사는 다음 결과를 확인한다.

- 기초자산 일별 가격이 보간이나 재정규화 없이 재무 계산에 전달된다.
- 일요일 비용과 원금 상환이 누락되거나 중복되지 않는다.
- 상한 초과 스테이킹 보상, 매각비용, 현금이 연결된다.
- 같은 종착 가격의 서로 다른 중간 경로가 다른 재무 결과를 만든다.
- 긴 표시 기간을 요청해도 공통 일별 경로의 재무 결과가 달라지지 않는다.
- 선택하지 않은 조건의 잘못된 날짜, 가격, 기준일, 출처 범위도 거부한다.
- 가격 숫자가 같아도 오래된 날짜의 코인 앵커를 연동 모드에서 거부한다.
- 0 흡수, 조건 범위, 모의 고저점의 확인일이 구분된다.
- 입력을 변경하지 않고 반환값에 순환 참조가 없다.

실제 기초자산 모듈과 연결해 두 종목의 2035년 세 조건을 각각 실행했다. 실행 결과가 앞 표의 네 번째 열이다. 전체 저장소 CI, 공개 화면, 릴리스 자산 검증은 이 단위 검사와 다른 범위다. 각 완료 여부는 해당 커밋의 실행 기록을 따른다.

다음 코드는 저장된 입력으로 연동 결과를 재현하는 공개 API 사용 예다.

```js
import {readFile} from 'node:fs/promises';
import {buildTreasuryAssetPaths} from './dist/treasury-asset-paths.js';
import {buildTreasuryForecasts} from './dist/treasury-model.js';

const btcHistory=JSON.parse(await readFile('dist/data/btc-daily.json','utf8'));
const ethHistory=JSON.parse(await readFile('dist/data/eth-ohlc.json','utf8'));
for(const symbol of ['MSTR','BMNR']){
	const history=JSON.parse(await readFile(`dist/data/${symbol.toLowerCase()}-ohlc.json`,'utf8'));
	const asOf=history.candles.at(-1).date.slice(0,10);
	const assetPaths=buildTreasuryAssetPaths({symbol,btcHistory,ethHistory,asOf,endYear:2035,seed:20261022});
	const forecasts=buildTreasuryForecasts({symbol,history,assetPaths,endYear:2035});
	for(const [id,result] of Object.entries(forecasts)){
		const last=result.path.at(-1);
		console.log(symbol,id,last.date,last.price,last.components.capitalRaised);
	}
}
```

각 기초자산 조건의 표본 경로는 하나다. 임의 seed의 경로가 여러 번 그려지거나 과거 블록을 중복 추출해도 독립적인 실제 시장 사례가 늘어나지 않는다. 주가 예측 정확도, 범위의 포함 확률, 실제 주식 발행 가능성, 미래 거래소 장중 OHLC는 검증 범위에 포함하지 않는다.
